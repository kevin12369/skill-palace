## 什么是 SKILL Palace

SKILL Palace 不是"人设聊天机器人"。它走的是相反路线：**不追求"像他"，而追求"用他的方法想问题"**。

- 别人做"赛博朋友圈"（像谁在跟你聊天）
- SKILL Palace 做"思维工具箱"（用谁的方法论分析问题）
- 且这些工具可以**组合成智囊团**，多视角交叉验证

每个 skill 都是**思维框架与文风的工具**，用于辅助用户自行研判。它不声称代表人物本人，也不引用任何未公开的专有研究。

## 圆桌会议（Roundtable）

SKILL Palace 不是"预设组合"，而是"按需组阁"。你提出一个问题，系统根据问题涉及的领域，**动态组装**最合适的专家圆桌。

| 问题特征 | 推荐专家 | 分析顺序 |
|---------|---------|---------|
| 涉及估值/护城河/安全边际 | 巴菲特 | 直接估值分析 |
| 涉及商业判断/逆向审视/认知偏误 | 芒格 | 直接逆向审视 |
| 涉及美联储/全球利率/美元 | 格林斯潘 | 全球宏观定调 |
| 涉及中国经济/政策/地产 | 高善文 | 中国宏观定调 |
| 完整投资决策链 | 高善文/格林斯潘（宏观）→ 芒格（筛选）→ 巴菲特（估值） | 宏观定调 → 逆向筛选 → 估值决策 |
| 牛市狂热/泡沫信号 | 索罗斯（反身性）+ 芒格（Lollapalooza）+ 格林斯潘（非理性繁荣） | 反身性诊断 → 泡沫判断 → 风险扫描 |
| 技术革命/产业转型 | 佩雷斯（技术-经济范式）+ 康德拉季耶夫（长波定位） | 范式结构分析 → 长波位置判断 |
| 通缩/债务周期/货币政策 | 欧文·费雪（债务通缩）+ 高善文（中国传导）/ 格林斯潘（全球传导） | 货币理论框架 → 宏观传导分析 |
| 成长股/管理层深度评估 | 菲利普·费雪（15点清单+闲聊法）+ 巴菲特（护城河） | 成长性评估 → 护城河验证 |
| 通缩/债务周期/去杠杆路径 | 欧文·费雪（债务通缩）+ 明斯基（脆弱性累积）+ 达里奥（去杠杆路径） | 理论框架 → 脆弱诊断 → 去杠杆方案 |
| 技术创新/产业颠覆评估 | 熊彼特（创造性破坏）+ 加特纳（Hype Cycle定位）+ 莱特（成本预测） | 创新定性 → 成熟度定位 → 成本量化 |

| A股牛熊/底部顶部判断 | 李大霄（政策市+估值中枢）+ 洪灏（周期定位） | 政策面 → 估值面 → 情绪面 |
| 商业模式/企业质量/长期持有 | 段永平（商业模式三问+不为清单）+ 巴菲特（护城河） | 生意模式 → 企业文化 → 价格 |

## 快速开始

### 两个仓库的关系

本仓库旁边还有一个单点仓库 [`kevin12369/gaoshanwen-skill`](https://github.com/kevin12369/gaoshanwen-skill)。
一句话分工：**它是高善文这一条 SKILL 的单点前身（单 skill 但工程更深），本仓库是含 51 个 SKILL 的库；
库里 [`skills/gao-shanwen/`](skills/gao-shanwen) 是同一套框架按本库 14 文件标准重新渲染的版本**。

| | `gaoshanwen-skill`（单点前身） | 本仓库 `skills/gao-shanwen/`（库内版本） |
|---|---|---|
| 范围 | 1 个 skill | 51 个 skill |
| 跟踪文件数 | 56 | 17 |
| `references/` | 8 个编号文件 | 8 个编号文件（同名同体系） |
| 示例正文 | 13 篇（`01-…`–`13-…`） | 3 篇（`example-0N-…`） |
| 额外 SKILL 变体 | `SKILL-a-share.md`、`SKILL-real-estate.md`、`SKILL.en.md` | 无（本库变体口径见[选择 SKILL 变体](#选择-skill-变体)） |
| `PROFILE.md` | 无 | 有（本库 14 文件标准要求） |
| 自检与治理 | `scripts/validate-skill.py`（53 项）、`tests/` | 由 `tools/skill-gen/` 统一渲染，无单点脚本 |
| 发布节奏 | 独立 tag `v1.0.0`–`v1.4.3` | 随本库 tag 走（`v2.x`） |

**怎么选**：只要高善文一个人的深度用法（含 A 股版 / 房地产版 / 英文版）→ 装 `gaoshanwen-skill`；
要一批人物、还要圆桌组阁 → 装本仓库。**两者择一，不要同时装**，否则同名 skill 会在 skills 目录里互相覆盖。

> 上表数字都可用 `git ls-files | wc -l`、`ls references`、`ls examples` 在两个仓库里直接数出。

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/kevin12369/skill-palace /tmp/skill-palace

# 2. 复制你需要的 skill 到对应平台的 skills 目录
#    以 charlie-munger 为例，路径见文末「兼容性」表
cp -r /tmp/skill-palace/skills/charlie-munger <skills路径>/charlie-munger

# 3. 安装全部 skill
cp -r /tmp/skill-palace/skills/* <skills路径>/
```

### 各平台 skills 路径

各平台的用户级 / 项目级 skills 目录见文末[兼容性](#兼容性)表（7 行，与本文件其余平台说法同源）。
下文所说的 `<skills路径>` 即该表中对应平台的目录。

### 选择 SKILL 变体

每个 skill 支持多版本体例。安装时将所需变体重命名为 `SKILL.md` 即可。当前仓库实际提供完整版与精简版两种；专项版与英文版是规范预留的文件名约定，`SKILL_SPEC.md` 允许但未强制，本仓库尚未落地（见下表"现有实例"列，数字可由 `find` 直接数出）。

| 变体 | 文件名 | 适用场景 | 现有实例 |
|------|--------|---------|---------|
| 完整版（默认） | `SKILL.md` | 深度分析，全量框架与文风 | 52 份（51 位专家 + `_template`） |
| 精简版 | `SKILL-condensed.md` | token 预算有限，快速调用（实测 1.8–3.0 KB） | 52 份 |
| 专项版 | `SKILL-<topic>.md` | 特定领域专项（如 A 股 / 房地产） | 0 份（规范预留，未使用） |
| 英文版 | `SKILL.en.md` | 国际化场景 | 0 份（规范预留，未使用） |

> 复核命令：`find skills -maxdepth 2 -name 'SKILL*.md' | sed 's|.*/||' | sort | uniq -c`
> 当前输出为 `52 SKILL-condensed.md` 与 `52 SKILL.md` 两行，即上表前两行。

```bash
# 示例：安装精简版（将变体重命名为 SKILL.md 即可）
cp /tmp/skill-palace/skills/charlie-munger/SKILL-condensed.md <skills路径>/charlie-munger/SKILL.md
```

### 验证

安装后，在对话中输入触发词，Agent 应自动加载该 skill：

> "用芒格的框架分析一下这笔投资该不该做"
> "像高善文那样讲讲当前的市场"

若未自动触发，检查 `SKILL.md` 的 `description` 字段是否包含对应关键词。无需手动注册——Agent 会根据 description 中的触发词自动激活。
