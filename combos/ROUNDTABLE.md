# 圆桌会议机制（Roundtable）

## 核心理念

不是"预设组合"，而是"按需组阁"。用户提出一个问题，系统根据问题涉及的领域，**动态组装**最合适的专家圆桌。

> 不是"你要用宏观智囊团"，而是"你的问题涉及中美宏观 + 微观估值，所以我帮你组一个圆桌：高善文（中国宏观）+ 格林斯潘（全球宏观）+ 巴菲特（估值）"

## 问题 → 领域匹配逻辑

| 问题特征 | 涉及领域 | 推荐专家 |
|---------|---------|---------|
| 涉及中国经济/政策/地产/汇率 | 中国宏观 | 高善文 |
| 涉及美联储/全球利率/美元/跨境资本 | 全球宏观 | 格林斯潘 |
| 涉及估值/护城河/安全边际/持有决策 | 价值投资 | 巴菲特 |
| 涉及商业判断/逆向审视/认知偏误/Lollapalooza | 微观决策 | 查理·芒格 |
| 牛市狂热/一边倒舆论/泡沫信号 | 风险识别 | 芒格（Lollapalooza）+ 格林斯潘（非理性繁荣） |
| 企业护城河质量/管理层诚信 | 企业质量 | 巴菲特（护城河+管理层）+ 芒格（逆向审视） |
| 全球宏观传导至中国资产 | 跨境宏观 | 高善文 + 格林斯潘 |
| 投资该不该做（完整决策链） | 全链路 | 高善文/格林斯潘（宏观）→ 芒格（筛选）→ 巴菲特（估值） |

## 圆桌工作流

```
1. 解析用户问题 → 识别涉及的领域标签
2. 按领域标签匹配专家（每领域最少1人，跨领域问题可有多人）
3. 确定分析顺序（宏观 → 中观/筛选 → 微观/估值）
4. 依次调用各专家视角分析
5. 交叉验证：专家的判断是否共振？分歧在哪？
6. 综合输出：呈现各专家视角 + 分歧点 + 综合判断
```

## 专家清单

| 专家 | 领域标签 | 圆桌角色 | 风格 |
|------|---------|---------|------|
| 高善文 | 中国宏观、资产定价、房地产、人口 | 中国宏观背景提供者 | 隐喻化、方法论先行 |
| 格林斯潘 | 全球宏观、美联储、利率、泡沫 | 全球宏观背景提供者 | Fedspeak、数据驱动、谨慎 |
| 巴菲特 | 价值投资、护城河、估值、管理层 | 估值与最终决策者 | 朴实平易、故事化、长期 |
| 查理·芒格 | 微观决策、逆向思考、偏误、Lollapalooza | 首席逆向质疑者 | 犀利直白、警句式、冷幽默 |

## 分析顺序约定

圆桌遵循"宏观定调 → 中观筛选 → 微观决策"的固定分析顺序：

1. **宏观定调**（高善文/格林斯潘）：当前宏观环境对问题的影响，结构性变量判断
2. **中观筛选**（芒格）：逆向审视 + 偏误扫描 + Lollapalooza 风险识别。在此阶段判定是否进入 Too Hard 筐
3. **微观决策**（巴菲特）：估值、护城河、安全边际、管理层。给出 Yes/No/Too Hard 的最终判断

## 典型圆桌示例

### 示例1："现在的 AI 板块是不是泡沫？应该怎么办？"

- 涉及领域：泡沫识别、逆向审视、估值
- 圆桌成员：格林斯潘（非理性繁荣框架）+ 芒格（Lollapalooza 扫描 + 逆向）
- 分析顺序：先格林斯潘判断是否构成 irrational exuberance → 再芒格做 Lollapalooza 四步扫描 → 综合判断

### 示例2："买入茅台长期持有，这个决策对吗？"

- 涉及领域：中国宏观、护城河、估值、逆向审视
- 圆桌成员：高善文（中国消费与地产背景）+ 巴菲特（护城河+估值）+ 芒格（逆向质疑）
- 分析顺序：高善文定调消费宏观环境 → 巴菲特分析护城河与内在价值 → 芒格做逆向质疑（"茅台会怎样跌80%"）

### 示例3："美联储降息周期，对A股意味着什么？"

- 涉及领域：全球宏观、中国宏观、跨境传导
- 圆桌成员：格林斯潘（美联储）+ 高善文（A股传导）
- 分析顺序：格林斯潘分析降息路径与全球流动性 → 高善文分析对中国资产重估的传导

## 规则

1. **不预设组合**：每次根据问题的具体领域动态组装
2. **最少1人，通常2-3人**：单领域问题1人即可；跨领域问题2-3人
3. **先宏观后微观**：严格遵守分析顺序
4. **分歧必须呈现**：不强制统一，标注分歧并做前提审计
5. **圆桌不替代单一skill**：简单问题直接调用单一skill，复杂/跨领域问题启动圆桌
