# 圆桌会议机制（Roundtable）

## 核心理念

不是"预设组合"，而是"按需组阁"。用户提出一个问题，系统根据问题涉及的领域，**动态组装**最合适的专家圆桌。

> 不是"你要用宏观智囊团"，而是"你的问题涉及中美宏观 + 微观估值，所以我帮你组一个圆桌：GS（中国宏观）+ GP（全球宏观）+ WB（估值）"

**低 token 原则**：组阁时优先读本节"快速组阁速查" + `registry/roundtable-matrix.json`，**不要**逐个读取 49 份完整 SKILL.md。仅在确定席位后，才加载被选中专家的 SKILL.md。

### 3. 确定性排序与候选收敛

圆桌遵循固定分析顺序：**宏观定调 → 中观筛选 → 微观决策**。组阁后按确定性规则收敛（v2.1 升级，落地方案见 `tools/skill-gen/assemble.py`）：

1. **两级命中**：A) 问题文本匹配领域标签（`tag_index` 子串命中）；B) 口语兜底词表（"上车/该不该买/抄底/追高"等高频问法 → 候选代码，解决"能不能上车"这类字面匹配弱的问题）。
2. **命中强度**：A 命中计 2 分、B 命中计 1 分，累加；排序键 =（阶段顺序 → 强度降序 → 字母序）。
3. **阶段限额**：宏观定调 ≤3、中观筛选 ≤2、微观决策 ≤2。
4. **兜底补位**：某阶段为空时补位——宏观空补 **GS**、中观空补 **CM**、微观空补 **WB**（保证三阶段齐全）。
5. **情境补位**：问题命中特定模式时按序补入，弥补结构性盲区（A股/中国 → GS+HH；美联储/降息 → GP+BB；科创/科技/AI → RS+HOM+GT；消费/白酒 → QG+DY；新能源 → PL+WR；金融/地产/红利 → LD+QG）。
6. **列席备询**：正式之外的命中者按序取 ≤6 人，不占正式名额。
7. **微观决策至少 1 人**：即使零命中，也补 WB 作最终裁决者。

### 4. 组阁算法（伪代码）

```
1. 解析用户问题
2. 路径A：问题匹配 tag_index 标签 → 取候选代码（命中 +2）
3. 路径B：口语兜底词表命中 → 取候选代码（命中 +1）
4. 合并去重，按 阶段 → 强度 → 字母 排序
5. 阶段限额截取（宏观≤3 / 中观≤2 / 微观≤2）
6. 空阶段兜底补位（GS / CM / WB）
7. 情境补位（A股/美联储/科创/消费/新能源/金融等模式）
8. 列席 = 剩余命中者，取 ≤6
9. 仅加载所选代码的 SKILL.md（其余不读，省 token）
10. 依次发言 → 交叉验证（共振/分歧）→ 合成最终判断
```

> 可执行版本：`python tools/skill-gen/assemble.py "问题"` 一键复现组阁（`--json` 输出结构化结果）。主持人可在脚本基线之上微调并注明理由。

## 圆桌工作流

```
1. 解析用户问题 → 识别涉及的领域标签
2. 按领域标签匹配专家代码（每领域最少1人，跨领域可多人）
3. 确定分析顺序（宏观 → 中观/筛选 → 微观/估值）
4. 依次调用各专家视角分析（仅加载已选 SKILL.md）
5. 交叉验证：专家的判断是否共振？分歧在哪？
6. 综合输出：呈现各专家视角 + 分歧点 + 综合判断
```

## 分析顺序约定

圆桌遵循"宏观定调 → 中观筛选 → 微观决策"的固定分析顺序：

1. **宏观定调**（GS / GP / KN / IF / RD / SZ / JG / RS / BB / LD / HH / FP / SH）：当前宏观环境对问题的影响，结构性变量判断。
2. **中观筛选**（CM / SZ / HM / CP / SP / GT / WR / JV / HOM / BM / FS / DK / CE / NT / XX / BC / JL / WG / MZ / LW / GR / RW / GD / JC / YS / JS / XW / QA / LQ / YJ / JM）：逆向审视 + 偏误扫描 + Lollapalooza 风险识别 + 周期/泡沫/脆弱性/行为定位 + 量价/趋势/形态/交易心理/量化统计套利分析。在此阶段判定是否进入 Too Hard 筐。
3. **微观决策**（WB / PF / CM / QG / LS / DY / PL）：估值、护城河、安全边际、管理层、财报质量、商业模式。给出 Yes / No / Too Hard 的最终判断。

### 示例1："现在的 AI 板块是不是泡沫？应该怎么办？"

### 示例2："买入茅台长期持有，这个决策对吗？"
- 涉及领域：中国宏观、护城河、估值、逆向审视
- 圆桌成员：GS（中国消费与地产背景）+ WB（护城河+估值）+ CM（逆向质疑）
- 分析顺序：GS 定调消费宏观环境 → WB 分析护城河与内在价值 → CM 做逆向质疑（"茅台会怎样跌 80%"）

### 示例3："美联储降息周期，对 A 股意味着什么？"

- 分析顺序：GP 分析降息路径与全球流动性 → GS 分析对中国资产重估的传导

### 示例4："当下美股市场和中国市场是否还能入场投资？"（跨域测试，见 `examples/中美市场入场圆桌实录.md`）
- 涉及领域标签：全球宏观、中国宏观、泡沫识别、估值决策、反身性
- 命中代码：**GP**（全球宏观 / 泡沫）、**GS**（中国宏观）、**SZ**（反身性 / 繁荣-萧条）、**CM**（逆向 / Lollapalooza）、**WB**（估值裁决）
- 排序：宏观定调 GP + GS → 中观筛选 SZ + CM → 微观决策 WB
- 列席备询：GT（AI 成熟度）、HM（脆弱性）、RD（去杠杆路径）
- 数据锚点：2026-07-31 收盘
- 结论摘要：
  - 美股"挑着买"——宽基指数安全边际薄、龙头剧烈分化（苹果 -7.35%、特斯拉 YTD -30.8%），避开 PE≈196 的拥挤赛道（科创50），控仓位、设止损。
  - 中国"蓝筹躺着投"——沪深300 PE 14.38 处历史偏低区（价值区间），但负向反身性未破、缺催化，动能交易须等信用扩张与信心逆转信号。
  - **五人共识**：① 美股整体不便宜、安全边际薄；② 科创50 PE≈196 是清晰投机；③ 中美分化是核心矛盾；④ 现金 / 安全边际为共同纪律。
  - **主要分歧**：SZ 看美股繁荣未尽 vs GP 忧非理性繁荣；GS 看中国"等催化" vs CM 忧负面 Lollapalooza 未解；WB 愿配中国价值 vs SZ 等叙事转折确认。

### 示例5："当前 A 股能不能上车？"（组阁脚本实测，见 `examples/A股上车圆桌实录.md`）

- 结论摘要：**能上车但上"价值车"不上"行情车"**——沪深300 类低估值蓝筹分 3-4 笔逢低布局；科创50 结构性泡沫（PE 200）坚决回避；留现金、不加杠杆、以"买公司"心态分批。

## 规则

1. **不预设组合**：每次根据问题的具体领域动态组装。
2. **最少 1 人，通常 2-3 人**：单领域问题 1 人即可；跨领域问题 2-3 人（最多 5 正式席位 + 列席备询）。
3. **先宏观后微观**：严格遵守分析顺序。
4. **分歧必须呈现**：不强制统一，标注分歧并做前提审计。
5. **圆桌不替代单一 skill**：简单问题直接调用单一 skill，复杂 / 跨领域问题启动圆桌。
6. **低 token 组阁**：组阁只读本节速查表 + `registry/roundtable-matrix.json`；确定席位后才加载对应 SKILL.md，不预读全部 profile。
7. **收敛确定性**：组阁可用 `tools/skill-gen/assemble.py` 一键复现（两级命中 → 限额 → 兜底 → 情境补位 → 列席）；主持人在脚本基线之上微调时须注明理由。

## 机器索引

`registry/roundtable-matrix.json` 为机器可读的紧凑索引，字段：
- `code_map`：skill 名 → 短代码（反向查 person → code）
- `stages`：三阶段 → 代码列表（宏观定调 / 中观筛选 / 微观决策）
- `experts`：代码 → {name, person, role, tags, stage, path}
- `tag_index`：标签 → 候选代码列表（332 个标签，供程序化命中）

agent 可据此在单次读取内完成"解析 → 组阁 → 排序"，无需遍历 49 份 SKILL.md。
