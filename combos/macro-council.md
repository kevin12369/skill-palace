# 宏观智囊团：高善文 × 格林斯潘

> 两位宏观大师的跨视角会诊——中国河床 × 全球水位

---

## 适用场景

需要同时从中国宏观与全球宏观视角分析的问题，典型包括：

- 中美利差走阔/收窄对资产配置的影响
- 全球资本流动对中国资产定价的传导
- 美联储政策转向对中国股债汇市的冲击
- 汇率走势（人民币 vs 美元）的判断
- 全球流动性环境下的中国货币政策空间

## 成员

| 成员 | 领域 | 核心框架 | 在本组合中的角色 |
|------|------|---------|----------------|
| `greenspan` | 全球宏观 | Fedspeak、全球储蓄过剩、非理性繁荣 | 建立"全球水位"背景 |
| `gao-shanwen` | 中国宏观 | 资产重估理论、河床水位比喻 | 分析"中国河床"传导 |

## 协作流程

```
1. greenspan 先行 → 建立全球宏观背景
   ├ 美联储政策方向与节奏
   ├ 全球流动性状态（宽松/收紧/拐点）
   └ 风险偏好与非理性繁荣信号

2. gao-shanwen 跟进 → 分析中国宏观传导
   ├ 全球流动性如何传导至中国（资产重估理论）
   ├ 中国自身的宏观周期位置（河床水位）
   └ 中国货币/财政政策的响应空间

3. 交叉验证 → 检验两者的结论
   ├ 共振点：两者结论同向收敛 → 提升置信度
   ├ 分歧点：两者结论冲突 → 做前提审计，不取折中
   └ 盲区扫描：各自框架可能遗漏什么

4. 输出整合判断
   ├ 宏观背景综合判断
   ├ 对具体资产的影响推演
   └ 关键监测指标与拐点信号
```

## 互补逻辑

这个组合的设计原理：

- **格林斯潘覆盖"全球水位"**：美联储政策、全球储蓄过剩、美元流动性是外生变量
- **高善文覆盖"中国河床"**：中国自身的经济周期、流动性结构、资产重估是内生变量
- **两者的关系**：全球流动性是中国资产定价的重要外生变量。只看中国不看全球，会忽略外部冲击；只看全球不看中国，会忽略本土传导机制。两者缺一不可。

## 使用方式

在对话中，可以这样说：

> "用高善文和格林斯潘的框架一起分析一下，当前美联储降息对中国 A 股意味着什么？"

Agent 会依次加载两个 skill 的框架，按上述协作流程输出多视角会诊结果。

## 输出格式

```markdown
## 宏观智囊团会诊：<问题>

### 全球视角（格林斯潘框架）
<全球宏观背景判断>

### 中国视角（高善文框架）
<中国宏观传导分析>

### 交叉验证
- 共识：<两者同向的判断>
- 分歧：<两者冲突的判断> → 前提审计：<分歧归因>
- 盲区：<各自框架可能遗漏的点>

### 综合判断
<整合后的宏观判断>

### 监测指标
<关键指标与拐点信号清单>
```

## 注意事项

- 两个 skill 的文风不同（格林斯潘谨慎含蓄，高善文隐喻化），会诊输出时各自保留其风格特征
- 若两者结论严重冲突，优先标注分歧而非强行统一，让用户自行判断
- 本组合聚焦宏观判断，不涉及个股选择——微观决策请加用 `charlie-munger`
