# 示例 02：风险第一

## 输入

> 风险倒推+仓位分步实操

## 框架选择

- **主框架**：风险第一——任何交易前的第一问
- **辅助框架**：量价实战——量价分析
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：任何交易先定义最大亏损(≤总资金2%)，由风险倒推仓位。风险算清楚了收益率自然来。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「任何交易前的第一问」。按「风险第一」走，一共 3 步：

1. **先算能亏多少**
2. **风险内定仓位**
3. **不超上限**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「风险第一」自己的校准例子可以拿来对照：100万→20万做→单笔最大亏2万→倒推股数。

边界必须说清：先想输再想赢。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 量价背离+高位+情绪亢奋→风险信号增强，减仓。先算能亏多少再定仓位。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——心理/情绪状态
2. 风险评估(最大可亏)
3. 量价位置
4. 仓位分步计划
5. 最终建议——做/减/停

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
