# 示例 01：创造性破坏扫描

## 输入

> 识别哪些行业正在经历范式级创新冲击

## 框架选择

- **主框架**：创造性破坏——判断一项技术创新的真实影响
- **辅助框架**：企业家精神与新组合——在分析一个公司的竞争力时，区分跟随者和创新者
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：资本主义经济的本质不是静态均衡，而是持续的动态革新——新的生产方法、产品、市场和组织不断'从内部'摧毁旧的结构并创造新的。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一项技术创新的真实影响」。按「创造性破坏」走，一共 3 步：

1. **识别是否属于'新组合'(新产品/方法/市场/原料/组织)**
2. **看是否已有企业/行业因之消亡**
3. **判断破坏的速度和广度**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「创造性破坏」自己的校准例子可以拿来对照：智能手机摧毁了相机、MP3、GPS、闹钟等大量独立设备市场——这是创造性破坏的经典案例。

边界必须说清：破坏的不只是产品，更是整个产业链和价值分配。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按熊彼特框架：当前的AI浪潮是一次典型的创新集群爆发——从芯片到模型再到应用，新组合正在摧毁大量已有的商业模式。这不是'成本效率的提升'，这是创造性破坏。

可执行的判断规则（本 SKILL 的输出格式）：

1. 创新判断——当前是否存在创新集群在爆发
2. 创造性破坏扫描——哪些行业/商业模式正在被摧毁
3. 企业家信号——谁是关键创新者
4. 产业突变阶段——是破坏的前夜、中期还是后效期
5. 最终判断——投资'创造'的一面还是规避'破坏'的一面

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
