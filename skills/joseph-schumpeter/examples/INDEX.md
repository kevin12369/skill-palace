# 示例索引

本目录收录基于约瑟夫·熊彼特创新演化论分析框架的典型示例，帮助理解框架的应用方式。

---

## 示例列表

### 01 - 创造性破坏判定

**适用路径**：A·快速判定（"这是不是创造性破坏"）

**框架应用**：创造性破坏判定 → 创新五形态分类 → 破坏深度判断（核心 vs 边缘）

**关键词**：创造性破坏、产业突变、价值链分析

**文件**：`01-creative-destruction-judgment.md`

---

### 02 - 产业演化深度分析

**适用路径**：B·深度分析（完整产业演化评估）

**框架应用**：创造性破坏判定 → 创新五形态 → 企业家定位 → 创新集群与周期 → 演化过程推演 → 终局追问 → 演化信号

**关键词**：演化经济学、创新集群、长波、产业变迁

**文件**：`02-industry-evolution-analysis.md`

---

### 03 - 企业家角色分析

**适用路径**：D·企业家角色分析（"谁是熊彼特式企业家"）

**框架应用**：企业家（实现新组合）vs 资本家（提供资金）vs 管理者（维持运行）的三维区分

**关键词**：企业家精神、新组合、打破均衡

**文件**：`03-entrepreneur-role-analysis.md`

---

### 04 - 终局追问

**适用路径**：C·终局追问（"资本主义的未来""大企业官僚化"）

**框架应用**：官僚化检查 → 企业家精神温度 → 知识分子对立评估 → 前资本主义情感评估

**关键词**：资本主义社会主义民主、官僚化、终局判断

**文件**：`04-endgame-analysis.md`

---

## 使用建议

1. 先从 `01-creative-destruction-judgment.md` 入手——这是最核心的定性判断
2. 需要全景式分析时用 `02-industry-evolution-analysis.md`
3. "人的因素"分析时用 `03-entrepreneur-role-analysis.md`
4. 宏大命题时用 `04-endgame-analysis.md`
