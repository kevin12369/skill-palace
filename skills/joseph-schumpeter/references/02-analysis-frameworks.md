# 02 - 分析框架工作流

> 本文件定义基于约瑟夫·熊彼特创新演化论的分析工作流与分支路径。所有流程均为熊彼特公开来源方法论的整理，用于辅助研判，不代表熊彼特先生本人或其未公开观点。

---

## 标准工作流（7 步）

以下为完整分析的标准步骤。简单判断见下方分支路径表。

### 第 1 步：创造性破坏判定

**核心操作**：定性判断这场变革的本质——

- 这是在摧毁什么产业/什么价值链的什么环节？
- 这是在创造什么新产业/新价值网络？
- 摧毁的是"边缘"还是"核心"？如果在边缘→持续性改进；如果在核心→创造性破坏。

**判断结果**：
- 核心破坏 → 进入深度分析，继续第 2 步
- 边缘改进 → 标注"按熊彼特框架，这属于持续性改进而非创造性破坏"，流程可精简

> 默认前提：创造性破坏是常态——大多数"看起来像革命"的技术变革最终只是在旧框架内优化。

### 第 2 步：创新五形态分类

**核心操作**：将当前创新归入熊彼特的五种创新形态：

1. 引入新产品
2. 采用新生产方式
3. 开辟新市场
4. 控制新原材料来源
5. 创造新组织形式

**形态叠加评估**：
- 1 个形态 → 局部创新
- 2-3 个形态 → 结构性创新
- 4-5 个形态 → 范式转移级创新

> 一种创新可能同时涉及多个形态。形态越多 → 破坏深度越大。

### 第 3 步：企业家角色定位

**核心操作**：识别当前场景中谁是——

- **熊彼特式企业家**：在"实现新组合"——打破既有均衡的创新者
- **资本家**：提供资金、承担财务风险
- **管理者**：维护现有业务运行

**定位三问**：
1. 他/她是否引入了之前不存在的"新组合"？
2. 他/她的成功是因为打破了旧产业的均衡，还是因为适应了既有框架？
3. 他/她是"一时的企业家"（已退化为管理者/资本家）还是"持续的企业家"？

### 第 4 步：创新集群与周期定位

**核心操作**：将当前变革放入长波历史中定位——

1. **集群归属**：这属于哪个历史上的/正在形成的创新集群？
2. **阶段判断**：该集群处于导入期 / 成长期 / 成熟期 / 衰退期？
3. **相互作用**：与同一集群中的其他创新是否在互相催化？

**历史参照**：

| 集群时期的信号 | 阶段 |
|---------------|------|
| 技术路线未收敛、赢家未出现、资本市场高度兴奋 | 导入期 |
| 技术标准确立、渗透率加速、基础设施铺开 | 成长期 |
| 渗透率见顶、寡头格局稳定、增长靠集中度提升 | 成熟期 |
| 新技术的萌芽出现、现有企业利润下降 | 衰退期/下一轮导入期 |

### 第 5 步：演化过程推演

**核心操作**：用"变异→选择→保留扩散"三步审视当前产业变迁。

1. **变异**：目前涌现了哪些新技术/新企业/新模式？（列举 3-5 个关键变异）
2. **选择**：市场竞争中胜出者是否已开始显现？选择标准是什么？
3. **保留扩散**：成功创新是否已经被广泛模仿？是否开始制度化（标准制定、政策写入）？

**判断**：当前处于变异的早期、选择的进行中、还是保留扩散的晚期？

> 在保留扩散的晚期，敏锐地寻找"下一轮变异的萌芽"——熊彼特式分析的核心价值在于"在旧范式稳固时，预判新变异的到来"。

### 第 6 步：终局追问

**核心操作**：推演当前创新浪潮的长期后果——

1. **新均衡的形态**：如果当前创新完全成功，10 年后的产业格局会是什么样？
2. **被埋葬的是什么**：旧产业的哪些部分会消失？哪些会转化？哪些会存活？
3. **官僚化风险**：当前的创新者会成为未来的官僚机器吗？（熊彼特 1942 的担忧）
4. **下一轮创新的种子**：当前创新浪潮的成功，是否在埋下下一轮创造性破坏的种子？

> 熊彼特式分析的标志性步骤：敢于做历史阶段的判断——"这一轮创新的终局将是……"但要标注"按框架推演"。

### 第 7 步：给演化跟踪信号

**核心操作**：附"未来需要盯住哪些变量/事件来验证或推翻本判断"。

**有效跟踪信号的特征**：
- 可观测（不是"市场变好了"，而是"新产业的企业数量月度增长超过 X%"）
- 可证伪（明确指出在什么条件下本判断被推翻）
- 有时间尺度（熊彼特式分析的尺度是"年"和"十年"，不是"季度"）

**格式**：
| 跟踪变量 | 当前状态 | 验证阈值 | 推翻阈值 |
|----------|---------|----------|---------|
| 旧产业的消亡速度 | 当前状态 | 若达到 X，快速创造性破坏确认 | 若低于 Y，可能是持续性改进被误判 |
| 新产业的企业数量/渗透率 | 当前值 | 趋势加速确认 | 趋势停滞，创新是假象 |
| 创新集群的交互效应 | 当前状态 | 多创新互相催化确认 | 创新孤立无交互 |

## 分支路径表

| 路径 | 适用场景 | 简述 |
|------|---------|------|
| **A·快速判定** | "这是不是创造性破坏"——初步定性 | 创造性破坏判定 + 创新五形态分类。两步输出：是/否/部分破坏。 |
| **B·深度分析** | 完整产业演化评估 | 全流程 7 步，从破坏判定到演化信号。适合重大技术变革的分析。 |
| **C·终局追问** | "资本主义的未来""大企业会不会官僚化"等命题 | 以框架 6（终局判断）为主 + 演化过程推演。输出以"按熊彼特 1942 框架"定调。 |
| **D·企业家角色分析** | "谁是熊彼特式企业家""X 公司是不是在扼杀创新" | 以框架 2（企业家—创新者）和框架 3（创新五形态）为主。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 是资本主��/终局的宏大命题？
  │    └─ 是 → C·终局追问
  │
  ├─ 是"谁是企业家"类问题？
  │    └─ 是 → D·企业家角色分析
  │
  ├─ 需要完整的产业演化评估？
  │    └─ 是 → A·快速判定（先定性）
  │              ├─ 不是创造性破坏 → 精简输出定调
  │              └─ 是创造性破坏 → B·深度分析
  │
  └─ 只是问"是不是创造性破坏"？
       └─ A·快速判定：两步定结论
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 7 步流程**：重大技术变革的产业演化评估、范式转移判断（如 AI 对各行业的影响、能源转型）
- **精简流程（核心 3 步）**：日常判断、初步筛选
  1. 创造性破坏判定
  2. 创新五形态分类
  3. 终局追问

### 数据与框架的关系

- 有行业数据可用：在演化过程推演中加入渗透率、企业数量变化、集中度变化等量化指标
- 无数据：声明"以下为按熊彼特框架进行的演化推演，缺乏实时数据交叉验证"
- 数据与框架冲突：以数据为准——框架是用来"帮助看清"，不是用来"替代看清楚"

### 时间尺度的诚实性

熊彼特式分析的天然问题是时间尺度——"产业演化"和"长波周期"的尺度是 10-50 年。当用户问的是短期（季度/年度）判断时：
- 明确标注"按熊彼特框架，这是一个 10-50 年的演化过程，以下判断包含高度不确定性"
- 短期判断可以借用"快速判定"路径，但必须告知局限
- 不适合超短期判断（日内/周度）——此时不套用本框架，直接回答即可
