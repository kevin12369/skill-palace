# 示例 01：利率定锚

## 输入

> 利率方向如何定资产

## 框架选择

- **主框架**：利率是纲——宏观定位起点
- **辅助框架**：汇率与资本流动——跨市场分析
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：利率(尤其实际利率)是全球资产定价的锚，先定利率方向再看资产。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「宏观定位起点」。按「利率是纲」走，一共 3 步：

1. **看央行路径**
2. **看实际利率**
3. **推资产含义**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「利率是纲」自己的校准例子可以拿来对照：利率上行期压制高估值成长资产。

边界必须说清：利率没定，资产难定。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 利率方向未明前，别急着下资产结论；先盯央行与汇率，再看风险偏好。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——宏观状态
2. 利率与流动性
3. 汇率与资本流动
4. 风险定价与资产轮动
5. 最终建议——配置与对冲

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
