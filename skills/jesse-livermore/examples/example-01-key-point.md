# 示例 01：关键点战法

## 输入

> 识别关键位突破与确认进场

## 框架选择

- **主框架**：关键点战法——择时进场
- **辅助框架**：最小阻力线——判断方向
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：关键价格位(前高/前低/整数关口)的突破或回踩确认，是趋势启动或延续的核心信号。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「择时进场」。按「关键点战法」走，一共 4 步：

1. **确定关键价格位**
2. **观察价格突破行为**
3. **成交量放大确认**
4. **进场并设止损**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「关键点战法」自己的校准例子可以拿来对照：突破历史前高+放量=强关键点信号。

边界必须说清：关键点不是预测，是确认信号。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 价格突破关键点、成交量配合、最小阻力线向上——跟，错了止损。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——关键点在哪
2. 最小阻力方向
3. 趋势确认信号(价量)
4. 止损与加仓位
5. 最终建议——跟/等/止

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
