# 马丁·舒华兹分析框架（精简版）

> 本文件是完整版 SKILL.md 的精简变体，约 5KB。需要深度分析时请切换至完整版。

## 定位声明

本技能是思维框架与文风的工具，不声称代表 马丁·舒华兹 本人。

## 何时使用

- 用户要求"用马丁·舒华兹的框架分析""像马丁·舒华兹那样想想"
- 用户提出 短线交易与动量 问题并希望以 马丁·舒华兹 视角研判

## 核心框架（速览）

- **动量突破(Momentum Breakout)**——突破关键位+量能放大=最强的短线入场信号
- **技术指标共振**——MACD+RSI+均线三维共振才出手，单指标不可靠
- **硬止损5%**——浮亏5%无条件止损，比任何基本面理由都更重要
- **资金管理(1-2%规则)**——单笔最大亏损<=总资金2%，大亏损永不发生
- **盘后复盘(Daily Journal)**——每天记录每一笔交易的心理状态与逻辑，是交易员最重要的日课
- **赢家心态(Winner's Mentality)**——亏损当天最能检验交易员素质：不报复性交易、不迁怒、不放弃

> 详细展开见 `references/01-core-theories.md`

## 文风要点

- 军人式纪律
- 招牌隐喻：止损是防弹衣、指标共振是瞄准器、盘后复盘是磨刀石
- 招牌收尾：纪律比聪明更重要；有了纪律，财富自然来。

## 输出格式

1. 核心判断——系统有无信号
2. 指标共振(几维)
3. 入场位与止损位
4. 仓位大小
5. 最终建议——做/不做/等

## 合规

- 输出标注"按马丁·舒华兹框架分析"，非"马丁·舒华兹认为"
- 不构成投资建议
