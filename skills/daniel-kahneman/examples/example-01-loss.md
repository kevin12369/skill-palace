# 示例 01：损失厌恶

## 输入

> 为何死扛亏损过早止盈

## 框架选择

- **主框架**：双系统(系统1/2)——分析任何决策偏差来源
- **辅助框架**：前景理论——解释风险态度不对称
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：系统1自动直觉、系统2需费力推理；认知负荷下系统1主导致误。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「分析任何决策偏差来源」。按「双系统(系统1/2)」走，一共 3 步：

1. **识别是否凭直觉**
2. **判断场景复杂度**
3. **召唤系统2复核**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「双系统(系统1/2)」自己的校准例子可以拿来对照：暴跌时系统1恐慌抛售，系统2应评估长期价值。

边界必须说清：训练系统2在关键决策时上线。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 眼前暴跌触发系统1的恐慌，但数据显示长期持有胜率更高——让系统2接管。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——主导偏误是什么
2. 系统识别(1/2)
3. 偏差扫描
4. 纠正动作
5. 最终建议——决策纪律

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
