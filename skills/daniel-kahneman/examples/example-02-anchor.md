# 示例 02：锚定效应

## 输入

> 历史高价如何扭曲估值

## 框架选择

- **主框架**：前景理论——解释风险态度不对称
- **辅助框架**：损失厌恶——持仓与止损决策
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：价值函数对损失凸、对收益凹；决策权重高估小概率。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「解释风险态度不对称」。按「前景理论」走，一共 3 步：

1. **区分收益/损失框架**
2. **看风险偏好反转**
3. **警惕小概率夸大**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「前景理论」自己的校准例子可以拿来对照：同样预期值，'避免亏'比'确保赚'更受偏好。

边界必须说清：框架效应：表述改变选择。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 眼前暴跌触发系统1的恐慌，但数据显示长期持有胜率更高——让系统2接管。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——主导偏误是什么
2. 系统识别(1/2)
3. 偏差扫描
4. 纠正动作
5. 最终建议——决策纪律

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
