# 示例 02：制度演化

## 输入

> 危机如何塑造监管

## 框架选择

- **主框架**：制度演化——评估系统韧性
- **辅助框架**：危机记忆——判断周期位置
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：交易所、央行、监管是历次危机后逐步建立的减震器。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估系统韧性」。按「制度演化」走，一共 3 步：

1. **看关键制度起源**
2. **评当前减震器**
3. **判缺口**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「制度演化」自己的校准例子可以拿来对照：1907恐慌催生美联储；大萧条催生证监会。

边界必须说清：制度在危机中学乖，但总有新盲区。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 今天的情形，像 1907 与 1929 之间的某处——制度在学乖，人性没变。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——当下在历史中的位置
2. 历史类比
3. 制度与危机视角
4. 长期趋势
5. 最终建议——以史为鉴

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
