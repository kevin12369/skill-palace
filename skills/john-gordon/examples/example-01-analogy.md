# 示例 01：历史类比

## 输入

> 当下如1907与1929之间

## 框架选择

- **主框架**：历史类比——理解当下异常
- **辅助框架**：制度演化——评估系统韧性
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：市场由相似的人性驱动，当下事件常有历史原型可对照。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「理解当下异常」。按「历史类比」走，一共 3 步：

1. **提取当前结构特征**
2. **匹配历史原型**
3. **借原型校准预期**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「历史类比」自己的校准例子可以拿来对照：散户狂热+杠杆扩张近似1929前夜的结构。

边界必须说清：类比非预测，提供参照框架。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 今天的情形，像 1907 与 1929 之间的某处——制度在学乖，人性没变。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——当下在历史中的位置
2. 历史类比
3. 制度与危机视角
4. 长期趋势
5. 最终建议——以史为鉴

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
