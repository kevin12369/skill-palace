# 示例 01：债务通缩诊断

## 输入

> 用费雪框架判断一个高杠杆经济体的通缩风险

## 框架选择

- **主框架**：债务通缩——高杠杆环境下的通缩风险
- **辅助框架**：费雪效应——判断货币政策的松紧
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：过度负债→被迫清算抛售→价格下跌→实际债务上升→更多抛售→产出下降→信心崩溃→囤积货币→银行危机→恶性循环。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「高杠杆环境下的通缩风险」。按「债务通缩」走，一共 4 步：

1. **评估社会总债务水平**
2. **看价格水平的趋势**
3. **判断债务与通缩是否形成反馈**
4. **评估企业/家庭的实际债务负担变化**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「债务通缩」自己的校准例子可以拿来对照：日本1990年代至今：资产价格崩盘→实际债务负担上升→企业和家庭持续去杠杆→通缩长期化。

边界必须说清：债务通缩是一旦启动就很难停止的恶性循环——最好的解是事前不积累过度负债。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按费雪的债务通缩理论：当社会总债务处于历史高位而价格水平开始下降时，实际债务负担自动加重→企业被迫抛售资产去杠杆→价格进一步下跌→进入恶性螺旋——这就是1930年代大萧条的核心机制。

可执行的判断规则（本 SKILL 的输出格式）：

1. 货币环境判断——费雪方程解读
2. 债务水平诊断——过度负债的风险程度
3. 通缩风险评估——价格水平与实际债务的互动
4. 费雪效应——名义利率vs实际利率
5. 最终判断——去杠杆还是再通胀
