## 完整输出

先说这套框架的判断逻辑：正常的散量不会造成明显的量能放大——异常放量必是主力所为。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「主力识别」。按「主力行为痕迹」走，一共 3 步：

1. **看量能异常放大**
2. **看价格异动方向**
3. **判主力意图**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「主力行为痕迹」自己的校准例子可以拿来对照：连续地量后突然放倍量+阳线=主力进场。

边界必须说清：异常量之后的走势揭示主力方向。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 底部持续放量+缩量回踩+再放量突破=主力完成吸筹→跟。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——量价是否健康
2. 主力行为判断
3. 突破/回调到位信号
4. 止盈止损位
5. 最终建议——跟/等/走
