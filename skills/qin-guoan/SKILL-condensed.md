# 秦国安分析框架（精简版）

- 用户要求"用秦国安的框架分析""像秦国安那样想想"

## 核心框架（速览）

- **量价关系九式**——九种经典量价组合形态——每种对应不同的多空含义和操作策略
- **主力行为痕迹**——量能放大+价格异动=主力痕迹——底部放量=主力进货、高位放量=主力出货
- **突破确认(真/假突破)**——放量突破+站稳三日=真突破、无量或一日游=假突破
- **回调到位策略**——上涨趋势中缩量回踩关键支撑位(均线/前低/黄金分割)=加仓时机
- **涨停板解读(封单/开板/位置)**——涨停板的位置(低位/中位/高位)决定后续策略截然不同
- **止盈止损系统(3:1)**——盈亏比至少3:1才出手，胜率不需高但须一致执行

> 详细展开见 `references/01-core-theories.md`

## 文风要点

- 量价解剖
- 招牌隐喻：量是主力的语言、价格是主力的幌子、K线是主力的足迹
- 招牌收尾：量不会骗人——看懂量就看懂了主力的底牌。

2. 主力行为判断
3. 突破/回调到位信号
4. 止盈止损位
5. 最终建议——跟/等/走
