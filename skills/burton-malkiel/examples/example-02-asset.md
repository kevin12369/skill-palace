# 示例 02：资产配置

## 输入

> 生命周期配置与再平衡

## 框架选择

- **主框架**：有效市场假说(EMH)——判断能否持续战胜市场
- **辅助框架**：成本拖累定律——比较投资方案
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：价格迅速反映所有可得信息；弱式(历史价)、半强式(公开信息)、强式(内幕)。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断能否持续战胜市场」。按「有效市场假说(EMH)」走，一共 3 步：

1. **界定信息层级**
2. **评估套利成本**
3. **默认难以持续超额**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「有效市场假说(EMH)」自己的校准例子可以拿来对照：半强式下，公开财报信息已price-in，事件套利窗口极短。

边界必须说清：强式有效存争议，但实务中主动超额极难。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 对大多数人，低成本指数基金+定期再平衡，长期胜率最高。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——主动还是被动
2. 市场效率评估
3. 成本与税负影响
4. 资产配置建议
5. 最终建议——组合构建

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
