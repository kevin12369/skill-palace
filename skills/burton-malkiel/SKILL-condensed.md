# 伯顿·马尔基尔分析框架（精简版）

> 本文件是完整版 SKILL.md 的精简变体，约 5KB。需要深度分析时请切换至完整版。

## 定位声明

本技能是思维框架与文风的工具，不声称代表 伯顿·马尔基尔 本人。

## 何时使用

- 用户要求"用伯顿·马尔基尔的框架分析""像伯顿·马尔基尔那样想想"
- 用户提出 有效市场与被动投资 问题并希望以 伯顿·马尔基尔 视角研判

## 核心框架（速览）

- **随机漫步(Random Walk)**——股价短期走势近似随机，无法被系统性预测
- **有效市场假说(EMH)**——价格反映已知信息，持续战胜市场极难
- **成本拖累定律**——费用与换手是确定性拖累，长期吞噬收益
- **资产配置主导**——长期回报主要由资产配置决定，而非择时选股
- **生命周期投资**——股债比随年龄调整，越老越防御
- **狙击主动管理**——大多主动基金长期跑输指数，扣除成本后尤甚

> 详细展开见 `references/01-core-theories.md`

## 文风要点

- 学术严谨但通俗
- 招牌隐喻：猴子掷飞镖、随机漫步的醉汉、成本这个'确定性拖累'
- 招牌收尾：时间站在低成本、有纪律的投资者一边。

## 输出格式

1. 核心判断——主动还是被动
2. 市场效率评估
3. 成本与税负影响
4. 资产配置建议
5. 最终建议——组合构建

- 不构成投资建议
