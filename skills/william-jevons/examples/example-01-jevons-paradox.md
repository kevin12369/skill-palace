# 示例 01：杰文斯悖论应用

## 输入

> 判断电动车普及是否导致锂电池总消耗暴增

## 框架选择

- **主框架**：杰文斯悖论——评估一项效率提升技术的真实减排效果
- **辅助框架**：反弹效应三层次——估算一项效率政策的真实节能量
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：技术进步提高资源使用效率→降低单位产出的资源消耗→降低使用成本→在宏观上反而刺激更多使用→总资源消耗可能不降反升。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估一项效率提升技术的真实减排效果」。按「杰文斯悖论」走，一共 4 步：

1. **看效率提升幅度**
2. **预估价格弹性带来的新增需求**
3. **识别新的应用场景(效率降本催生的)**
4. **判断总消耗是增加还是减少**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「杰文斯悖论」自己的校准例子可以拿来对照：蒸汽机效率越高→英国煤炭消耗越多(19世纪)；空调能效比提升→家庭空调拥有量和单机容量增长→总用电上升。

边界必须说清：悖论不是100%成立——若有总量约束(如碳配额)或需求饱和，可以被打破。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按杰文斯悖论框架:LED照明效率比白炽灯高85%，但全球照明用电总量在LED普及后不降反升——因为更便宜的光刺激了更多照明需求和应用场景(从道路到植物工厂)。这就是经典的反弹效应。

可执行的判断规则（本 SKILL 的输出格式）：

1. 杰文斯悖论判断——效率提升会导致总消费增加吗
2. 反弹效应估算——直接/间接/宏观经济三个层次
3. 总量约束——哪种情况下悖论被打破
4. 能源转型含义——对光伏/电动车/氢能的效率逻辑
5. 最终判断——效率政策是否需要配合总量约束

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
