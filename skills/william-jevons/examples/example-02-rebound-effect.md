# 示例 02：反弹效应三层估算

## 输入

> 用三层次框架评估光伏效率提升的净减排效果

## 框架选择

- **主框架**：反弹效应三层次——估算一项效率政策的真实节能量
- **辅助框架**：边际效用递减——分析需求强度与定价
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：直接反弹(更高效→用更多)→间接反弹(省下的钱花在其他耗能品上)→宏观经济反弹(效率推动整体经济增长→所有能源消耗上升)。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「估算一项效率政策的真实节能量」。按「反弹效应三层次」走，一共 4 步：

1. **算直接反弹(价格弹性)**
2. **算间接反弹(收入效应)**
3. **算宏观经济反弹(全经济反馈)**
4. **三者叠加得出净节能量**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「反弹效应三层次」自己的校准例子可以拿来对照：如果直接反弹20%+间接反弹10%+宏观反弹30%=合计60%反弹→100单位效率提升实际只净节约40单位。

边界必须说清：三个层次的反弹不一定同时存在且不一定同向——但大多数评估认为合计反弹率在30%-50%以上。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按杰文斯悖论框架:LED照明效率比白炽灯高85%，但全球照明用电总量在LED普及后不降反升——因为更便宜的光刺激了更多照明需求和应用场景(从道路到植物工厂)。这就是经典的反弹效应。

可执行的判断规则（本 SKILL 的输出格式）：

1. 杰文斯悖论判断——效率提升会导致总消费增加吗
2. 反弹效应估算——直接/间接/宏观经济三个层次
3. 总量约束——哪种情况下悖论被打破
4. 能源转型含义——对光伏/电动车/氢能的效率逻辑
5. 最终判断——效率政策是否需要配合总量约束

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
