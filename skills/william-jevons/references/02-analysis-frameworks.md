# 02 - 分析框架工作流

> 本文件定义基于威廉·斯坦利·杰文斯资源效率悖论的分析工作流与分支路径。所有流程均为杰文斯公开来源方法论的整理，用于辅助研判，不代表杰文斯先生本人或其未公开观点。

---

## 标准工作流（7 步）

### 第 1 步：效率提升判定

**核心操作**：判断当前技术变化属于——

- **效率提升 (Efficiency Gain)**：同样的资源投入产出更多，或同样的产出消耗更少资源
- **替代转换 (Substitution)**：用一种资源替代另一种资源（如：太阳能替代煤炭）
- **纯粹扩容 (Capacity Expansion)**：增加资源投入获得更多产出（非效率变化）

**判断结果**：
- 效率提升 → 自动触发杰文斯悖论分析，进入第 2 步
- 替代转换 → 转向资源约束分析（框架 4），判断新资源是否也有"枯竭"风险
- 纯粹扩容 → 不适用本框架

> 默认前提：效率提升 + 需求弹性 > 0 → 杰文斯悖论存在触发可能。

### 第 2 步：悖论验证四步

**核心操作**：

1. **效率提升确认**：新技术使单位资源消耗降低了多少百分比？
2. **实际成本下降确认**：效率提升是否转化为使用者的实际成本下降？下降了多少？
3. **需求弹性判断**：该资源的需求如何进行"弹性分级"——
   - 高弹性（照明、通信、运输）：价格降一点，需求暴涨→悖论高度可能
   - 中弹性（制热/制冷、工业流程）：价格降明显，需求增加有限
   - 低弹性（基本生存需求、医疗必需）：价格降再多，需求也涨不了
4. **总消耗方向判断**：效率提升 + 成本下降 + 弹性 → 总消耗是增是减？

**格式**：
| 步骤 | 判断 | 数据/依据 |
|------|------|----------|
| 效率提升幅度 | X% | 具体来源 |
| 使用成本下降 | Y% | 具体来源 |
| 需求弹性分级 | 高/中/低 | 原因说明 |
| 总消耗方向 | 增/减/不确定 | 综合判断 |

### 第 3 步：新应用场景解锁扫描

**核心操作**：技术效率提升是否解锁了全新应用场景？

- **已有场景扩展**：已有的消费者/企业用得更多、更频繁
- **新场景解锁**：因为成本降到阈值以下，全新应用出现（如 LED 价格降到 2 美元以下后，路灯之外出现了景观灯、装饰灯、农业补光灯）

**新场景解锁 = 悖论加剧的核心机制**：效率提升的意义不只是让现有消费者"用更少钱获得同样服务"，而是让"此前根本用不起该资源的人/场景"变成消费者。

### 第 4 步：资源约束评估

**核心操作**：判断该资源的约束性质——

1. **物理储量上限**：已探明储量 vs 年消耗速度 = 剩余年限
2. **替代技术前景**：存在可替代的其他资源吗？替代技术的成熟度如何？
3. **悖论叠加**：如果替代技术本身也伴随效率提升 → 新的杰文斯悖论可能被触发

**约束分级**：
- **硬约束**：物理极限不可逾越 + 无已知替代 → 资源枯竭大概率在可预见未来发生
- **软约束**：存在替代技术前景但时间不确定
- **伪约束**：已知替代技术已成熟且经济可行

### 第 5 步：数学化推演

**核心操作**：用数量化的趋势判断替代定性叙事。

**杰文斯式推演格式**：
1. 当前关键变量：消耗量 Qᵗ、效率 Eᵗ（单位：资源/产出）、产出 Yᵗ
2. 关系：Q = Y × (1/E)
3. 推演：如果效率从 E 提升到 E'（E' > E），产出从 Y 增长到 Y'（Y' > Y，因为效率提升刺激了需求）
4. 判断：Q' = Y' × (1/E') 是大于还是小于 Q = Y × (1/E)？
5. 关键因子：Y' 的增长率 vs E' 的增长率——如果需求增长快于效率提升，则 Q' > Q（悖论触发）

> 如果缺乏具体数据，用符号推演代替数字——但必须标注"以下为数学化框架推演，缺乏具体数据校验"。

### 第 6 步：外生冲击扫描

**核心操作**：是否存在类似"太阳黑子"的外部冲击传导机制？

1. **冲击源识别**：存在什么非经济因素可能影响该资源的供给/需求？（气候、地缘政治、技术断裂、大流行病）
2. **传导机制**：冲击通过什么渠道传导到经济？
3. **周期特征**：该冲击是一次性的还是周期性的？
4. **与悖论的相互作用**：外生冲击是强化了资源约束（供应减少），还是加剧了悖论（刺激更多替代需求）？

> 标注：太阳黑子-商业周期的具体机制已被证伪，此步仅运用"外生冲击监测"的思维框架。

### 第 7 步：长期演化信号

**核心操作**：附 50-100 年尺度的资源-技术演化关键变量清单。

**格式**：
| 变量 | 当前值 | 10 年趋势 | 50 年趋势 | 关键不确定性 |
|------|-------|----------|----------|------------|
| 资源消耗总量 | 当前 | 方向 | 可能景 | 悖论触发程度 |
| 效率提升速度 | 当前 | 方向 | 上限 | 物理极限 |
| 替代技术成熟度 | 当前阶段 | 进展 | 可能替代 | 时间表 |
| 新场景解锁速度 | 当前 | 趋势 | 上限 | 需求饱和点 |

## 分支路径表

| 路径 | 适用场景 | 简述 |
|------|---------|------|
| **A·快速悖论判定** | "这个技术省不省资源"——快速定性 | 效率提升判定 + 悖论触发判断。两步输出：触发/不触发/不确定。 |
| **B·深度悖论分析** | 完整的效率-资源关系评估 | 全流程 7 步，从效率判定到长期信号。适合重大能源/资源政策分析。 |
| **C·资源约束论证** | "石油会不会用完""锂矿够不够" | 以框架 4（煤炭枯竭论）为主 + 悖论验证。 |
| **D·边际效用定价** | "为什么水便宜钻石贵"类问题 | 以框架 2（边际效用递减）为主。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 是定价/价值问题？
  │    └─ 是 → D·边际效用定价
  │
  ├─ 是资源约束/枯竭问题？
  │    └─ 是 → C·资源约束论证
  │
  ├─ 是效率-消耗的悖论关系？
  │    └─ 是 → A·快速悖论判定
  │              ├─ 不触发悖论 → 精简输出原因
  │              └─ 触发悖论 → B·深度悖论分析
  │
  └─ 只是问"节能技术有没有用"？
       └─ A·快速悖论判定
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 7 步流程**：重大能源政策分析（如碳中和路径中的杰文斯悖论风险）、新技术对宏观资源消耗的影响评估
- **精简流程（核心 3 步）**：日常判断、快速筛选
  1. 效率提升判定 + 悖论触发判断
  2. 悖论验证四步中的关键两项（需求弹性 + 新场景解锁）
  3. 长期演化信号

### 杰文斯悖论"不触发"的情况

以下情况悖论不触发或弱触发：
1. **零弹性需求**：资源是生理必需品的绝对极限（如人体每天必需的水量有上限）
2. **监管总量上限**：碳排放配额总上限 + 可强制执行的碳价
3. **替代转换零悖论**：如果替代技术效率提升同时伴随"完全不同的资源"，则旧资源的悖论不触发，但新资源可能触发新悖论

### 时间尺度的诚实性

杰文斯悖论的分析尺度是"数十年到世纪"。当用户问短期趋势时：
- 明确标注"杰文斯悖论的验证需要数十年尺度的数据，以下为趋势性判断而非精确预测"
- 短期（2-5 年）内，效率提升确实可能暂时压低消耗——悖论的完全展开需要数十年
