# 示例 01：PEG选股

## 输入

> 用PEG筛成长股

## 框架选择

- **主框架**：GARP(合理价格成长)——成长股筛选
- **辅助框架**：PEG——估值比较
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：既看成长又看估值，以合理价格买成长，避免为成长付过高价。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「成长股筛选」。按「GARP(合理价格成长)」走，一共 3 步：

1. **看盈利增速**
2. **看估值**
3. **求匹配**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「GARP(合理价格成长)」自己的校准例子可以拿来对照：增速30%+PE合理的成长股优先。

边界必须说清：成长无价的代价是回调。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这家公司产品我天天用、增长又快、PEG 合理——典型的十倍股候选，拿住它。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——公司值不值得买
2. 股票分类
3. 成长与PEG
4. 调研与常识验证
5. 最终建议——持有/卖出/回避
