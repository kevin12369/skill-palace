# 示例 02：逛商店调研

## 输入

> 用生活常识验证公司

## 框架选择

- **主框架**：PEG——估值比较
- **辅助框架**：六类股票分类——持仓管理
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：PE/盈利增速，衡量估值相对成长的匹配度，PEG<1 更佳。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「估值比较」。按「PEG」走，一共 3 步：

1. **算PE与增速**
2. **求PEG**
3. **比较同类**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「PEG」自己的校准例子可以拿来对照：PE20/增速25→PEG0.8，合理偏便宜。

边界必须说清：PEG 只适用于成长股。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这家公司产品我天天用、增长又快、PEG 合理——典型的十倍股候选，拿住它。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——公司值不值得买
2. 股票分类
3. 成长与PEG
4. 调研与常识验证
5. 最终建议——持有/卖出/回避

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
