# 示例 03（专项场景）：第二层次思维

## 输入

> 公司出了超预期的好财报，为什么股价反而跌了？市场是不是不理性？

## 框架选择

- **主框架**：第二层次思维（价格反映的是预期差，而非事实本身）
- **辅助框架**：钟摆理论（预期与情绪的叠加）
- **核心区分**：第一层想"这是好消息"，第二层想"好消息比预期好多少、以及已经被定价了多少"

## 完整输出

先给结论：**市场不是不理性，而是在给"预期差"定价，而不是给"事实"定价。财报是好的，但可能不如价格里已经包含的那么好。**

第一层思维问：这是好消息还是坏消息？第二层思维问三个问题：

1. **这个好消息，多少已经被定价了？** 股价是预期的集合。如果过去一段时间涨幅已经把"超预期"提前反映，那么财报落地就变成"利好出尽"。
2. **好消息的构成是什么？** 是可持续的经营改善，还是一次性的因素（价格、汇率、资产处置、低基数）？市场对两者的定价完全不同，前者计入估值，后者只影响一次性收益。
3. **预期本身被谁推高了？** 卖方一致预期上调的速度，往往快于基本面改善的速度。当预期上调过头，好财报也会变成"不够好"。

**这就是"预期差"的机制**：价格变动取决于"实际 - 预期"，而不是"实际 - 去年"。所以判断一份财报会不会带来上涨，看的不该是同比增速，而是它相对一致预期和相对股价隐含预期的差距。

**二阶追问**：如果这次"利好出尽"之后继续跌，说明什么？说明市场开始重估的是第二层问题的第 2 条——它怀疑好消息的可持续性。此时应把注意力从"预期差"转向"盈利质量"。

**边界提醒**：第二层次思维不能被滥用成"永远看空"。它的正确用法是解释价格与事实的偏离，而不是为下跌编故事。当你需要用三层解释才能说通一件事时，往往说明你已经在事后归因了。
