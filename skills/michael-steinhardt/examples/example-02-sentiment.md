# 示例 02：情绪博弈

## 输入

> 极端情绪反向交易

## 框架选择

- **主框架**：催化剂驱动——选标的
- **辅助框架**：宏观+微观融合——决策过滤
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：没有催化剂的好公司只是'好公司'，不是'好交易'；必须有近期事件改变市场定价。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「选标的」。按「催化剂驱动」走，一共 3 步：

1. **识别近期催化剂**
2. **评估催化剂对定价的冲击**
3. **抢在市场前建仓**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「催化剂驱动」自己的校准例子可以拿来对照：财报披露、政策落地、并购公告=催化剂。

边界必须说清：时效性极强：催化剂到期就走，不留恋。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这条政策还没被市场充分price-in，催化剂触发在即→重仓，目标2周。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——催化剂在哪
2. 信息优势评估
3. 多空方向
4. 时间窗口(短/中)
5. 最终建议——仓位与方向

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
