# 示例 01：催化剂事件

## 输入

> 识别近期催化剂并抢跑建仓

## 框架选择

- **主框架**：信息优势——任何交易前的自检
- **辅助框架**：催化剂驱动——选标的
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：比别人更早、更准确地获取和解读信息，是战胜市场的唯一途径。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「任何交易前的自检」。按「信息优势」走，一共 3 步：

1. **我的信息比市场多什么**
2. **市场已price-in多少**
3. **我还有多少信息窗口**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「信息优势」自己的校准例子可以拿来对照：政策文件发布前从内部资料预判方向。

边界必须说清：合法信息优势非内幕交易。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这条政策还没被市场充分price-in，催化剂触发在即→重仓，目标2周。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——催化剂在哪
2. 信息优势评估
3. 多空方向
4. 时间窗口(短/中)
5. 最终建议——仓位与方向

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
