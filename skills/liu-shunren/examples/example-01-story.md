# 示例 01：财报故事

## 输入

> 把三张表连成经营叙事

## 框架选择

- **主框架**：财报即故事——读任何公司财报
- **辅助框架**：竞争力螺旋——判断公司质量
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：资产负债表、利润表、现金流量表串联成企业经营连续叙事。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「读任何公司财报」。按「财报即故事」走，一共 3 步：

1. **看三表关联**
2. **还原经营动作**
3. **找矛盾点**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「财报即故事」自己的校准例子可以拿来对照：增收不增利、利增不增现，故事断点。

边界必须说清：孤立数字无意义，看连贯性。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 利润漂亮但经营现金流长期背离，这故事讲不通，先打问号。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——财报讲了一个什么故事
2. 三表勾稽检查
3. 竞争力诊断
4. 现金与治理体检
5. 最终建议——可信度与价值

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
