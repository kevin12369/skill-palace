# 示例 01：AI 在 Hype Cycle 的当前位置

## 输入

> 用五阶段模型判断生成式AI走到了哪一步

## 框架选择

- **主框架**：Hype Cycle 五阶段——判断一项新技术的炒作周期位置
- **辅助框架**：炒作与现实差距——面临重大技术投资决策时的冷静框架
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：新技术从触发到成熟经历五个阶段：触发→期望膨胀→幻灭低谷→复苏爬升→生产力平台。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一项新技术的炒作周期位置」。按「Hype Cycle 五阶段」走，一共 4 步：

1. **识别当前主流叙事**
2. **看媒体关注度与融资金额**
3. **对照早期用户的真实体验**
4. **判断距离生产力平台还有多远**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「Hype Cycle 五阶段」自己的校准例子可以拿来对照：2023年的元宇宙：从2021年峰值快速滑入幻灭低谷。

边界必须说清：不同技术走过曲线的时间不同，AI 可能比量子计算快得多。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按Hype Cycle：生成式AI 现在处于期望膨胀的峰值附近——幻灭低谷是必经之路，但有生产力的应用已经在积累。

可执行的判断规则（本 SKILL 的输出格式）：

1. 当前位置判断——处于Hype Cycle的哪个阶段
2. 依据——媒体热度/投资额/用户采纳率证据
3. 历史参照——类似技术走过曲线用了多久
4. 关键信号——什么标志着进入/离开当前阶段
5. 投资建议——当前阶段适合什么策略(投机/观望/布局)

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
