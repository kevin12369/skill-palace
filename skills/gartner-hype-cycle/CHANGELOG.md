## [1.0.0] - 初始版本发布

### 新增

- 初始版本发布，包含 Gartner 技术成熟度曲线（Hype Cycle）分析框架的完整技能文件集。

#### 核心文件

- `SKILL.md`：完整版技能定义文件，包含目的、使用场景、5 个核心框架、7 步工作流概览、文风规范、输出模板、协作说明与局限性声明。
- `SKILL-condensed.md`：精简版技能文件（~3KB），包含核心框架速览、5 步精简工作流、文风要点、输出格式与变体说明。
- `PROFILE.md`：Gartner Hype Cycle 框架档案卡，包含框架基本信息、核心出版物、框架体系、互补关系与免责声明。

#### 参考文献

- `references/01-core-theories.md`：5 个核心框架的完整定义、操作步骤、诊断方法与真实案例（互联网泡沫、云计算、生成式 AI 等）。
- `references/02-analysis-frameworks.md`：标准 7 步工作流详解、分支路径与流程使用说明。
- `references/03-style-and-voice.md`：Hype Cycle 分析文风 DNA，包含语气特征（5 项）、句式偏好、文风禁忌与正反示例。
- `references/04-key-views-timeline.md`：Hype Cycle 框架从 1995 年提出到 2023 年 AI 泡沫讨论的演化时间线。
- `references/05-publications.md`：Gartner Hype Cycle 核心出版物与相关文献索引。
- `references/06-glossary.md`：术语表，收录 19 条 Hype Cycle 与技术采纳生命周期核心术语的定义与使用语境。
- `references/07-checklist.md`：风格校准 Checklist，分内容校准、风格校准、合规校准三大板块。
- `references/08-style-anti-patterns.md`：文风反例库，收录典型表达错误与正确改写示例。

#### 示例

- `examples/INDEX.md`：示例索引，规划技术阶段定位与炒作 vs 实质扫描等示例。

#### 元数据

- `CITATION.cff`：CFF 1.2.0 格式的引用元数据文件。
- `CHANGELOG.md`：本文件。

### 框架特点

- **5 个核心框架**：Hype Cycle 五阶段、炒作 vs 实质识别（剪刀差诊断）、技术采纳生命周期（跨越鸿沟）、优先级矩阵、多技术交叉定位。
- **7 步标准工作流**：收集信号 → 阶段定位 → 剪刀差分析 → 跨越鸿沟评估 → 优先级判断 → 搭骨架 + 套文风 → 给跟踪信号。
- **结构化冷静文风系统**：结构化框架 + 冷静克制 + 实用主义 + 图表化思维 + 区分信号与噪音。
- **完整的合规体系**：Gartner 框架声明、非官方定位声明、投资免责声明、描述性定位声明。
