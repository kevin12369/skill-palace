# 04 - 框架演化史与关键时间线

> 本文件记录 Gartner 技术成熟度曲线（Hype Cycle）框架的演化历史与关键里程碑。Hype Cycle 框架由 Gartner 公司提出。本时间线为 SKILL Palace 基于公开信息的独立整理。

---

## 框架演化年表

| 时间 | 事件 | 核心意义 | 框架贡献 |
|------|------|---------|---------|
| 1995 | Gartner 分析师 Jackie Fenn 首次系统提出 Hype Cycle 概念 | 将技术的炒作与成熟过程建模为五阶段曲线 | Hype Cycle 框架的诞生——此后成为全球最广泛使用的技术趋势可视化工具之一 |
| 1990s 后期 | 互联网泡沫（dot-com bubble）达到高峰 | 完美验证了"技术触发→期望膨胀→幻灭低谷"的前三段——Hype Cycle 获得第一次大规模现实检验 | 互联网泡沫是 Hype Cycle 最经典的案例之一 |
| 2000-2001 | 互联网泡沫破裂 | 大量互联网公司倒闭——纳斯达克从 2000 年 3 月 5,048 点跌至 2002 年 10 月 1,114 点（跌幅 78%） | 历史上最大规模的"期望膨胀→幻灭低谷"的实证 |
| 2000-至今 | Gartner 开始每年发布《Hype Cycle for Emerging Technologies》年度报告 | 标准化的年度技术趋势定位成为业界最权威的参考之一 | Hype Cycle 成为年度技术趋势分析的标准框架 |
| 2003-2007 | 互联网幸存者（Amazon, Google, eBay）从幻灭低谷中崛起，进入启蒙爬坡 | 证明幻灭低谷不是技术的坟墓，而是洗牌谷——幸存者在此建立长期竞争优势 | Web 2.0 时代的崛起对应 Hype Cycle 的"启蒙爬坡→生产力高原"路径 |
| 2008 | Jackie Fenn 与 Mark Raskino 出版《Mastering the Hype Cycle》 | 首次将 Hype Cycle 系统化为可操作的企业技术管理工具 | Hype Cycle 从"观察工具"升级为"决策工具" |
| 2008-2015 | 云计算从"幻灭低谷"进入"启蒙爬坡"并最终进入"生产力高原" | 2008 年左右云计算被广泛质疑，但 AWS 在持续增长——典型的技术在幻灭低谷不被看好但实质进展加速的案例 | 云计算是 Hype Cycle"幻灭低谷→生产力高原"路径的经典示范 |
| 2016 | AI（深度学习）从上一轮幻灭低谷重新进入期望膨胀 | AlphaGo 击败李世石引发新一轮 AI 热潮——AI 经历"二次期望膨胀" | 展示了同一技术可能经历多轮 Hype Cycle（"双波"模式） |
| 2022.11 | ChatGPT 发布——生成式 AI 进入技术触发→期望膨胀的快速通道 | 史上最快从技术触发到期望膨胀峰值的案例之一 | 生成式 AI 的爆炸性普及验证了 Hype Cycle 在社交媒体时代可能被加速 |
| 2023 | 生成式 AI 触及期望膨胀期巅峰 | 全球企业集体"all in AI"、AI 初创估值飙升、CEO 财报电话会必提 AI | 生成式 AI 成为"极致期望膨胀"的现代案例 |
| 2023-至今 | AI 泡沫讨论——"生成式 AI 是否接近幻灭低谷？" | 投资者和分析师激烈争论——AI 的期望膨胀还能持续多久？幻灭何时到来？ | Hype Cycle 在 AI 时代的现实应用——每一个人都在试图定位 AI 在曲线上的位置 |

## 框架演变脉络

### 第一代：概念诞生（1995）

**核心贡献**：Jackie Fenn 将技术成熟度的"波峰波谷"规律首次形式化为五阶段曲线。

**历史背景**：1990 年代的科技热潮催生了大量"过度承诺-不及预期-失望幻灭"的循环。Fenn 的目的是帮助企业理解这一循环的规律，做出更理性的技术投资决策。

### 第二代：年度报告系统化（2000-2010）

**核心贡献**：
- Gartner 开始每年发布 20-30 项新兴技术的 Hype Cycle 定位；
- 衍生出 100+ 个行业/领域特定的 Hype Cycle 变体（如 Hype Cycle for AI、Hype Cycle for Healthcare）；
- 结合"技术优先级矩阵"提供决策量化参考。

### 第三代：从分析工具到决策工具（2008-至今）

**核心贡献**：《Mastering the Hype Cycle》将框架升级为：
- 企业技术投资的阶段化资源分配指南
- 技术组合管理的可视化工具
- 企业与供应商技术对话的共同语言

### 第四代：社交媒体时代的新挑战（2020-至今）

**核心挑战**：
- 社交媒体加速了"注意力"的传播速度——期望膨胀期更陡、更短
- 技术周期整体在加快——从发现到峰值的时间在缩短
- "双波"现象增多——同一技术在短时间内经历多轮 Hype Cycle

## 经典案例在 Hype Cycle 上的路径

### 案例 1：云计算（2006-2020）

```
2006  AWS EC2 发布                      → 技术触发
2008-2010  被质疑"不过是服务器托管"      → 幻灭低谷
2010-2015  SaaS 爆发、混合云成熟        → 启蒙爬坡
2015-至今  云计算成为基础设施             → 生产力高原
```

**启示**：AWS 在幻灭低谷期（2008-2010）的收入仍在快速增长——实质进展从未停止，只是注意力离开了。这恰恰是投资云计算的最佳窗口。

### 案例 2：互联网（1995-2010）

```
1995-1998  浏览器、门户网站兴起           → 技术触发→期望膨胀
1999-2000  dot-com 泡沫巅峰              → 期望膨胀峰值
2000-2002  泡沫破裂，纳斯达克跌 78%       → 幻灭低谷
2003-2007  Web 2.0 崛起                  → 启蒙爬坡
2008-至今  互联网成为基础设施             → 生产力高原
```

**启示**：期望膨胀峰值越高，幻灭低谷越猛烈——但最终到达生产力高原的趋势不受影响。只是走了一条极端的波峰波谷路径。

### 案例 3：生成式 AI（2022-至今，进行中）

```
2022.11  ChatGPT 发布                    → 技术触发（极速）
2023     全民 AI、估值飙升               → 期望膨胀（极陡）
2024-至今 泡沫讨论、"何时幻灭"之争        → 可能已过峰值/接近幻灭
```

**启示**：仍在进行中——这是检验 Hype Cycle 在社交媒体时代是否依然有效的"正在进行时"案例。

## 与其他思想的互补

| 框架/人物 | 互补关系 |
|----------|---------|
| 卡洛塔·佩雷斯的技术浪潮 | 佩雷斯看技术革命的导入-展开结构（50 年长波），加特纳看单项技术的中短波炒作-成熟节奏（3-10 年） |
| 西奥多·莱特的莱特定律 | 莱特看技术成本下降的物理规律（不受情绪影响），加特纳看技术市场预期的情绪周期（完全受情绪驱动） |
| Geoffrey Moore 跨界鸿沟 | Moore 聚焦于"从早期采纳者到早期大众"的一道鸿沟，加特纳覆盖技术从生到熟的全程 |
| Everett Rogers 创新扩散 | Rogers 提供了五类采纳者的分类和 S 曲线，加特纳将采纳者分类嵌入更丰富的时间维度 |
