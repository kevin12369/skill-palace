# Gartner 技术成熟度曲线（Hype Cycle）— 框架档案卡

## 基本信息

- **框架名称**：技术成熟度曲线 / Hype Cycle for Emerging Technologies
- **提出机构**：Gartner, Inc.（全球领先的 IT 研究与顾问公司）
- **首次提出**：1995 年，由 Gartner 分析师 Jackie Fenn 系统化提出
- **领域**：技术趋势分析、创新管理、技术投资决策
- **性质**：
  - 描述性分析框架，非预测性工具
  - 全球企业技术战略规划中最广泛使用的可视化工具之一
  - Gartner 每年发布年度《Hype Cycle for Emerging Technologies》报告
  - 已衍生出 100+ 个领域特定的 Hype Cycle 变体

## 核心出版物/输出

- **《Gartner Hype Cycle for Emerging Technologies》年度报告（2000—至今）**：每年发布一版，覆盖当年 20-30 项新兴技术，是业界最权威的技术趋势参考之一。
- **Jackie Fenn 的原始研究（1995）**：首次将技术的炒作与成熟过程建模为五阶段曲线。
- **《Mastering the Hype Cycle》（2008）**：Jackie Fenn 与 Mark Raskino 合著，系统阐述 Hype Cycle 方法论与企业应用。

## 框架体系

技术成熟度曲线将任何新兴技术的生命周期建模为五个阶段：技术触发、期望膨胀期、幻灭低谷、启蒙爬坡、生产力高原。与之互补的是技术采纳生命周期（创新者→早期采纳者→早期大众→晚期大众→落后者）和"跨越鸿沟"理论。详见 `SKILL.md` 和 `references/` 目录下的详细文件。

本技能与以下技能形成互补：

## 框架来源声明

本技能中的所有框架、模型和分析方法均来自 Gartner 公司的公开研究与相关学术文献：
- Gartner Hype Cycle 方法论（Jackie Fenn, 1995）；
- 《Mastering the Hype Cycle》（Fenn & Raskino, 2008）；
- Geoffrey Moore 的《跨越鸿沟》（Crossing the Chasm, 1991）及相关技术采纳研究；
- Everett Rogers 的《创新扩散》（Diffusion of Innovations, 1962）。

SKILL Palace 将本框架作为分析工具收录，用于辅助用户自行研判。它不声称代表 Gartner 公司或其分析师的观点。
