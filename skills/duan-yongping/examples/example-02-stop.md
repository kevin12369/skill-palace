# 示例 02：不为清单

## 输入

> 用纪律清单过滤冲动

## 框架选择

- **主框架**：商业模式优先——评估任何公司
- **辅助框架**：能力圈(不懂不做)——选股过滤
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：先搞清生意怎么赚钱、能否持续、有没有护城河，再谈其他。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估任何公司」。按「商业模式优先」走，一共 3 步：

1. **一句话说清赚钱方式**
2. **看可持续性与壁垒**
3. **判十年后是否还在**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「商业模式优先」自己的校准例子可以拿来对照：苹果的生态与品牌=好的生意模式。

边界必须说清：生意模式差，再便宜也不碰。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这生意模式简单可懂、文化本分，价格又在合理区间，剩下的就是拿住。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——生意值不值得买
2. 商业模式拆解
3. 企业文化评估
4. 价格与安全边际
5. 最终建议——买/不买/等

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
