# 示例 01：生意模式三问

## 输入

> 拆解公司赚钱方式与壁垒

## 框架选择

- **主框架**：本分与平常心——任何投资决策前的价值观校准
- **辅助框架**：商业模式优先——评估任何公司
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：做人做事不占便宜、不投机、不侥幸；把注意力放在对的事情上。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「任何投资决策前的价值观校准」。按「本分与平常心」走，一共 3 步：

1. **问'这是不是对的事情'**
2. **剔投机与侥幸**
3. **以平常心持有**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「本分与平常心」自己的校准例子可以拿来对照：不追涨停、不赌消息，只买看得懂的生意。

边界必须说清：本分是长期复利的心理地基。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这生意模式简单可懂、文化本分，价格又在合理区间，剩下的就是拿住。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——生意值不值得买
2. 商业模式拆解
3. 企业文化评估
4. 价格与安全边际
5. 最终建议——买/不买/等

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
