# 示例 01：OBV背离

## 输入

> 用OBV背离预判反转

## 框架选择

- **主框架**：OBV(On-Balance Volume)——预测价格方向
- **辅助框架**：格伦维尔八大法则——系统性买卖
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：按涨跌日累加或减去当日成交量得到OBV线——OBV的走势比价格走势更有预见性。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「预测价格方向」。按「OBV(On-Balance Volume)」走，一共 3 步：

1. **涨日+成交量**
2. **跌日-成交量**
3. **看OBV趋势与价格是否同步**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「OBV(On-Balance Volume)」自己的校准例子可以拿来对照：价格横盘OBV持续上升=蓄力待突破。

边界必须说清：OBV是量价的数学翻译。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 价格突破前高但OBV未创新高=顶背离→警惕反转；量价配合=延续。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——量价是否配合
2. OBV位置与背离
3. 格伦维尔法则触发
4. 成交量确认
5. 最终建议——跟/等/反向
