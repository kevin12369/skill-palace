# 示例 02：机构荒诞

## 输入

> 幽默解构复杂理财方案

## 框架选择

- **主框架**：利益错位——评估建议来源
- **辅助框架**：专业者盲区——质疑复杂方案
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：卖方靠佣金/管理费，与客户长期盈亏天然错位。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估建议来源」。按「利益错位」走，一共 3 步：

1. **识别建议者激励**
2. **比对与客户利益**
3. **打折听信**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「利益错位」自己的校准例子可以拿来对照：理财顾问推高佣产品，未必最优于客户。

边界必须说清：看激励而非听意图。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这产品层层收费，游艇是卖家的；客户要问：我的游艇在哪？

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——谁在赚钱
2. 利益结构解剖
3. 荒诞点揭示
4. 客户视角提醒
5. 最终建议——避坑

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
