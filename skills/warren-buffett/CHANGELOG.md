### 框架特点

- **12 个核心框架**：能力圈、安全边际、市场先生、经济护城河（五种类型）、所有者盈余、资本配置（五条路径）、内在价值、长期复利、管理层质量（三维评估）、集中投资、通货膨胀防御、20 孔打卡纪律。
- **8 步标准工作流**：取数 → 能力圈检验 → 护城河评估 → 所有者盈余计算 → 内在价值估算 → 管理层三维评估 → 安全边际判断 → 最终决定。
- **4 条分支路径**：A 快速筛选（20 孔打卡 + 能力圈）/ B 深度估值（完整 DCF）/ C 护城河专项（五类型 + 加宽判断）/ D 管理层评估（三维 + 资本配置记录）。
- **巴菲特式文风系统**：朴实平易 + 故事化叙述 + 自嘲式幽默 + 长期视角 + 农民式智慧 + 股东信语体 + 实用主义 + 道德高度 + 标志性语录自然融入。
- **完整的合规体系**：AI 模拟声明、投资免责声明、不冒充本人、不预测具体价格、能力圈硬 Gate。

### 定位声明

本技能是思维框架与文风的工具，用于辅助用户自行研判。不声称代表沃伦·巴菲特先生本人，不引用或复制未公开的专有研究。巴菲特的公开观点以伯克希尔·哈撒韦历年股东信、年报、股东大会讲话和公开访谈为准。
