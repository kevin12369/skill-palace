# 示例 02：叙事经济学

## 输入

> AI叙事如何推高估值

## 框架选择

- **主框架**：CAPE周期调整市盈率——评估市场整体贵贱
- **辅助框架**：叙事经济学——理解价格驱动
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：股价/十年通胀调整盈利均值，跨期跨市场可比的估值温度计。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估市场整体贵贱」。按「CAPE周期调整市盈率」走，一共 3 步：

1. **取CAPE分位**
2. **比历史区间**
3. **比他国**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「CAPE周期调整市盈率」自己的校准例子可以拿来对照：CAPE>30(美历史均值~16)提示整体偏贵。

边界必须说清：高位不立即跌，但长期回报受压。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> CAPE 处历史高分位，叠加病毒式叙事，非理性繁荣特征明显，宜降杠杆。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——是否泡沫化
2. CAPE/估值位置
3. 叙事与情绪
4. 杠杆与扩散
5. 最终建议——防御与警惕

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
