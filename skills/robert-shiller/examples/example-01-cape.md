# 示例 01：CAPE预警

## 输入

> 用周期调整市盈率判市场贵贱

## 框架选择

- **主框架**：非理性繁荣——判断市场是否过热
- **辅助框架**：CAPE周期调整市盈率——评估市场整体贵贱
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：资产价格受心理、投机与叙事驱动，可长期偏离基本面。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断市场是否过热」。按「非理性繁荣」走，一共 3 步：

1. **看估值偏离**
2. **看投机情绪**
3. **看叙事强度**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「非理性繁荣」自己的校准例子可以拿来对照：2000科技股、2006房市、2021 Meme股皆属此类。

边界必须说清：繁荣可延续，但终回归。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> CAPE 处历史高分位，叠加病毒式叙事，非理性繁荣特征明显，宜降杠杆。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——是否泡沫化
2. CAPE/估值位置
3. 叙事与情绪
4. 杠杆与扩散
5. 最终建议——防御与警惕

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
