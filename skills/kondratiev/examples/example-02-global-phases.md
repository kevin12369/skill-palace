# 示例 02：全球相位差

## 输入

> 分析中美在IT康波中的不同相位

## 框架选择

- **主框架**：价格长波与创新集群——判断当前处在长波上升段还是下降段
- **辅助框架**：战争周期与康波——把地缘冲突放进长周期框架时，避免过度解读
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：康波的经验起点是价格水平的长周期涨落（约 50-60 年一轮），而每一轮上升期都伴随一组基础技术的扩散；价格长波与技术集群在历史上高度同步。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断当前处在长波上升段还是下降段」。按「价格长波与创新集群」走，一共 4 步：

1. **看长期价格水平的方向，而不是单年通胀**
2. **看基础技术是否处在扩散期**
3. **看基础设施投资是否在扩张**
4. **两者同向时，长波方向判断更可靠**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「价格长波与创新集群」自己的校准例子可以拿来对照：19 世纪中后期与 19 世纪末到 20 世纪初的两段价格长波上升期，分别对应铁路与电气化的扩散，价格方向与技术扩散同向。

边界必须说清：价格长波是统计事实，其因果解释仍有争论；用的时候只当同向证据，不要当机制。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按康波框架：我们大概率处于信息技术康波的秋季后半段至冬季前夕——繁荣期的广泛扩散已经完成，技术红利边际递减，通胀中枢高于2000年代，全球正等待下一轮重大技术集群。

可执行的判断规则（本 SKILL 的输出格式）：

1. 当前康波季节定位——春/夏/秋/冬
2. 证据——价格长波/创新集群/社会情绪
3. 历史参照——上一轮同等季节发生了什么
4. 各国相位差——哪些国家更先/更后
5. 最终判断——当前季节适合的战略姿态(扩张/等待/抄底)
