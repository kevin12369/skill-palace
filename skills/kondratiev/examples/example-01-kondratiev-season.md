# 示例 01：康波季节定位

## 输入

> 判断全球经济当前处于哪一轮康波的什么季节

## 框架选择

- **主框架**：康波四季模型——资产配置的长期方向判断
- **辅助框架**：价格长波与创新集群——判断当前处在长波上升段还是下降段
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：每轮康波(约50-60年)经历春季(复苏)→夏季(繁荣)→秋季(滞胀)→冬季(萧条)，历史上一共经历了五轮。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「资产配置的长期方向判断」。按「康波四季模型」走，一共 3 步：

1. **看价格长波的方向(上升/下降)**
2. **看当前技术集群的生命周期位置**
3. **参照历史同时期的资产表现**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「康波四季模型」自己的校准例子可以拿来对照：2000-2020可大致对应IT康波的秋季到冬季过渡——互联网泡沫/次贷/去杠杆/低利率,与历史上第三轮康波秋季(1900s-1920s)高度对应。

边界必须说清：每一轮康波的季节长度不是固定的，识别的是结构性特征而非时间点。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按康波框架：我们大概率处于信息技术康波的秋季后半段至冬季前夕——繁荣期的广泛扩散已经完成，技术红利边际递减，通胀中枢高于2000年代，全球正等待下一轮重大技术集群。

可执行的判断规则（本 SKILL 的输出格式）：

1. 当前康波季节定位——春/夏/秋/冬
2. 证据——价格长波/创新集群/社会情绪
3. 历史参照——上一轮同等季节发生了什么
4. 各国相位差——哪些国家更先/更后
5. 最终判断——当前季节适合的战略姿态(扩张/等待/抄底)

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
