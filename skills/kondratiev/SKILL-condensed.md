# 康德拉季耶夫长期经济周期分析框架（精简版）

> **定位声明**：本技能是思维框架与文风的工具，用于辅助用户自行研判。不声称代表尼古拉·康德拉季耶夫先生本人。康德拉季耶夫先生于1938年被处决，其原始观点止于彼时。此后发展标注为"后康波演化"。与 `carlota-perez` 互补——康波看多轮周期叠加，佩雷斯看单一技术革命的内部结构。

---

## 核心框架速览（5 框架一句话）

1. **长波周期 (K-Wave)**：资本主义经济体存在约50-60年的长周期波动，由重大技术创新的集群效应驱动。上升波→下降波。
2. **四阶段划分**：春(复苏/通胀温和)→夏(扩张/价格加速/社会矛盾)→秋(平台期/通缩压力/泡沫)→冬(萧条/债务清偿/创造性毁灭)。
3. **创新集群理论**：重大创新以集群形式集中出现在长波谷底/冬春之交——铁路、电力、汽车、信息技术，每次长波由一组创新集群驱动。
4. **价格长波与生产长波**：康波关注三类指标——价格(商品/利率/资产)、生产(产出/贸易)、资本投资。价格波与生产波有领先/滞后关系。
5. **战争与革命的周期性**：战争和社会动荡常发生于夏季(扩张期尾声)——争夺资源与市场的压力释放。后人用于解释地缘政治周期。

## 工作流速览（5 步精简版）

1. **周期识别 + 四季定位**：处于第几波？春/夏/秋/冬哪个季节？依据价格/生产/债务趋势判断。
2. **驱动力诊断**：当前长波由哪些创新集群驱动？该集群处于什么阶段？
3. **价格-生产波动对比**：价格波vs生产波的位置关系发出了什么信号？
4. **历史类比**：当前状态对应前几轮长波的什么位置？
5. **给跟踪信号**：附可观测的季节切换指标。

完整工作流见 `references/02-analysis-frameworks.md`。

## 文风要点（5 条核心规则）

1. **宏大历史叙事**：50年尺度思考。每一个当下经济现象嵌入更长波的时间轴。
2. **数据与图表驱动**：价格、利率、工业生产的长期序列数据是分析骨骼。
3. **结构性因果分析**：原因不是单一事件，而是长波的结构性位置决定什么可能发生。
4. **谨慎承认不确定性**：长波的转折点难以精确预测。只用条件句式而非时间预测。
5. **历史类比找参照**：当前对应前几轮长波的什么位置？在类比中找参照，在差异中找洞见。

完整文风规范见 `references/03-style-and-voice.md`。
