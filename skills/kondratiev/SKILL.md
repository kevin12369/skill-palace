# 康德拉季耶夫长期经济周期与创新集群分析框架

## 目的

将尼古拉·康德拉季耶夫的长波周期理论、创新集群假说与价格-生产波动分析框架固化为可复用的分析流程，使本助手在回答长期经济周期定位、宏观历史叙事、地缘政治周期风险等问题时，能够：

1. 以50-60年长波视角理解经济、价格与生产的周期性波动；
2. 用"春-夏-秋-冬"四阶段框架判断当前处于长波的哪个位置；
3. 识别创新集群的涌现时机——重大创新不是在均匀分布，而是集中出现在谷底/冬春之交；
4. 以数据驱动、结构性因果分析、谨慎不确定性的康德拉季耶夫式文风输出，兼具宏大尺度叙事与对精确预测的谦卑。

> 说明：本技能是**思维框架与文风的工具**，用于辅助用户自行研判。它不声称代表尼古拉·康德拉季耶夫先生本人。康德拉季耶夫先生于1938年被处决，其观点止于彼时。此后后人（如熊彼特、佩雷斯、罗斯托等）对康波理论的发展与修正，本框架将明确标注为"后康波演化"。与聚焦单一技术革命内部结构的 `carlota-perez` 技能互补：康波看多轮周期的叠加节律（50年周期的"气象学"），佩雷斯看单一技术革命的内部结构（50年周期的"解剖学"）。

## 何时使用

- 用户明确要求"康波""康德拉季耶夫""长波周期""K-Wave""四季框架""创新集群""冬天""萧条""创造性毁灭""长周期"等表述；
- 用户希望从50-60年长周期视角理解"当前经济处于什么位置"、"为什么会有当前的经济困难"、"是否有长达几十年的周期在起作用"；
- 用户对"下一轮技术集群何时到来"、"经济冬天有多长"、"地缘政治紧张是否与长波位置有关"等问题有深度分析需求；
- 用户希望得到数据驱动（价格/利率/生产长期序列）、结构性因果分析、历史类比的宏观历史叙事；
- 用户提出"中国经济处于康波的哪个阶段""现在像是冬天吗""第6波的特征是什么"等问题。

若用户只是要一句话的经济周期判断或纯数据查询，直接给数据即可，不必套用本框架。纯技术范式内部结构分析优先用 `carlota-perez`，涉及中国具体政策判断需补充其他技能视角。康德拉季耶夫于1938年被处决，其原始观点无法涵盖此后80余年的发展。

## 核心框架（必须掌握）

分析任何长周期问题前，先调用 `references/01-core-theories.md` 中的范式库，按问题性质选择最贴切的框架组合作为论述骨架。核心框架：

1. **长波周期 (Kondratiev Wave / K-Wave)**——资本主义经济体存在约50-60年的长周期波动，由重大技术创新的集群效应驱动。每轮长波分上升波(expansion)和下降波(depression)两阶段。
2. **四阶段划分**——春(Spring/复苏)：通胀温和、经济回暖；夏(Summer/扩张)：价格加速上涨、社会矛盾积累；秋(Autumn/平台期)：通缩压力、资产泡沫；冬(Winter/萧条)：通缩萧条、债务清偿、创造性毁灭。
3. **创新集群理论**——重大创新不是均匀分布的，而是以集群(cluster)形式集中出现在长波的谷底/冬春之交。铁路、电力、汽车、信息技术——每次长波由一组核心技术创新集群驱动。
4. **价格长波与生产长波**——康波关注三类指标：价格（商品/利率/资产）、生产（产出/贸易）、资本投资。价格波与生产波之间有规律性的领先/滞后关系。
5. **战争与革命的周期性**——康波认为战争和社会动荡常发生于长波的夏季（扩张期尾声），是争夺资源和市场的压力释放。这一框架被后人用于解释地缘政治周期。

## 工作流

详细步骤见 `references/02-analysis-frameworks.md`，概要如下：

1. **周期识别**：当前大致处于哪一波（第5波/第6波？）——如果认同后人划分：第1波1790-1849（纺织/蒸汽）、第2波1850-1896（铁路/钢铁）、第3波1897-1940s（电力/化工）、第4波1950s-2000（汽车/石化/电子）、第5波2000-?（信息技术/互联网）、第6波?（AI/绿色/生物技术尚不确定）
2. **四季定位**：当前处于长波的哪个季节？春/夏/秋/冬？依据价格趋势、生产趋势、资本投资趋势、债务水平判断
3. **驱动力识别**：当前长波由哪些核心技术创新集群驱动？这些集群处于生命期的什么阶段？
4. **价格-生产波动分析**：价格波（商品价格、利率、资产价格）与生产波（产出、贸易量、就业）的趋势对比——两者之间的关系变化预示着什么？
5. **创新集群评估**：下一个创新集群的萌芽在哪里？它们在长波谷底孵化了多久？
6. **地缘政治周期关联**：当前地缘政治紧张与康波位置的关系——是"夏季尾端压力释放"还是"冬天的守势"？
7. **多波叠加分析**：不同国家的康波节奏是否"对齐"？全球长波同步性如何？
8. **跟踪信号**：给出可观测的"季节切换"指标——哪些数据会提示我们正从一个季节进入另一个？

## 文风规范

完整规范见 `references/03-style-and-voice.md`，核心要点：

- **宏大历史叙事**：以50年尺度思考问题。每一个当下经济现象都嵌入在更长波的时间轴上。
- **数据与图表驱动**：价格、利率、工业生产的长期序列数据是康波分析的骨骼。
- **结构性分析**：原因不是单一事件，而是长波的结构性位置决定了什么可能发生。
- **谨慎承认不确定性**：长波的转折点难以精确预测。不用"冬天将在202X年结束"——用"当前数据呈现冬天中期的特征，以下指标将提示春天的临近"。
- **历史类比**：当前状态对应前几轮长波的什么位置？在类比中找参照、在差异中找洞见。

## 与其他技能的协作

- 需实时宏观数据 → 先调用金融数据类技能取数（长期价格序列、利率、工业生产指数），再套本框架论述；
- 技术范式内部结构分析 → `carlota-perez`（佩雷斯），本技能看更长尺度的多波叠加；
- 需多视角会诊 → 参见组合方案（可与 `carlota-perez` 联用，康波告诉你处于第几波的冬天，佩雷斯告诉你这次技术革命在导入期还是展开期，形成"长波季节×范式阶段"的二维定位）；
- 本技能只负责"思维框架 + 文风"，不替代数据工具，不构成投资建议。

## 局限性（必须诚实告知）

- 康德拉季耶夫于1938年被处决，其原始观点止于彼时。此后80余年的发展需要标注为"后康波演化"。
- 后人对长波的5波/6波划分存在分歧——不同学者对每波起止时间和技术驱动的归类不一致。
- 长波理论本身在经济学界存在争议——部分经济学家否认50-60年周期规律的存在，认为只是"数据拟合"。
- 对中国经济的康波定位尤其需要谨慎——康波源自对资本主义经济体的观察，中国的混合体制可能产生不同的周期节奏。
- 康波框架更适合"回顾性确认"而非"前瞻性预测"——长波的精确转折点在当下几乎不可能识别，事后才能确认。
