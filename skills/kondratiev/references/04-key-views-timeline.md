# 04 - 关键观点年表与长波划分史

> 本文件记录康德拉季耶夫生平与思想演进、后人长波划分详表、以及康波理论的后世演化树。所有内容来自公开历史资料。康德拉季耶夫于1938年被处决。

---

## 康德拉季耶夫生平与思想演进

| 年份 | 事件 | 意义 |
|------|------|------|
| 1892.3.4 | 出生于俄罗斯科斯特罗马省 | 农民家庭出身 |
| 1911—1915 | 圣彼得堡大学经济学系学习 | 师从图干-巴拉诺夫斯基等，接触经济周期研究 |
| 1917 | 俄国革命期间短暂参与政治——成为临时政府的粮食供应部副部长 | 实践经历加深了对农业经济和粮食市场的理解 |
| 1919—1920s | 在莫斯科商情研究所开始系统研究经济周期统计数据 | 奠定了长波理论的数据基础 |
| 1920 | 创立莫斯科商情研究所并任所长 | 聚集了一批统计学家研究经济波动 |
| 1922 | 出版《粮食市场及其在战争与革命期间的调节》 | 早期农业市场研究 |
| 1924 | 发表"The Static and Dynamic View of Economics" | 对经济学方法论的独立贡献——区分静态均衡与动态周期分析 |
| 1925 | 出版《长经济周期》（俄文） | **康德拉季耶夫最重要的著作**——系统论证50-60年长波的存在 |
| 1926 | 《长经济周期》德文版发表 | 进入德国学术圈，被熊彼特等人注意到 |
| 1928 | 出版《大经济周期》 | 对长波理论的深化，更多国家数据验证 |
| 1928 | 因与新经济政策（NEP）路线矛盾失去商情研究所所长职位 | 政治压力开始 |
| 1930 | 被苏联政权逮捕 | 罪名："劳动农民党"政治指控——其经济理论与马克思主义关于资本主义"必然崩溃"的论断矛盾 |
| 1932 | 被判处8年监禁，关押于苏兹达尔政治隔离监狱 | 在狱中继续写作经济手稿（多数已失散） |
| 1938.9.17 | 在苏联大清洗中被秘密审判并执行死刑 | 年仅46岁——康德拉季耶夫逝世，其原始观点止于此 |
| 1939 | 熊彼特出版《商业周期》——正式命名"康德拉季耶夫长波" | 康波走向国际学术界 |
| 1987 | 苏联正式平反康德拉季耶夫 | 恢复名誉 |

---

## 后人长波划分详表

> 康德拉季耶夫原始数据仅涵盖第1波和第2波的大部分，以及第3波的早期（约1790-1920）。第3波后半段及第4-6波的划分均为后人的工作，不同学者之间存在分歧。

### 第1波（纺织与蒸汽时代）——1790—1849

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 上升波 | 1790-1815 | 英国工业革命扩散、纺织机械化、蒸汽动力商业化 |
| 上升波-春 | 1790-1800 | 工业革命初期扩散、运河建设 |
| 上升波-夏 | 1800-1815 | 拿破仑战争、欧洲工业产能扩张 |
| 下降波-秋 | 1815-1825 | 战后调整、价格下跌 |
| 下降波-冬 | 1825-1849 | 1825年恐慌、1830s—1840s长期萧条——但也孵化了铁路技术 |

**核心创新**：纺织机械、蒸汽机、冶铁
**基础设施**：运河网起始
**康德拉季耶夫原始验证**：有（基于英国、法国数据）

---

### 第2波（铁路与钢铁时代）——1850—1896

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 上升波-春 | 1850-1855 | 铁路投资恢复、钢铁生产扩张 |
| 上升波-夏 | 1855-1873 | 铁路建设全球化、自由贸易扩张、第二次工业革命扩散 |
| 下降波-秋 | 1873-1880 | 1873年恐慌、Gilded Age的财富集中 |
| 下降波-冬 | 1880-1896 | "长萧条"(Long Depression)、通缩压力——但电力/化工/内燃机在谷底孵化 |

**核心创新**：铁路、蒸汽船、电报、钢铁大规模生产
**基础设施**：全球铁路网、全球电报网
**康德拉季耶夫原始验证**：有（基于英国、法国、美国、德国数据）

---

### 第3波（电力与化工时代）——1897—1940s

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 上升波-春 | 1897-1905 | 电力/汽车/化学工业开始商业化扩散 |
| 上升波-夏 | 1905-1920 | 美好年代尾声 + 第一次世界大战——战争驱动的工业产能扩张 |
| 下降波-秋 | 1920-1929 | 战后调整、'咆哮的二十年代'、经济泡沫 |
| 下降波-冬 | 1929-1940s | 大萧条、二战——历史最大的长波冬季（但电力和汽车技术已在谷底等待展开期） |

**核心创新**：电力、内燃机、化学工业、电话、无线电
**基础设施**：电网、电话网
**康德拉季耶夫原始验证**：部分（康德拉季耶夫原始数据止于1920s之初）

---

### 第4波（汽车与大规模生产时代）——1950s—2000

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 上升波-春 | 1950s | 战后重建、汽车普及、布雷顿森林体系 |
| 上升波-夏 | 1960s-1973 | "黄金时代"——充分就业、增长强劲、福利国家扩张 |
| 下降波-秋 | 1973-1980 | 石油危机、布雷顿森林解体、滞胀 |
| 下降波-冬 | 1980-2000 | 沃尔克紧缩→去通胀、1990sIT早期扩展、亚洲金融危机、LTCM |

**核心创新**：汽车全面普及、石油化工、电子/半导体早期、核能
**基础设施**：全球高速公路网、电网全面扩展、航空网、广播电视网
**康德拉季耶夫原始验证**：无——全部为后人划分（熊彼特/罗斯托/等）

---

### 第5波（信息与互联网时代）——2000—?

| 阶段 | 时间 | 关键事件 | 争议 |
|------|------|---------|------|
| 上升波-春 | 2000-2005? | dot-com泡沫后恢复、移动通信扩张、互联网普及加速 | 是春季还是只是冬季中的反弹？ |
| 上升波-夏 | 2005-2008? | 房地产泡沫、金融化加速、全球增长同步 | 夏极短——仅3-4年 |
| 下降波-秋 | 2008-2015? | 全球金融危机、欧债危机、量化宽松时代开始 | 秋季吗？还是直接入冬？ |
| 下降波-冬 | 2015-? | 低增长、低利率、高债务、贸易冲突、新冠冲击 | 冬天仍在进行中？ |

**关键争议**：
1. **第5波上升波是否只有约8年？** 康波的传统上升波是20-30年，第5波的上升波异常短——是数字化加速了周期节奏，还是我们对2000-2008的"上升波"定位错误（可能只是第4波冬季末的一个反弹）？
2. **2008年后的阶段是第5波的下降波，还是第5波已经完结、第6波已经开始？** 两种说法都有支持者。

**核心创新**：互联网、移动通信、云计算、大数据、AI早期（深度学习）
**基础设施**：全球光纤网络、移动通信基础设施、云计算数据中心
**康德拉季耶夫原始验证**：无——全部为后人划分

---

### 第6波？（AI / 绿色能源 / 生物技术时代）——?—?

**争议点**：
- **支持"第6波正在开始"的论点**：AI成本在快速下降、新能源成本已低于化石能源、生物技术突破加速、多项技术似乎符合"新长波的早期创新集群"特征
- **支持"仍处于第5波下降波"的论点**：数字化转型仍在深化（渗透率尚未饱和）、AI可能只是ICT范式的延伸而非独立新波、全球仍处于2008年金融危机后的长期调整中、缺乏一次"全局性冬天的出清"（央行QE人为压制了出清）

**6波说的潜在创新集群**：AI/AGI、绿色能源与储能、生物技术与基因编辑、量子计算、太空经济（部分）

## 康波理论的后人演化树

```
康德拉季耶夫（1920s）— 原始长波实证发现
│
├─ 熊彼特（1939, Business Cycles）
│   └─ +创新集群理论 → "康德拉季耶夫长波"正式命名
│   └─ +创造性毁灭作为长波机制
│
├─ 门施（Gerhard Mensch, 1970s）
│   └─ +基本创新与长波低谷的统计关联验证
│
├─ 佩雷斯（2002, 技术革命与金融资本）
│   └─ +长波内部结构（导入期/展开期）
│   └─ +金融资本vs生产资本的分离机制
│
├─ 罗斯托（W.W. Rostow, 1970s）
│   └─ +长波与增长的阶段论结合
│
├─ Modelski & Thompson（1990s-2000s）
│   └─ +长波与全球政治-军事周期的对应
│
├─ 周金涛（2000s-2016）
│   └─ 将康波理论引入中国金融市场分析
│   └─ "人生就是一场康波"——普及化
│
└─ 其他后人贡献
    ├─ Andrew Tylecote — 长波与技术变革
    ├─ Chris Freeman/Francisco Louçã — 自工业革命以来的时间序列
    └─ 对冲基金/宏观策略的康波分析实践（如Ray Dalio的长期债务周期）
```

---

> 声明：第3波后半段及第4-6波的划分全部为后人的工作。康德拉季耶夫于1938年被处决，其原始观点止于1920年代的数据分析。不同学者对每波起止时间的划分存在分歧，本表仅提供一种有代表性的划分版本。
