### 框架特点

- **5 个核心框架**：长波周期、四阶段划分、创新集群理论、价格长波与生产长波、战争与革命的周期性。
- **8 步标准工作流**：周期识别 → 四季定位 → 驱动力识别 → 价格-生产波动分析 → 创新集群评估 → 地缘政治周期关联 → 多波叠加分析 → 给跟踪信号。
- **4 条分支路径**：A 快速判断 / B 深度分析 / C 主题提问 / D 四季警戒。
- **康波式文风系统**：宏大历史叙事 + 数据与图表驱动 + 结构性因果分析 + 谨慎不确定性 + 历史类比找参照。
- **完整的合规体系**：AI 模拟声明、投资免责声明、已故人物时间边界声明、后人发展标注要求、长波争议声明。
