# 示例 02：去杠杆路径分析

## 输入

> 判断中国去杠杆能否实现漂亮去杠杆

## 框架选择

- **主框架**：漂亮去杠杆——判断一个高负债经济体如何去杠杆
- **辅助框架**：全天候资产配置——构建稳健的大类资产配置组合
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：去杠杆的四条腿：①债务减记/重组 ②紧缩 ③财富转移(从债权人到债务人) ④印钞/货币化。四条腿的平衡是'漂亮去杠杆'(名义GDP增速>名义利率且避免通胀失控)。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一个高负债经济体如何去杠杆」。按「漂亮去杠杆」走，一共 4 步：

1. **看四条腿各自进度**
2. **判断是否平衡**
3. **失衡→大萧条或通胀失控**
4. **平衡→软着陆**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「漂亮去杠杆」自己的校准例子可以拿来对照：2008年美国：大规模印钞(QE)+部分债务减记+轻度紧缩=漂亮去杠杆。日本1990：只靠超低利率+紧缩迟迟不到位→丑陋去杠杆。

边界必须说清：关键公式：名义GDP增速 > 名义利率 = 去杠杆有序。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按达里奥经济机器模型：中国目前处于长期债务周期的去杠杆阶段——路径取决于当局在减记、紧缩、财富转移和货币化之间如何组合。如果能实现漂亮去杠杆(类似2008年美国)，资产价格可能在短期内重建。

可执行的判断规则（本 SKILL 的输出格式）：

1. 全球宏观定调——三力叠加(生产率+短周期+长周期)
2. 债务周期位置——短期/长期分别在哪
3. 去杠杆路径——是漂亮去杠杆还是丑陋去杠杆
4. 全天候配置——等风险权重的资产建议
5. 最终框架——原则、信号和可能的路径依赖
