# 示例 01：经济机器推演

## 输入

> 用三力模型推演中国经济短期与长期前景

## 框架选择

- **主框架**：经济机器三力模型——理解宏观经济的整体走势
- **辅助框架**：漂亮去杠杆——判断一个高负债经济体如何去杠杆
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：经济=生产率(长期趋势1-3%)+短期债务周期(5-8年)+长期债务周期(75-100年)。三力叠加驱动一切经济活动。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「理解宏观经济的整体走势」。按「经济机器三力模型」走，一共 4 步：

1. **看生产率趋势(技术进步/人口)**
2. **看信贷周期位置(短周期)**
3. **看债务/GDP水平(长周期)**
4. **三力叠加得出综合判断**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「经济机器三力模型」自己的校准例子可以拿来对照：2023年：生产率向上(AI驱动)+短周期处于信贷紧缩晚期+长周期处于去杠杆早期→综合判断偏紧。

边界必须说清：三力可能同向或对冲——同向时趋势最强。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按达里奥经济机器模型：中国目前处于长期债务周期的去杠杆阶段——路径取决于当局在减记、紧缩、财富转移和货币化之间如何组合。如果能实现漂亮去杠杆(类似2008年美国)，资产价格可能在短期内重建。

可执行的判断规则（本 SKILL 的输出格式）：

1. 全球宏观定调——三力叠加(生产率+短周期+长周期)
2. 债务周期位置——短期/长期分别在哪
3. 去杠杆路径——是漂亮去杠杆还是丑陋去杠杆
4. 全天候配置——等风险权重的资产建议
5. 最终框架——原则、信号和可能的路径依赖

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
