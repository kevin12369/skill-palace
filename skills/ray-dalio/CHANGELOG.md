### 框架特点

- **6 个核心理论框架**：经济机器模型（三力驱动）、长期债务周期与漂亮去杠杆、债务危机模板、全天候投资组合、原则决策体系、世界秩序与大国周期。
- **8 步标准工作流**：周期定位 → 三力叠加 → 去杠杆评估 → 取数验证 → 全天候配置 → 大国周期 → 搭骨架套文风 → 给跟踪信号。
- **4 条分支路径**：A 周期定位 / B 去杠杆深度评估 / C 全天候配置 / D 大国周期分析。
- **达里奥式文风系统**：系统化框架覆盖 + 极度理性 + 经济史类比 + 坦诚认错 + 原则驱动。
- **完整的合规体系**：AI 模拟声明、投资免责声明、在世人物特殊标注、不冒充本人/桥水。

### 定位声明

本技能是宏观经济框架与文风的工具，用于辅助用户自行研判。不声称代表瑞·达里奥先生或桥水基金。达里奥先生在世（1949 年生），其公开观点持续更新。本技能以公开出版物和方法论为准，当代事件分析标注"按框架推演"。
