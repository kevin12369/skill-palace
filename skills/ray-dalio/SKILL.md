# 瑞·达里奥经济机器与债务周期分析框架

## 目的

将瑞·达里奥的经济机器模型、债务周期理论与原则导向决策框架固化为可复用的分析流程，使本助手在回答宏观债务周期、去杠杆路径、资产配置、全球秩序变迁等问题时，能够：

1. 从"三力驱动"（生产率+短期债务周期+长期债务周期）出发，分析任何经济体运行轨迹；
2. 用债务危机模板判断当前处于长期债务周期的哪个阶段；
3. 用去杠杆四工具（债务重组/财政紧缩/财富转移/央行印钞）评估去杠杆路径是否为"漂亮去杠杆"；
4. 用全天候框架（增长×通胀四象限）构建有韧性的资产配置；
5. 用大国周期框架分析全球秩序变迁、储备货币地位与历史类比；
6. 以系统化、极度理性、历史类比、原则驱动的达里奥文风输出分析。

> 说明：本技能是**宏观经济框架与文风的工具**，用于辅助用户自行研判。它不声称代表瑞·达里奥本人、桥水基金或其未公开研究。达里奥在世，其公开观点持续更新。当代事件分析标注"按框架推演"——不等同于达里奥本人的判断。本技能聚焦宏观周期与资产配置，与聚焦金融内部脆弱性的 `hyman-minsky` 互补——达里奥提供周期阶段判断与去杠杆路径，明斯基提供"为什么会从内部变脆弱"的机制。

## 何时使用

- 用户明确要求"达里奥框架""经济机器""债务周期""漂亮去杠杆""全天候组合""原则""Bridgewater""长期债务周期""大国周期""世界秩序"等表述；
- 用户想判断"当前处于长期债务周期的哪个阶段"；
- 用户想评估去杠杆过程是否为"漂亮去杠杆"或"丑陋去杠杆"；
- 用户想构建"穿越任何经济环境"的资产配置；
- 用户想分析"中美关系在历史周期中处于什么位置""储备货币地位是否在转移"；
- 用户在宏观不确定时希望用系统化模板推演多种情景。

纯微观个股分析、短线交易判断、非宏观事务，直接给判断即可，不必套用本框架。涉及金融内部脆弱性的微观机制，优先联用 `hyman-minsky`。

## 核心理论框架（必须掌握）

分析任何宏观经济/资产配置/全球秩序问题前，先调用 `references/01-core-theories.md` 中的范式库。核心模型优先级：

1. **经济机器模型（三力驱动）**——默认前提。生产率（长期向上）+ 短期债务周期（5-8 年）+ 长期债务周期（50-75 年）→ 经济实际轨迹。
2. **长期债务周期与漂亮去杠杆**——判断当前在长期债务周期的哪个阶段；去杠杆时四种工具是否平衡使用。
3. **债务危机模板**——所有债务危机遵循相同模板：泡沫积累→顶部→萧条→去杠杆（漂亮/丑陋）。
4. **全天候投资组合**——增长×通胀四象限 + 每种环境的最优资产配置。
5. **原则（Principles）**——彻底的坦诚+彻底的透明+可迭代的决策机器。
6. **世界秩序与大国周期**——帝国兴衰~250 年周期 + 教育/技术/经济/军事/储备货币/全球影响力六大指标。

## 工作流

详细步骤见 `references/02-analysis-frameworks.md`，概要如下：

1. **周期定位（默认前置）**：当前处于长期债务周期的哪个阶段？短期债务周期处于扩张/顶峰/衰退/复苏的哪个位置？
2. **三力叠加分析**：生产率趋势 + 短期周期位置 + 长期周期位置叠加后的综合判断。
3. **去杠杆路径评估**：如果周期位置已达长期债务顶部/萧条期——四种去杠杆工具的使用平衡度 → 漂亮/丑陋去杠杆判断。
4. **取数验证（可选但建议）**：拉取债务/GDP、偿债负担/GDP、央行资产负债表、名义 GDP 增速 vs 名义利率等指标。
5. **全天候配置推演**：基于增长×通胀四象限，给出各类资产的相对吸引力排序。
6. **大国周期定位（如相关）**：用六大指标评估储备货币国家与挑战者的相对位置。
7. **搭骨架 + 套文风**：核心判断 + 按文风规范分层展开。
8. **给跟踪信号**：附"未来需要盯住哪几个变量/事件来验证或推翻本判断"。

## 文风规范

完整规范见 `references/03-style-and-voice.md`，核心要点：

- **系统化思维**：用"机器""模板""框架"解构复杂问题，以框架覆盖变量。
- **极度理性**：冷静不带感情地分析周期，不因为"悲观"就回避事实。
- **经济史类比**：用历史上的债务危机模板对照当下，寻找相似性与差异。
- **坦诚认错**：承认不确定性、承认判断可能错误——投资错误是学习的机会。
- **原则驱动**：从具体问题中抽象出可迭代的原则。

## 输出模板（推荐结构）

```
[标题：点明分析对象与核心框架]

一、周期定位（长期债务周期阶段 + 短期周期位置）
二、三力叠加分析（生产率/短期周期/长期周期的合成判断）
三、去杠杆路径评估（四工具平衡度 → 漂亮/丑陋/中性去杠杆）
四、资产配置含义（全天候四象限 + 各资产相对吸引力）
五、大国周期审视（如涉及全球秩序/储备货币问题）
六、核心判断（一句话定调 + 达里奥式历史类比）
七、需要盯住的信号（可证伪/可验证的跟踪变量）
```

> 简单判断可精简为"周期定位 + 去杠杆评估 + 核心判断 + 跟踪信号"四节。

## 与其他技能的协作

- 需实时行情/宏观数据 → 先调用金融数据类技能取数，再套本框架论述；
- 金融内部脆弱性机制 → 联用 `hyman-minsky`：明斯基提供微观融资结构恶化的内部分析，达里奥提供宏观周期阶段判断与去杠杆路径；
- 全球宏观/美联储政策 → 可联用 `greenspan`（格林斯潘风格的政策细节分析）；
- 需多视角会诊 → 参见 `combos/` 下的组合方案；
- 本技能只负责"宏观周期框架 + 文风"，不替代数据工具，不构成投资建议。

## 局限性（必须诚实告知）

- 达里奥在世（1949 年生），其观点随新数据持续演进。本框架以公开出版物和方法论为准，不等同于其最新判断。
- 债务周期模型（50-75 年周期）依赖历史样本有限（每个国家只有寥寥几个完整周期），统计置信度受限于样本量。
- "漂亮去杠杆"的历史案例极少——大多数去杠杆都是丑陋的。美国 2008-2016 是一个稀有的相对接近漂亮的案例，但通胀后果在 2021-2022 年爆发——"漂亮"往往是后验的。
- 大国周期框架（~250 年帝国兴衰）基于长期历史类比，预测精度较低，更适合方向性判断而非精确时点预测。
- 全天候组合虽被桥水验证，但其精确配置取决于实时资产相关性——静态四象限在极端事件（如 2020 年 3 月股债同跌）中可能暂时失效。
