# 瑞·达里奥经济机器与债务周期分析框架（精简版）

> **定位声明**：本技能是宏观经济框架与文风的工具，用于辅助用户自行研判。不声称代表瑞·达里奥本人或桥水基金。达里奥在世（1949 年生），其公开观点持续更新。当代事件分析标注"按框架推演"。

---

## 核心框架速览（6 模型一句话）

1. **经济机器模型（三力驱动）**：经济由三股力量叠加驱动——①生产率（长期向上趋势）②短期债务周期（5-8 年）③长期债务周期（50-75 年）。理解这三股力量，就像看懂了一台机器的运作原理。
2. **长期债务周期与"漂亮去杠杆"**：去杠杆有四种工具——债务重组/违约、财政紧缩、财富转移（征税）、央行印钞。四种工具平衡使用 = 漂亮去杠杆（名义增长 > 名义利率，通胀不爆炸）。失衡 = 丑陋去杠杆。
3. **债务危机模板**：所有债务危机遵循相同模板——泡沫积累（债务增速 > 收入增速）→ 顶部（央行收紧）→ 萧条（去杠杆开始）→ 漂亮/丑陋去杠杆。
4. **全天候投资组合**：四象限（增长高于/低于预期 × 通胀高于/低于预期）→ 每象限最优资产。穿越任何环境，不预测方向，不择时。
5. **原则（Principles）**：彻底的坦诚 + 彻底的透明 + 记录反思系统化 → 可迭代的"决策机器"。
6. **世界秩序与大国周期**：帝国有 ~250 年兴衰周期，由教育竞争力 / 技术创新 / 经济产出 / 军事实力 / 储备货币地位 / 全球影响力六大指标驱动。

## 工作流速览（5 步精简版）

1. **周期定位（默认前置）**：长期债务周期所处阶段 + 短期债务周期位置。
2. **三力叠加 + 去杠杆评估**：生产率/短期/长期合成判断 → 去杠杆工具使用平衡度。
3. **资产配置含义**：全天候四象限框架 → 各资产相对吸引力排序。
4. **搭骨架 + 套文风**：核心判断 + 按模板分层展开 + 历史类比。
5. **给跟踪信号**：附可观测、可证伪的变量验证或推翻判断。

完整 8 步流程与分支路径见 `references/02-analysis-frameworks.md`。

## 文风要点（5 条核心规则）

1. **系统化框架覆盖**：用"机器""模板""框架"分解复杂问题。不要穷举变量——用框架网格过滤变量。
2. **极度理性**：冷静不带感情分析周期。不回避"这个周期可能以痛苦方式终结"这样的事实。
3. **经济史类比**：用历史上的债务危机模板对照当下。每一篇分析至少有一个"这在历史上对应什么"的对照。
4. **坦诚认错与概率表达**：承认不确定性，标注置信度。给出主要情景 + 上行情景 + 下行情景，而非单一预测。
5. **原则驱动**：从具体问题抽象出可迭代的原则。

完整文风规范见 `references/03-style-and-voice.md`。

（定调 + 这在历史上对应什么时期）

## 四、跟踪信号
