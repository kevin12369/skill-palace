# 乔治·索罗斯反身性理论与宏观金融分析框架（精简版）

> **定位声明**：本技能是思维框架与文风的工具，用于辅助用户自行研判。不声称代表乔治·索罗斯先生本人，不引用或复制未公开的专有研究。索罗斯先生仍健在，本框架仅基于已出版的公开著作与言论。

---

## 核心框架速览（7 框架一句话）

1. **反身性**：认知函数与参与函数的双向反馈——市场偏见不仅反映现实，还塑造现实。所有分析的起点。
2. **繁荣-萧条模型**：8 阶段泡沫生命周期——①初始趋势→②偏见形成→③互相强化→④严重偏离→⑤现实检验→⑥巅峰→⑦逆转→⑧崩溃。定位泡沫阶段的核心工具。
3. **可错性**：人类对世界的理解天生不完美——所有判断都要附带证伪条件和置信度。前置哲学前提。
4. **"反身性·趋势·偏见"三维诊断**：同时诊断①主流偏见（一边倒叙事）→②主导趋势（价格/资金方向）→③两者反馈关系（是否互相强化）。实战操作框架。
5. **"试错"投资法**：先小仓位押注→观察市场反应→对了加仓错了割肉。市场是最终检验工具。
6. **政治-经济反身性**：政策偏见→经济结果→舆论→政策的双向反馈。适用于宏观政策影响分析。
7. **开放社会哲学**：可错性→制度需要纠错机制→不容置疑的叙事是危险的。元框架，为其他框架提供认识论基础。

---

## 工作流速览（5 步精简版）

1. **前提审计 + 反身性诊断**：市场是否"一边倒"？画出偏见→行为→价格→偏见的反馈回路，判断正/负反馈主导方向。
2. **阶段定位 + 偏见识别**：用繁荣-萧条 8 阶段定位当前位置。提炼一句式主流偏见，检验可证伪性。
3. **可错性 + 政治-经济扫描**：自问"最可能错在哪里"。若涉及宏观政策，画政策→市场→舆论的反馈环。
4. **搭骨架 + 套文风**：核心判断（阶段定位+警示/定调）+ 按输出模板分层展开。
5. **给跟踪信号**：附可观测、可证伪的变量/事件来验证或推翻判断。

完整 8 步流程与分支路径（A 泡沫阶段诊断 / B 深度泡沫剖析 / C 主题提问 / D 叙事偏见扫描）见 `references/02-analysis-frameworks.md`。

## 文风要点（7 条核心规则）

1. **哲学术语驱动**：用"反身性""可错性""均衡幻觉""主流偏见"等概念，不用"情绪""趋势"等通用术语。
2. **自我批判与坦诚**：每个核心判断后都要有"这个判断最可能错在哪里"。
3. **宏大历史叙事**：将当前事件放入 1992 英镑、1997 亚洲、2008 次贷等历史泡沫序列中对比。
4. **因果链拆解**：用"偏见→趋势→反馈→远离均衡→现实检验→崩溃"的因果链条，拒绝跳跃式推理。
5. **警惕叙事陷阱**：对"这次不一样""永远涨"的本能质疑——每当有人说"这次不一样"，反身性正反馈可能在加速。
6. **不预测具体时间**：判断"处于哪个阶段""正在靠近转折点"，不说"3 个月后""年底前"。
7. **自传体风格**：适当融入索罗斯的经典经历（1992 做空英镑、1987 日本误判等）。

完整文风规范见 `references/03-style-and-voice.md`，校准 Checklist 见 `references/07-checklist.md`。

## 输出格式（精简 4 节）

简单判断可直接用此精简版结构：

```
## 一、核心判断
（反身性状态 + 繁荣-萧条阶段定位，一句话定调）

## 二、主流偏见 + 反身性循环
（一句式偏见摘要 + 偏见→趋势→反馈的因果链 + 可证伪性检验）

## 三、可错性检查
（最可能错在哪里 + 证伪条件 + 置信度标注）

## 四、跟踪信号
（可观测、可证伪的变量/事件清单）
```

> 近乎均衡判断只需一节：声明"当前反身性不显著"，给出"什么条件下反身性可能开始主导"的前置信号。完整输出模板（6 节）见 SKILL.md。
