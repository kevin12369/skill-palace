# 02 - 分析框架工作流

> 本文件定义基于乔治·索罗斯方法论的分析工作流与分支路径。所有流程均为索罗斯公开来源方法论的整理，用于辅助研判，不代表索罗斯先生本人或其未公开观点。

---

## 标准工作流（8 步）

以下为完整分析的标准步骤。简单决策见下方分支路径表。

### 第 1 步：前提审计

**核心操作**：在进入反身性分析前，先检查前提条件——

**自问三问**：
1. 我是否已将可错性原则内化？（我承认我的判断可能错误）
2. 当前市场的舆论是否已出现"一边倒"？（如果舆论分歧充分，反身性可能不显著）
3. 我能否识别出市场上至少一个主流偏见？

**判断结果**：
- 三个都是 → 继续
- 任一不是 → 反身性框架可能不适用于当前场景，声明并简化分析
- 找不到主流偏见 → 市场可能处于索罗斯所说的"近乎均衡"状态，无需过度分析

> 在近乎均衡状态中，价格和基本面之间有合理的反馈机制。强行套用反身性框架等于无病呻吟。

### 第 2 步：反身性循环诊断

**核心操作**：画出一个完整的反身性循环图。

**步骤**：
1. **识别认知函数**：市场参与者对标的的核心叙事是什么？
2. **识别参与函数**：这种偏见如何驱动买卖行为？
3. **描述反馈回路**：
   - 正反馈：偏见→买入→价格↑→强化偏见→更多买入
   - 负反馈：价格↑→怀疑→抛售→价格↓→修正偏见
4. **判断主导方向**：
   - 正反馈主导 → 远离均衡，继续第 3 步
   - 正负反馈平衡 → 近乎均衡，泡沫风险低
   - 负反馈主导 → 可能已在崩溃中，跳至第 7 步

### 第 3 步：繁荣-萧条阶段定位

**核心操作**：用 8 阶段模型定位当前所处的具体阶段。

**阶段诊断清单**：
| 诊断问题 | 对应阶段 |
|---------|---------|
| 趋势刚开始，大多数人还不相信？ | ① 初始趋势 |
| "这次不一样"叙事出现，但估值尚未离谱？ | ② 偏见形成 |
| 价格上涨验证偏见，偏见推动更多买入？ | ③ 互相强化 |
| 估值脱离所有历史锚定，"新范式"叙事盛行？ | ④ 严重偏离 |
| 第一次负面事件出现，市场回调后迅速修复？ | ⑤ 现实检验 |
| 最后一波狂热涌入，内部人开始减仓？ | ⑥ 巅峰时刻 |
| 下跌引发抛售，抛售引发更多下跌？ | ⑦ 逆转 |
| 价格崩溃，偏见彻底瓦解？ | ⑧ 崩溃 |

### 第 4 步：主流偏见识别

**核心操作**：深入剖析"市场上所有人都在相信什么"。

**步骤**：
1. **用一句话概括当前主流偏见**
2. **检验偏见的可证伪性**：在什么条件下这个偏见会被证伪？如果找不到可证伪条件，该偏见极其危险
3. **寻找反面证据**：刻意搜索不支持主流偏见的证据（达尔文协议）
4. **评估偏见的稳定性**：偏见的基础是"事实"还是"别人的行为"？"别人都在买所以我买"的偏见最不稳定

### 第 5 步：可错性检查

**核心操作**：强制检查自身判断的可错性。

**步骤**：
1. **自问**：
   - 我的判断最可能错在哪里？
   - 有没有关键假设一旦被推翻，后续逻辑全部崩溃？
   - 我有没有因为仓位/立场/声誉而不愿看到某些反面证据？
2. **设计证伪条件**：列出 2-3 个具体、可观测的事件，一旦出现即推翻本判断
3. **标注置信度**：对每个关键判断标注高/中/低置信度

> 索罗斯："我犯过很多错误。关键在于犯错时亏了多少，而不是对了几次。"

### 第 6 步：政治-经济反身性扫描（可选）

**触发条件**：分析涉及宏观政策、国际关系、监管变化时触发。

**操作**：
1. 画政策→市场→舆论→政策的反馈环
2. 判断政策制定者对市场反馈的敏感度
3. 识别政策"不得不转向"的临界条件

### 第 7 步：试错投资法校验

**核心操作**：基于以上分析，输出试错式行动建议。

**步骤**：
1. **提炼可检验假设**：不超过两句话
2. **设计试错方案**：
   - 先建多少仓位试探？
   - 什么市场反应证明假设正确→加仓？
   - 什么市场反应证明假设错误→止损？
3. **设定退出条件**：不仅是"亏了多少"才退出，更是"什么证据出现"才退出

### 第 8 步：搭骨架 + 套文风 + 跟踪信号

**核心操作**：将前述分析转化为结构化输出。

**输出结构**（详见 SKILL.md 输出模板）：
1. 核心判断（反身性状态 + 繁荣-萧条阶段定位）
2. 反身性循环图（偏见→趋势→反馈的逻辑链条）
3. 主流偏见剖析
4. 可错性检查（证伪条件）
5. 试错行动建议
6. 需要盯住的信号

**文风要求**（详见 `03-style-and-voice.md`）：
- 哲学术语驱动
- 自我批判与坦诚
- 宏大历史叙事
- 因果链拆解
- 警惕叙事陷阱
- 不预测具体时间
- 自传体风格交织

|------|---------|---------|------|
| **A·泡沫阶段诊断** | "AI 是不是泡沫""这个板块到哪了"——快速定位 | 仅 SKILL.md，重点加载 01 之框架 2、3 | 三元诊断（偏见→趋势→反馈）+ 8 阶段定位。判断是否远离均衡，离转折点还有多远。 |

| **D·叙事偏见扫描** | 市场一边倒叙事——需要拆解叙事偏见 | 01（框架 1、2、4）+ 07 checklist | 以主流偏见识别和反身性反馈诊断为重心。判断当前叙事是否构成"均衡幻觉"，用可错性检验。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 是具体概念/理论问题？
  │    └─ 是 → C·主题提问：加载相关理论，定点回答
  │
  ├─ 市场/板块是否已狂热/一边倒？
  │    └─ 是 → 先走 A·泡沫阶段诊断（快速定位），如判断值得深入→ B·深度泡沫剖析
  │
  ├─ 用户关注的是叙事/"大家都不相信会跌"？
  │    └─ 是 → D·叙事偏见扫描：拆解主流偏见
  │
  └─ 用户需要完整泡沫分析？
       └─ 是 → B·深度泡沫剖析（全流程 8 步）
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 8 步流程**：重大泡沫判断、资产配置决策、系统性风险评估
- **精简流程（核心 4 步）**：日常观察、初步定位、简单判断
  1. 反身性循环诊断
  2. 繁荣-萧条阶段定位
  3. 主流偏见识别
  4. 跟踪信号

### 近乎均衡的处理

当判断市场处于近乎均衡状态（反身性不显著）时：
- 声明"当前市场不适用反身性框架——价格与基本面之间存在合理的反馈机制"
- 不做过度分析
- 可以给"在什么条件下反身性可能开始主导"的前置信号

> 索罗斯自己说过，反身性只在"远离均衡"时最重要。大部分时间市场是近乎均衡的，强行套用框架只会造成分析噪音。

### 转折点判断的诚实性

索罗斯强调："我不预测转折点的具体时间。"本框架分析转折点时应：
- 识别"前置信号"（趋势减速、偏见仍在加速、内部人减仓等）
- 不给具体日期或时间窗口
- 强调"正在靠近"而非"已经到达"——转折点只能在事后确认
