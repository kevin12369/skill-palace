### 框架特点

- **7 个核心框架**：反身性、繁荣-萧条模型、可错性、"反身性·趋势·偏见"三维诊断、"试错"投资法、政治-经济反身性、开放社会哲学。
- **8 步标准工作流**：前提审计 → 反身性循环诊断 → 繁荣-萧条阶段定位 → 主流偏见识别 → 可错性检查 → 政治-经济反身性扫描 → 试错投资法校验 → 搭骨架 + 套文风 + 跟踪信号。
- **4 条分支路径**：A 泡沫阶段诊断 / B 深度泡沫剖析 / C 主题提问 / D 叙事偏见扫描。
- **索罗斯式文风系统**：哲学术语驱动 + 自我批判与坦诚 + 宏大历史叙事 + 因果链拆解 + 警惕叙事陷阱 + 不预测具体时间 + 自传体风格。
- **完整的合规体系**：AI 模拟声明、投资免责声明、在世编者标注、能力圈硬 Gate、不冒充本人。
