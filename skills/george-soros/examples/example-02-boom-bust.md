# 示例 02：繁荣-萧条定位

## 输入

> 用8步模型判断一个行情的周期位置

## 框架选择

- **主框架**：繁荣-萧条序列——判断一场泡沫化的行情走到了哪一步
- **辅助框架**：可错性——所有投资分析的基本前提
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：典型的8步：①未被认识到的趋势→②趋势加速→③成功检验→④主流偏见增强→⑤偏离加大→⑥质疑出现→⑦临界点→⑧加速逆转。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一场泡沫化的行情走到了哪一步」。按「繁荣-萧条序列」走，一共 4 步：

1. **数一数行情持续了多久**
2. **看主流偏见的强度**
3. **听'这次不一样'的出现频率**
4. **找反方声音被边缘化的证据**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「繁荣-萧条序列」自己的校准例子可以拿来对照：2021年SPAC狂潮：没人质疑估值→大量散户买入→2022年SPAC崩溃。

边界必须说清：序列的形状(斜率/幅度/时长)因标的而异，但逻辑结构高度重复。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按索罗斯框架：当前AI板块的叙事正在自我强化——价格上涨强化'AI改变一切'叙事，叙事再吸引更多资金——这已是繁荣阶段的典型反身性特征。

可执行的判断规则（本 SKILL 的输出格式）：

1. 反身性判断——当前有没有正反馈环在运作
2. 主流偏见——市场共识是什么，为什么它可能是错的
3. 繁荣-萧条位置——处于序列的哪一步
4. 临界点信号——什么会触发逆转
5. 最终判断——投机还是观望

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
