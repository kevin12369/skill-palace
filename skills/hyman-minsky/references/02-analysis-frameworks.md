# 02 - 分析框架工作流

> 本文件定义基于海曼·明斯基金融不稳定假说的分析工作流与分支路径。所有流程均为明斯基公开来源方法论的整理，用于辅助研判，不代表明斯基本人或其未公开观点。

---

## 标准工作流（8 步）

以下为完整分析的标准步骤。简单评估见下方分支路径表。

### 第 1 步：融资结构诊断（默认前置）

**核心操作**：对分析对象进行三种融资结构分类——

**具体指标**（详见 `01-core-theories.md` 理论 2）：

| 指标 | 对冲融资 | 投机融资 | 庞氏融资 |
|------|---------|---------|---------|
| 利息覆盖率 | > 2.0 倍 | 1.0-2.0 倍 | < 1.0 倍 |
| 债务/EBITDA | < 3.0 倍 | 3.0-6.0 倍 | > 6.0 倍 |
| LTV | < 60% | 60%-85% | > 85% |

**核心产出**：
- 三类融资的大致比例分布
- 与历史基准的偏差（5 年/10 年前是多少？）
- 演化方向（对冲 → 投机 → 庞氏的方向和速度？）

> 融资结构诊断是默认前置的、不可跳过的第一步。没有融资结构分类，后续所有判断都缺基础。

### 第 2 步：脆弱性评估

**核心操作**：基于融资结构分布判断系统性风险等级——

**脆弱性五级评估表**：

| 等级 | 特征 | 标志 |
|------|------|------|
| **1 级：稳健** | 对冲融资占绝对主导（>70%），庞氏 < 5% | 利息覆盖率普遍 > 2.0 |
| **2 级：偏稳健** | 对冲 > 50%，投机 30-40%，庞氏 < 10% | 投机融资在上升但可控 |
| **3 级：脆弱** | 投机融资 > 40%，庞氏 10-20% | 投机融资比例持续上升超过 3 年 |
| **4 级：高度脆弱** | 庞氏融资 > 20%，利率敏感度高 | 大量经济主体靠展期/资产升值维生 |
| **5 级：临界** | 庞氏 > 30%，触发事件高度迫近 | 融资结构已达历史危机前可比水平 |

**判断结果**：
- 1-2 级 → 较低关注，继续监控演化方向
- 3 级 → 中度警惕，进入触发机制识别
- 4-5 级 → 高度警惕，完整 8 步流程展开

### 第 3 步：触发机制识别

**核心操作**：明斯基时刻五步触发协议（详见 `01-core-theories.md` 理论 3）

1. **识别庞氏融资者**：哪些主体/行业/市场存在显著庞氏特征？
2. **识别抛售触发事件**：利率上升？资产价格回落？银行抽贷？评级下调？外部冲击？
3. **绘制传导链**：抛售 → 抵押品贬值 → 银行追缴/抽贷 → 更多抛售 → 流动性枯竭
4. **评估流动性缓冲**：央行/市场做市商是否有足够能力吸收抛售？
5. **评估紧迫度**：当前离临界点有多远？

**触发事件评分矩阵**（1-5 分，分数越高越危险）：

| 触发源 | 当前状态 | 危险评分 | 变化方向 |
|--------|---------|---------|---------|
| 利率 | 当前水平 | 1-5 | 上升/下降/持平 |
| 资产价格 | 偏离合理估值幅度 | 1-5 | 加速/减速/见顶 |
| 信贷标准 | 紧缩/宽松程度 | 1-5 | 收紧/放松 |
| 外部冲击概率 | 战争/贸易/疫情/地缘 | 1-5 | 上升/下降 |
| 监管变化 | 去杠杆/改革力度 | 1-5 | 趋严/趋松 |

### 第 4 步：取数验证（可选但建议）

**核心操作**：拉取以下数据以校验框架判断：

- 宏观杠杆率（债务/GDP、私人部门杠杆率）
- 利息覆盖率分布（各行业/各规模企业）
- 不良贷款率与拨备覆盖率
- 资产价格偏离度（股市 CAPE/市净率 vs 历史均值、房价收入比/租售比）
- 央行资产负债表与流动性注入规模

**若数据无法获取**：声明"以下为框架性推演，缺乏实时数据校验。实际决策前应补充数据验证。"

### 第 5 步：稳定器分析

**核心操作**：评估"大政府+大央行"的响应能力与悖论——

1. **大政府自动稳定器**：当前赤字/GDP 的自动扩张空间？财政空间是否已被高债务压缩？
2. **大央行最后贷款人**：央行是否有足够空间降息/扩表？流动性工具的覆盖范围？
3. **悖论评估**：当前稳定器是否已经在制造下一轮脆弱？（零利率 → 杠杆上升、QE → 资产泡沫、财政刺激 → 通胀）
4. **与历史对比**：当前稳定器规模 vs 2008 年 vs 2020 年的对比

### 第 6 步：二价格传导分析

**核心操作**：评估资本资产价格波动→实体经济的冲击渠道（详见 `01-core-theories.md` 理论 5）

1. **财富效应**：股市/房价下跌幅度 × 家庭金融资产占比 → 消费减少估算
2. **抵押品渠道**：资产价格下跌 → 银行抵押品减值 → 抽贷/惜贷 → 企业投资收缩
3. **识别最脆弱环节**：高杠杆家庭？中小银行？地产产业链？影子银行？

### 第 7 步：搭骨架 + 套文风

**核心操作**：将前述分析转化为结构化输出。

**输出结构**（详见 SKILL.md 输出模板）：
1. 融资结构诊断（三类融资比例 + 演化方向）
2. 脆弱性评估（系统性风险等级）
3. 明斯基时刻触发条件（触发事件 + 传导路径）
4. 稳定器分析（大政府+大央行响应 + 悖论）
5. 二价格传导（资本资产 → 实体经济的冲击渠道）
6. 核心判断（一句话定调 + 机制解构）
7. 需要盯住的信号

**文风要求**（详见 `03-style-and-voice.md`）：
- 学术犀利：论述紧凑，不卖弄学术腔
- 机制解构：因果链拆解，不堆砌现象描述
- 周期敏感：繁荣中逆向审慎，恐慌中预判稳定器
- 批判性视角：指出主流共识忽略的金融不稳定性

### 第 8 步：给跟踪信号

**核心操作**：附"未来需要盯住哪几个变量/事件来验证或推翻本判断"。

**有效跟踪信号的特征**：
- 可观测（不是"市场情绪恶化"，而是"利息覆盖率中位数跌破 1.5"）
- 可证伪（明确指出在什么条件下本判断被推翻）
- 有时限（不是"总有一天"，而是"6-12 个月内"）

**格式**：

| 跟踪变量 | 当前状态 | 恶化警戒线 | 推翻本判断的信号 |
|---------|---------|----------|---------------|
| 利息覆盖率中位数 | 当前值 | 跌破 X | 回到 Y 以上持续 Z 季 |
| 庞氏融资占比 | 当前值 | 超过 X% | 回落至 Y% 以下 |
| 央行政策利率 | 当前水平 | 上升至 X% | 大幅下调至 Y% |
| 资产价格偏离度 | 当前值 | 偏离超过 X% | 回归至 Y% |

## 分支路径表

| 路径 | 适用场景 | 加载文件 | 简述 |
|------|---------|---------|------|
| **A·融资结构诊断** | 初步评估某个市场/行业的债务健康度 | 仅 SKILL.md，无需加载额外文件 | 三种融资分类 + 演化方向判断。两步给出健康度评级。 |
| **B·系统性风险评估** | 全面评估整个金融系统或多市场的脆弱性 | 01 + 03 + 07 | 完整 8 步展开，从融资分类到跟踪信号。适用于重大系统性风险研判。 |
| **C·危机触发分析** | 已知脆弱性较高，评估明斯基时刻的触发条件和紧迫度 | 01（理论 2 融资结构 + 理论 3 明斯基时刻） | 聚焦第 2-3 步，深度分析触发机制、传导路径、流动性缓冲。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 希望评估特定市场的债务健康度？
  │    └─ 是 → A·融资结构诊断：三类分类 + 演化方向
  │
  ├─ 希望全面评估系统性风险？
  │    └─ 是 → B·系统性风险评估：完整 8 步展开
  │
  ├─ 已知系统脆弱，关注崩溃触发？
  │    └─ 是 → C·危机触发分析：触发协议 + 传导链 + 缓冲评估
  │
  └─ 纯数据查询？
       └─ 直接给数据，不套框架
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 8 步流程**：重大系统性金融风险评估、多市场脆弱性联动分析、危机预警研报
- **精简流程（核心 4 步）**：单一市场/行业融资结构快速诊断
  1. 融资结构诊断
  2. 脆弱性评级
  3. 核心判断
  4. 跟踪信号

### 取数步骤的处理

- 有数据工具可用：执行第 4 步取数，将数据整合到脆弱性评级和触发机制分析中
- 无数据工具：跳过第 4 步，在输出开头声明"以下为框架性推演，缺乏实时数据校验"
- 取数结果与框架判断冲突：以数据为准修改判断——明斯基不会为了维护框架而忽视事实

### 脆弱性评级的使用

- 脆弱性评级是分析结论的定性总结，不是精确度量
- 评级升级或降级本身就是重要信号（从 3 级升至 4 级比始终在 4 级更需要关注）
- 不同市场/行业的评级不可直接比较——中国地产的 4 级和美国科技股的 3 级有完全不同的结构和传导含义

## 明斯基与费雪的工作流衔接

当融资结构诊断发现庞氏融资比例已达高危且触发事件临近时：

1. 先用明斯基框架分析**上半场**：脆弱性积累 → 触发 → 崩溃
2. 然后在崩溃后的分析中切换到费雪框架分析**下半场**：抛售 → 通缩 → 实际债务上升 → 更多抛售 → 更多通缩

**衔接点**：明斯基的"明斯基时刻"（崩溃开始）= 费雪的"债务通缩螺旋启动"。见 `irving-fisher` 技能的触发条件。
