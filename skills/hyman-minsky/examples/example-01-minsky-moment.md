# 示例 01：明斯基时刻预警

## 输入

> 用融资结构诊断当前系统性风险

## 框架选择

- **主框架**：金融不稳定假说——在经济繁荣期诊断金融脆弱性
- **辅助框架**：稳定性孕育不稳定性——在看似平稳的市场中寻找风险
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：资本主义经济运行内生出金融脆弱性——繁荣期越长，投机和庞氏融资比例越高，系统越脆弱。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「在经济繁荣期诊断金融脆弱性」。按「金融不稳定假说」走，一共 4 步：

1. **判断融资结构(对冲/投机/庞氏)**
2. **看哪种结构在扩张**
3. **评估连锁违约风险**
4. **定位最脆弱的环节**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「金融不稳定假说」自己的校准例子可以拿来对照：2008年：次贷的庞氏特征(靠房价续涨来维持) + 信用衍生品的连锁反应。

边界必须说清：对冲融资是健康的，投机融资需警惕，庞氏融资是定时炸弹。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按明斯基框架：当前低波动环境已经持续了两年，信用利差收窄到历史低位——这正是稳定性在孕育不稳定性的典型阶段。不是会不会出问题，而是在哪个环节先暴露。

可执行的判断规则（本 SKILL 的输出格式）：

1. 融资结构诊断——对冲/投机/庞氏各占多少
2. 脆弱性累积——哪个部门/环节最脆弱
3. 明斯基时刻风险——触发因素可能是什么
4. 传导机制——危机如何扩散
5. 政策与应对——最后贷款人会怎么反应

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
