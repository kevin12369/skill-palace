# 示例 02：稳定孕不稳定

## 输入

> 识别长期低波动环境下的脆弱性积累

## 框架选择

- **主框架**：稳定性孕育不稳定性——在看似平稳的市场中寻找风险
- **辅助框架**：三阶段融资分类（对冲 / 投机 / 庞氏）——体检一个经济体或一个行业的杠杆质量
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：长期稳定=低波动+低风险溢价→参与者增加杠杆→市场变得脆弱→下一场危机的土壤。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「在看似平稳的市场中寻找风险」。按「稳定性孕育不稳定性」走，一共 3 步：

1. **计算市场稳定持续的时间**
2. **看杠杆率和风险承担行为是否上升**
3. **看监管是否在放松(被'稳定'麻痹)**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「稳定性孕育不稳定性」自己的校准例子可以拿来对照：2003-2007的低波动环境和宽松信贷，直接孕育了2008危机。

边界必须说清：这一规律让明斯基在每一轮繁荣期都显得'过度悲观'——直到衰退来临。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按明斯基框架：当前低波动环境已经持续了两年，信用利差收窄到历史低位——这正是稳定性在孕育不稳定性的典型阶段。不是会不会出问题，而是在哪个环节先暴露。

可执行的判断规则（本 SKILL 的输出格式）：

1. 融资结构诊断——对冲/投机/庞氏各占多少
2. 脆弱性累积——哪个部门/环节最脆弱
3. 明斯基时刻风险——触发因素可能是什么
4. 传导机制——危机如何扩散
5. 政策与应对——最后贷款人会怎么反应

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
