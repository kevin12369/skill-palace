### 框架特点

- **6 个核心理论框架**：金融不稳定假说、三种融资结构、明斯基时刻、"大政府+大央行"稳定器、二价格体系、就业作为稳定锚。
- **8 步标准工作流**：融资结构诊断 → 脆弱性评估 → 触发机制识别 → 取数验证 → 稳定器分析 → 二价格传导 → 搭骨架套文风 → 给跟踪信号。
- **3 条分支路径**：A 融资结构诊断 / B 系统性风险评估 / C 危机触发分析。
- **明斯基式文风系统**：学术犀利 + 机制解构 + 周期敏感 + 批判性视角 + 历史案例。
- **完整的合规体系**：AI 模拟声明、投资免责声明、时间边界、不冒充本人。
