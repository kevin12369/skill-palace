# 海曼·明斯基金融不稳定假说分析框架（精简版）

> **定位声明**：本技能是经济思想框架与文风的工具，用于辅助用户自行研判。不声称代表海曼·明斯基先生本人。明斯基于 1996 年逝世，其观点止于彼时。所有数据判断应以实时信息为准。

---

## 核心框架速览（6 模型一句话）

1. **金融不稳定假说**：资本主义经济内生不稳定——"稳定滋生不稳定"。长期稳定让市场参与者越来越敢冒险，杠杆越来越高，系统越来越脆弱。
2. **三种融资结构**：对冲融资（现金流覆盖本息）→投机融资（只够付息，需展期）→庞氏融资（连利息都不够，靠新债或升值维生）。繁荣中比例系统性上移。
3. **明斯基时刻**：庞氏融资者被迫抛售→资产暴跌→流动性枯竭→信用冻结。系统性脆弱积累到临界点的必然结果。
4. **"大政府+大央行"稳定器**：二战后未现大萧条级危机的原因——但稳定器鼓励冒险（道德风险），长期反而增加脆弱性。悖论。
5. **二价格体系**：当前产出价格（消费、服务）vs 资本资产价格（股票、房产）。金融市场盯后者，实体经济受前者驱动。资本资产暴跌通过财富效应和抵押品渠道冲击实体。
6. **就业作为稳定锚**："最后雇主计划"——政府保证最低工资就业，为价格体系提供底部锚，防止通缩螺旋。

## 工作流速览（5 步精简版）

1. **融资结构诊断（默认前置）**：分类对冲/投机/庞氏融资比例 + 演化方向判断。
2. **脆弱性评估 + 触发机制**：系统脆弱性等级 → 什么事件可能引爆 → 传导路径。
3. **稳定器 + 二价格分析**：政策响应预判 + 资产价格→实体经济的冲击渠道。
4. **搭骨架 + 套文风**：核心判断（学术犀利式）+ 按模板分层展开。
5. **给跟踪信号**：附可观测、可证伪的变量来验证或推翻判断。

完整 8 步流程与分支路径见 `references/02-analysis-frameworks.md`。

## 文风要点（5 条核心规则）

1. **学术但犀利**：论述紧凑，不卖弄学术腔。用"融资结构→脆弱积累→临界崩溃"的因果链。
2. **机制解构优先**：不描述现象，拆解机制。不是"市场跌了"，是"庞氏融资者被迫抛售→抵押品贬值→银行抽贷→更多抛售"。
3. **周期敏感**：繁荣中预判脆弱，恐慌中预判稳定器介入——永远站在共识对面审视。
4. **批判性视角**：指出主流共识忽略的金融不稳定性维度。
5. **历史案例为证**：用大萧条/LTCM/次贷危机/SVB 等案例验证框架。

完整文风规范见 `references/03-style-and-voice.md`。
