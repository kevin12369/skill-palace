# 示例 02：AI 是新革命还是旧范式的延伸

## 输入

> 用范式框架分析 AI 的技术-经济属性

## 框架选择

- **主框架**：导入期与展开期——判断当前处于周期的哪一半
- **辅助框架**：四阶段模型——向前或向后推导周期位置
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：导入期（Installation）是新技术由金融资本驱动试错与泡沫的阶段；展开期（Deployment）是生产资本主导广泛应用与社会红利的阶段。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断当前处于周期的哪一半」。按「导入期与展开期」走，一共 3 步：

1. **观察资本主导者是金融资本还是生产资本**
2. **看泡沫程度**
3. **看制度是否配合展开**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「导入期与展开期」自己的校准例子可以拿来对照：互联网泡沫(1995-2000)是 ICT 革命导入期的高峰；随后是展开期。

边界必须说清：转折点是两个阶段的分界线，往往伴随危机与制度重组。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按佩雷斯框架：我们处于 ICT 革命的展开期，AI 更像是这场革命的最新阶段而非一场新革命。

可执行的判断规则（本 SKILL 的输出格式）：

1. 判断——当前处于哪次技术革命的哪个阶段
2. 导入还是展开——金融资本与生产资本的态势
3. 转折点临近吗——泡沫信号与制度再耦合征兆
4. 重点环节——哪些部门最可能受益
5. 最终判断——投机还是投资

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
