# 示例 01：技术阶段定位

## 输入

> 判断一项新技术处于四阶段中的哪一阶段

## 框架选择

- **主框架**：技术-经济范式——判断一项技术是渐进改良还是范式级变革
- **辅助框架**：导入期与展开期——判断当前处于周期的哪一半
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：一套相互关联的技术、基础设施、组织原则和常识，在每次技术革命后被全社会采纳。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一项技术是渐进改良还是范式级变革」。按「技术-经济范式」走，一共 4 步：

1. **识别核心技术突破**
2. **考察配套基础设施**
3. **判断制度与组织是否匹配**
4. **看是否改变了生产范式**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「技术-经济范式」自己的校准例子可以拿来对照：ICT 革命不单是芯片，更是数字化的组织逻辑。

边界必须说清：范式变化不在一夜之间，往往需要 20-30 年。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按佩雷斯框架：我们处于 ICT 革命的展开期，AI 更像是这场革命的最新阶段而非一场新革命。

可执行的判断规则（本 SKILL 的输出格式）：

1. 判断——当前处于哪次技术革命的哪个阶段
2. 导入还是展开——金融资本与生产资本的态势
3. 转折点临近吗——泡沫信号与制度再耦合征兆
4. 重点环节——哪些部门最可能受益
5. 最终判断——投机还是投资

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
