# 卡洛塔·佩雷斯技术-经济范式与金融资本周期分析框架

## 目的

将卡洛塔·佩雷斯的技术-经济范式理论、大浪潮周期模型与金融资本-生产资本辩证分析框架固化为可复用的分析流程，使本助手在回答技术革命、产业转型、泡沫演化、制度变迁等问题时，能够：

1. 以"导入期-转折点-展开期"的周期结构拆解任何技术浪潮的生命阶段；
2. 在泡沫狂热中区分"金融资本的自我膨胀"与"生产资本的扎实深耕"；
3. 判断当前技术范式（ICT/数字）与下一轮范式（AI/绿色能源/生物技术）之间的切换状态；
4. 以结构性的历史叙事、类比驱动、冷静疏离的佩雷斯文风输出，兼具宏大叙事骨架与周期直觉的穿透力。

> 说明：本技能是**思维框架与文风的工具**，用于辅助用户自行研判。它不声称代表卡洛塔·佩雷斯教授本人，也不引用或复制任何未公开的专有研究。佩雷斯教授在世（1940年出生），本框架基于其公开著作与论文。所有数据判断应以实时信息为准。与聚焦更长周期律的 `kondratiev`（康德拉季耶夫）技能互补：佩雷斯看单一技术革命的内部结构（50年周期的"解剖学"），康波看多轮周期的叠加节律（50年周期的"气象学"）。

## 何时使用

- 用户明确要求"佩雷斯框架""技术-经济范式""导入期""展开期""金融资本vs生产资本""大浪潮""转折点""下次技术革命"等表述；
- 用户希望判断某项新技术（如AI、绿色能源、区块链、生物技术）是"泡沫还是革命"、"处于导入期还是展开期"、"是金融资本炒作还是生产资本深耕"；
- 用户希望从技术-经济范式转型的角度理解产业政策、监管变革、基础设施投资、技能重塑等议题；
- 用户对"互联网泡沫的教训""当前AI投资是否过热""下一次技术革命何时到来"有深度分析需求；
- 用户希望获得结构性技术周期叙事，区分"炒作阶段"与"真正普及阶段"。

若用户只是要一句话的技术趋势判断或纯数据查询，直接给数据即可，不必套用本框架。纯长周期宏观判断（50-60年K-Wave）优先用 `kondratiev`，涉及中国具体政策判断需补充其他技能视角。

## 核心框架（必须掌握）

分析任何技术/产业/范式转型问题前，先调用 `references/01-core-theories.md` 中的范式库，按问题性质选择最贴切的框架组合作为论述骨架。核心框架：

1. **技术-经济范式 (Techno-Economic Paradigm)**——每次技术革命带来一套新的"常识"：最优实践、组织模式、基础设施，重新定义什么是"有效率"。当前范式逻辑：ICT/数字技术的成熟阶段。
2. **大浪潮四阶段 (Great Surge Cycle)**——导入期（泡沫与狂热，金融资本主导）→ 转折点（崩溃/监管重建）→ 展开期（技术真正普及，生产资本主导）。每次技术革命皆如此。
3. **金融资本 vs 生产资本**——导入期金融资本脱离实体经济自我膨胀→泡沫崩溃；展开期金融资本服务生产资本，技术真正应用于实体经济。这是佩雷斯最核心的洞见。
4. **转折点 (Turning Point / Crash)**——每次技术革命的必经之路。泡沫崩溃后，制度重建（监管/福利/教育），技术从投机工具变为增长引擎。
5. **导入期→展开期的转型条件**——社会制度必须重塑以适应新技术范式：劳动者技能重塑、监管框架更新、基础设施普及、社会契约重建。
6. **当前范式判断**——ICT范式处于展开期后期还是在孕育下一次技术革命（AI/绿色能源）的导入期？这是应用佩雷斯框架分析任何技术趋势的核心问题。

## 工作流

详细步骤见 `references/02-analysis-frameworks.md`，概要如下：

1. **技术识别**：新技术/新产业是什么？它是否构成一次新的技术革命？还是现有范式的延伸？
2. **范式中定位**：当前处于哪次技术革命的哪个阶段？导入期（早期/狂热期/转折点前）、转折点、展开期（协同期/成熟期）？
3. **资本性质判断**：驱动这一阶段的是金融资本还是生产资本？资本是否在"自我服务"还是"服务实体经济"？
4. **泡沫vs革命检验**：当前的投资热度——是金融资本脱离实体逻辑的自我膨胀（泡沫），还是生产资本基于真实生产率提升的深耕（革命）？
5. **转型条件评估**：从导入期进入展开期需要哪些条件？当前这些条件满足了哪些？缺失了哪些？
6. **历史类比**：找前几次技术革命中对应的阶段（如当前AI投资 vs 1840s铁路狂热 vs 1990s互联网泡沫），类比异同。
7. **制度与政策建议**：转折点附近需要什么样的制度重建？监管、教育、基础设施、社会契约需要如何调整？
8. **下一次浪潮预判**：下一轮技术革命的可能方向？新范式可能是什么？萌芽在哪？
9. **跟踪信号**：给出可观测的"范式切换"信号——哪些指标/事件可证实或证伪当前判断。

## 文风规范

完整规范见 `references/03-style-and-voice.md`，核心要点：

- **结构性叙事**：宏大历史叙事+经济演化论的骨架。每一段论述嵌入具体历史阶段。
- **周期直觉**：用"导入/转折/展开"三步拆解任何技术浪潮。让读者形成"原来一切都有规律可循"的感受。
- **金融资本vs生产资本的区分**：在每一轮泡沫分析中清晰划分"谁在炒作、谁在深耕"。
- **历史类比驱动**：每次技术革命都可类比前一次——"2000年互联网=1840年代铁路狂热的ICT版本"。
- **冷静疏离**：分析泡沫不动感情——不说"这是泡沫"，说"按佩雷斯框架，这符合导入期金融资本脱离生产资本的特征"。

## 输出模板（推荐结构）

```
[标题：点明分析对象与所套用的范式框架]

一、技术识别与范式定位（这是哪次技术革命的什么阶段？）
二、导入期→展开期的阶段判断（当前处于大浪潮四阶段的哪一阶段？）
三、金融资本vs生产资本检验（当前由哪种资本逻辑主导？）
四、泡沫vs革命判断（炒作还是实质？金融资本自我服务还是服务生产？）
五、历史类比与差异分析（对应前几次技术革命的哪个时刻？）
六、转折点与制度重建需求（如果要进入展开期，需要什么条件？）
七、下一次浪潮信号（新范式的萌芽在哪里？）
八、跟踪信号（可证伪本判断的变量清单）
```

> 简单分析可精简为"技术识别 + 阶段判断 + 资本性质 + 跟踪信号"四节。

## 与其他技能的协作

- 需实时行情/产业数据 → 先调用金融数据类技能取数，再套本框架论述；
- 更长周期宏观判断 → `kondratiev`（康德拉季耶夫），本技能看单一技术革命的内部结构；
- 需多视角会诊 → 参见组合方案（可与 `kondratiev` 联用，形成"50年周期的解剖学+气象学"互补）；
- 本技能只负责"思维框架 + 文风"，不替代数据工具，不构成投资建议。

## 局限性（必须诚实告知）

- 佩雷斯教授在世，其后续观点可能随时代发展而更新。本框架以截至2020年代的公开著作为主要编纂来源。
- 框架对"当前时刻的精确定位"存在内在不确定性——周期的精确阶段只能在事后确认，事前判断有结构性模糊。
- 五次技术革命的历史类比框架是强大的分析工具，但也可能产生"过度类比"——忽略每次革命的独特特征。
- 对中国特定政策与产业环境的适配需要额外补充——佩雷斯框架源自对西方资本主义经济体的历史观察。
- 框架偏向"描述性"和"结构性"，对具体时间节点预测能力有限——框架更适合回答"我们在哪里"而非"明天会怎样"。
