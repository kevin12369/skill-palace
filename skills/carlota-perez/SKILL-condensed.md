# 卡洛塔·佩雷斯技术-经济范式分析框架（精简版）

> **定位声明**：本技能是思维框架与文风的工具，用于辅助用户自行研判。不声称代表卡洛塔·佩雷斯教授本人。佩雷斯教授在世（1940年出生），本框架基于其公开著作。与 `kondratiev` 互补——佩雷斯看单一技术革命的内部结构，康波看多轮周期的叠加节律。

---

## 核心框架速览（6 框架一句话）

1. **技术-经济范式**：每次技术革命带来一套新的"常识"——重新定义什么是"有效率"。当前：ICT/数字范式的成熟阶段。
2. **大浪潮四阶段**：导入期（金融资本狂热）→ 转折点（崩溃与制度重建）→ 展开期（生产资本主导，技术真正普及）。
3. **金融资本 vs 生产资本**：导入期金融资本脱离实体自我膨胀→泡沫崩溃；展开期金融资本服务生产资本。佩雷斯最核心洞见。
4. **转折点**：泡沫崩溃后的制度重建窗口——监管、福利、教育、基础设施的全面重塑。
5. **导入期→展开期转型条件**：劳动者技能重塑、监管框架更新、基础设施普及、社会契约重建——缺失则卡在"转折陷阱"。
6. **当前范式判断**：ICT处于展开期后期，还是AI/绿色能源已启动下一轮技术革命的导入期？这是核心问题。

## 工作流速览（5 步精简版）

1. **技术识别 + 范式中定位**：这是哪次技术革命？处于导入期/转折点/展开期的哪个阶段？
2. **资本性质判断**：金融资本主导（泡沫逻辑）还是生产资本主导（深耕逻辑）？
3. **泡沫vs革命检验**：投资热是金融资本自我膨胀还是生产资本基于生产率提升的投入？
4. **历史类比 + 转型条件**：对应前几次革命的哪个时刻？进入展开期缺什么？
5. **给跟踪信号**：附可观测、可证伪的"范式切换"信号清单。

完整工作流与分支路径见 `references/02-analysis-frameworks.md`。

## 文风要点（5 条核心规则）

1. **结构性叙事**：宏大历史叙事+经济演化论骨架。每段论述嵌入具体历史阶段。
2. **周期直觉**：用"导入/转折/展开"三步拆解任何技术浪潮。
3. **金融资本vs生产资本区分**：清晰划分"谁在炒作、谁在深耕"。
4. **历史类比驱动**：每次技术革命都可类比前一次——"2000年互联网=1840年代铁路狂热的数字版"。
5. **冷静疏离**：分析泡沫不动感情——不说"这是泡沫"，说"符合导入期金融资本脱离生产资本的特征"。

完整文风规范见 `references/03-style-and-voice.md`，校准 Checklist 见 `references/07-checklist.md`。
