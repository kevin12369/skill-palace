# 04 - 关键观点年表与技术革命年表

> 本文件记录卡洛塔·佩雷斯关键观点的演变、五次技术革命的详细年表，以及佩雷斯本人关键时间节点。所有内容来自公开来源，用于辅助理解其思想演变脉络，不代表佩雷斯教授本人或其未公开观点。

---

## 五次技术革命详细年表

### 第1次技术革命：工业革命——早期机械化（1771—）

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 爆发期 | 1771年 | 阿克莱特在克罗姆福德开设第一家水力纺纱厂——标志工厂制的诞生 |
| 导入期-狂热 | 1780s—1790s | 运河建设狂热——英国运河网从无到有的基础设施泡沫 |
| 转折点 | 1793年 | 运河泡沫崩溃 + 法国大革命战争引发金融恐慌 |
| 展开期 | 1800s—1820s | 工厂制在纺织业全面普及，蒸汽动力开始与水力竞争 |
| 成熟期 | 1820s | 机械化纺织业的增长达到极限，蒸汽动力暗示下一轮革命的来临 |

**关键要素**：棉花、铁
**基础设施**：运河和水道网络
**组织模式**：工厂制（集中生产）
**范式名称**：早期机械化

---

### 第2次技术革命：蒸汽与铁路时代（1829—）

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 爆发期 | 1829年 | 斯蒂芬森的"火箭号"在雨山试验中获胜——铁路时代的标志 |
| 导入期-狂热 | 1830s—1840s | 英国铁路狂热——铁路公司如雨后春笋涌现，股价飙升，投机泛滥 |
| 转折点 | 1847年 | 铁路狂热崩溃——泡沫爆裂，大量铁路公司破产 |
| 展开期 | 1850s—1860s | 铁路在全欧洲/北美全面铺设，成为经济骨干网 |
| 成熟期 | 1870s | 铁路网络基本成型，钢铁开始替代铁暗示下一轮革命 |

**关键要素**：铁、煤
**基础设施**：铁路网、蒸汽船、电报
**组织模式**：合资股份公司、专业管理阶层崛起
**范式名称**：蒸汽与铁路

---

### 第3次技术革命：钢铁与重工业时代（1875—）

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 爆发期 | 1875年 | 贝塞麦转炉使廉价钢大规模生产成为可能 |
| 导入期-狂热 | 1880s—1890s | 全球铁路/航运/钢铁投资狂热——阿根廷、澳大利亚大量外资涌入 |
| 转折点 | 1890年 | 巴林银行危机——全球金融恐慌，阿根廷违约 |
| 展开期 | 1900s—1910s | 电力、化学、汽车在重工业基础上全面扩散——"美好年代" |
| 成熟期 | 1910s—1920s | 钢铁/重工业范式饱和，一战重组，石油开始替代煤炭 |

**关键要素**：廉价钢
**基础设施**：全球航运网、全球电报网、铁路的全球拓展
**组织模式**：巨型卡特尔、纵向一体化企业、专业经理人阶层成熟
**范式名称**：钢铁、电力与重工业

---

### 第4次技术革命：石油与大规模生产时代（1908—）

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 爆发期 | 1908年 | 福特T型车投产——大规模生产与消费时代的标志 |
| 导入期-狂热 | 1920s | "咆哮的二十年代"——汽车/无线电/电力狂热投资，股票市场泡沫 |
| 转折点 | 1929—1933 | 华尔街大崩溃 + 大萧条——资本主义最深重的危机 |
| 转折点-制度重建 | 1933—1945 | 罗斯福新政、社会保障体系、凯恩斯主义宏观管理、布雷顿森林体系 |
| 展开期 | 1945—1971 | "黄金时代"——福特制大规模生产与消费的全盛时期 |
| 成熟期 | 1970s | 石油危机、布雷顿森林体系解体、增长极限、滞胀——暗示下一轮革命 |

**关键要素**：石油、塑料
**基础设施**：高速公路网、电网、航空网、郊区化
**组织模式**：福特制/泰勒制大规模生产、垂直一体化巨型企业
**范式名称**：石油、汽车与大规模生产

---

### 第5次技术革命：信息与通信技术时代（1971—）

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 爆发期 | 1971年 | 英特尔微处理器（4004）发布——芯片作为关键要素登场 |
| 导入期-狂热 | 1995—2000 | 互联网泡沫——dot-com狂热，NASDAQ暴涨暴跌 |
| 转折点A | 2000—2001 | 互联网泡沫崩溃——dot-com破灭 |
| 制度回应 | 2000s | Sarbanes-Oxley、数据隐私法的早期讨论 |
| 转折点B | 2008 | 全球金融危机——金融化过度后的第二次转折 |
| 制度回应B | 2008—2010s | Dodd-Frank、巴塞尔III、量化宽松 |
| 展开期 | 2010s—至今? | 平台经济崛起、云计算/AI/移动互联网在全经济扩散 |
| 成熟期? | 2020s? | 平台饱和、反垄断、数字化生产率增长放缓——下一轮革命的萌芽？ |

**关键要素**：芯片/硅（摩尔定律驱动的价格持续下降）
**基础设施**：互联网、光纤、移动通信、云计算
**组织模式**：网络化组织、平台模式、敏捷/精益生产
**范式名称**：信息与通信技术（ICT）

## 对后世事件的前瞻性判断（按框架推演）

以下观点按佩雷斯框架进行推演——这不是佩雷斯教授本人的判断，她是活着的学者，其观点可能随时间更新：

### AI投资热潮（2020s）

按佩雷斯框架推演：
- AI目前展示出"新范式导入期"的一些特征——关键要素（算力）成本在持续下降，基础设施（AI算力中心/云）在狂热铺设
- 但同时AI也可以被看作ICT范式的"最深度延伸"——如果AI只是现有ICT范式的一个深度阶段，那它就处于ICT展开期的后期
- 从金融资本vs生产资本的视角判断：当前的AI投资由VC和科技巨头主导（混合了生产资本和金融资本），但AI投资的估值逻辑大量依赖"未来收入"而非当前利润——这是导入期的金融资本特征
- 历史类比：目前的AI投资在某些方面类似2000年互联网泡沫时期——金融资本在大量涌入，基础设施在铺设，但技术在实体经济中尚未全面渗透并提升生产率——但差异在于AI的主要推动者是已有盈利能力的科技巨头，而非初创泡沫企业

### 绿色能源转型（2020s）

按佩雷斯框架推演：
- 绿色能源转型符合新范式导入期的关键要素特征——可再生能源成本持续下降、全球共识形成、基础设施在铺设
- 但绿色能源与ICT/化石能源的关系并非简单的"替代"——更像是新型叠加
- 如果绿色能源＋AI＋生物技术共同构成第6次技术革命，我们可能正处于第6次革命的导入期第一阶段（爆发期），而第5次革命（ICT）处于展开期后期——双重叠加

> 声明：以上属于按佩雷斯方法论框架的推演，不代表佩雷斯教授本人的判断。佩雷斯教授在世，其观点是开放演化的。
