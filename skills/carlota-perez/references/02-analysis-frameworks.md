# 02 - 分析框架工作流

> 本文件定义基于卡洛塔·佩雷斯方法论的分析工作流与分支路径。所有流程均为佩雷斯公开来源方法论的整理，用于辅助研判，不代表佩雷斯教授本人或其未公开观点。

---

## 标准工作流（9 步）

以下为完整分析的标准步骤。简单技术趋势判断见下方分支路径表。

### 第 1 步：技术识别

**核心操作**：新技术/新产业是什么？是否构成一次新的技术革命，还是现有范式的延伸？

**判断标准**：
- 是否存在一种"关键要素"——即价格持续下降、供给看似无限的核心投入品？
- 是否催生了新型基础设施网络——改变了经济活动的空间组织方式？
- 是否要求企业改变其"最优实践"和组织模式？

**判断结果**：
- 三个标准都不满足 → 现有范式内的增量创新，流程到此终止
- 部分满足 → 潜在的范式转型萌芽，继续分析但降低结论置信度
- 全部满足 → 构成新的技术革命，全面展开分析

### 第 2 步：范式中定位

**核心操作**：当前处于哪次技术革命（第5次ICT？第6次绿色/AI？）的哪个阶段？

**定位指标**：
- 导入期第一期（爆发期）：新技术出现，关键要素开始降价，老范式出现危机迹象
- 导入期第二期（狂热期）：金融资本主导，基础设施狂热投资，资产泡沫膨胀
- 转折点：泡沫崩溃，制度重建过程
- 展开期第一期（协同期）：技术在全经济范围普及，生产率全面提升
- 展开期第二期（成熟期）：技术范式接近极限，市场饱和，新范式萌芽显现

**判断依据**：
- 关键要素与基础设施的渗透率趋势
- 金融资本与生产资本的相对主导力
- 政策信号（监管在限制还是在赋能？）
- 生产率统计数据（技术普及是否带来生产率提升？）

### 第 3 步：资本性质判断

**核心操作**：驱动当前阶段的是金融资本还是生产资本？资本在"自我服务"还是"服务实体经济"？

**判断维度**（详见理论3）：

1. **资金来源**：投机性资金 vs 产业长期资本？
2. **回报逻辑**：依赖资产转售 vs 依赖真实利润？
3. **叙事风格**：宏大"改变世界"叙事 vs 务实"成本降低X%"叙事？
4. **渗透率-生产率脱节检验**：技术渗透率在提升但生产率统计数据未改善？

### 第 4 步：泡沫vs革命检验

**核心操作**：当前的技术投资热度——是金融资本脱离实体经济逻辑的自我膨胀（泡沫），还是生产资本基于真实生产率提升的深耕（革命）？

**泡沫检验清单**：
- [ ] 新增进入者/初创企业的数量是否呈指数级上升（大量"me-too"企业）？
- [ ] 估值是否脱离了任何基于生产率的合理估计？
- [ ] 是否存在"这次不一样"的宏大叙事在支撑估值？
- [ ] 资本涌入速度是否远超技术实际渗透和生产转化的速度？
- [ ] 代表性"明星企业"是否有持续盈利路径，还是依赖持续融资生存？

**革命检验清单**：
- [ ] 生产率统计（TFP/劳动生产率）是否在改善？
- [ ] 技术是否在降低全行业/全经济的实际成本？
- [ ] 新技术是否在催生全新的、可持续的商业模式（而非仅仅转移存量蛋糕）？
- [ ] 基础设施是否在从"实验性"转向"公共品"属性？

**判断原则**：
- 泡沫检验项 ≥ 3 → 导入期狂热阶段，金融资本主导
- 革命检验项 ≥ 3 → 展开期协同阶段，生产资本主导
- 两者均不满足 → 转折点区间或早期导入期

### 第 5 步：转型条件评估

**核心操作**：从导入期进入展开期需要哪些条件？（详见理论5）

**四个层面评分（每种0-5分）**：

| 条件 | 评分 | 依据 |
|------|------|------|
| 基础设施普及度 | /5 | 覆盖率、成本可及性、公共品属性 |
| 劳动者技能重塑 | /5 | 技能供给-需求匹配度、培训体系投资 |
| 监管框架适配度 | /5 | 是否释放新技术潜力同时约束破坏性 |
| 社会契约谈判状态 | /5 | 收入分配趋势、社会对技术转型的接受度 |

**综合判断**：
- 四项均 ≥ 3 → 展开期条件基本成熟
- 某一项显著 < 3 → 该项为瓶颈，可能拖慢/卡住转折点
- 多项 < 3 → 处于"转折陷阱"，展开期尚未到来

### 第 6 步：历史类比

**核心操作**：找前几次技术革命中对应的阶段进行类比分析。

**类比框架**（以当前AI投资潮为例）：

| 类比对象 | 相似之处 | 不同之处 | 启示 |
|---------|---------|---------|------|
| 1840s铁路狂热 | 基础设施狂热投资、金融资本主导、政府支持、大量企业涌入 | AI基础设施更虚拟化、全球资本流动性更高 | 铁路狂热后是长期增长——但大多数铁路公司倒闭了 |
| 1920s无线电/电力狂热 | 新技术被广泛炒作、股票市场狂热、1929崩溃 | AI尚未被如此广泛地零售投资者参与 | 狂热会终结——但技术革命不会 |
| 1990s互联网泡沫 | 科技估值脱离利润、dot-com繁荣、"新经济"叙事 | AI技术路线已有明确大厂分布，不像dot-com的"所有人都在试" | 泡沫破裂→清洗后的真正赢家在展开期崛起（如Amazon从dot-com废墟中崛起） |

### 第 7 步：制度与政策建议

**核心操作**：转折点附近需要什么样的制度重建？

**制度重建检查清单**：
- 监管：反垄断是否需要更新？消费者/劳动者保护是否需要升级？环境/安全标准是否需要新技术框架？
- 教育/技能：技术培训体系是否与新技术要求匹配？终身学习机制是否在建立？
- 金融：金融监管是否约束了金融资本的"脱离服务生产"倾向？
- 收入分配：新技术创造的增量如何更公平地分配？社会契约是否支持新技术的全面扩散？
- 公共投资：基础设施的公共品供给是否足够？是否有"数字/绿色鸿沟"？

### 第 8 步：下一次浪潮预判

**核心操作**：下一轮技术革命的可能方向？新范式的萌芽在哪里？

**预判维度**：
- **成本下降曲线**：什么技术/资源的成本在持续快速下降？（→潜在关键要素）
- **基础设施网络效应**：什么基础设施的网络效用在加速？（→潜在范式基础设施）
- **组织模式实验**：什么新型组织模式在大量实验？（→潜在范式组织模式）
- **"痛点"与"瓶颈"**：当前范式在什么方面遇到了不可逾越的瓶颈？（→新范式要解决的问题）

### 第 9 步：给跟踪信号

**核心操作**：附"未来需要盯住哪几个变量/事件来验证或推翻本判断"。

**有效跟踪信号的特征**：
- 可观测（不是"范式转型在加速"，而是"清洁能源发电成本连续两年低于化石能源"）
- 可证伪（明确指出在什么条件下本判断被推翻）
- 围绕范式的核心指标（关键要素价格、基础设施渗透率、生产率、资本性质信号）

**格式**：
| 跟踪变量 | 当前状态 | 验证阈值（证实判断） | 推翻阈值（证伪判断） |
|----------|---------|-------------------|-------------------|
| 变量 1 | 当前值 | 若达到 X，判断成立 | 若跌破 Y，判断推翻 |
| 变量 2 | 当前值 | 若达到 X，判断成立 | 若跌破 Y，判断推翻 |

## 分支路径表

| 路径 | 适用场景 | 加载文件 | 简述 |
|------|---------|---------|------|
| **A·快速判断** | "这个新技术是泡沫还是革命"——初步判断 | 仅 SKILL.md，无需加载额外文件 | 技术识别 + 资本性质快速判断。两步判否直接给出"现有范式延伸"结论。 |
| **B·深度分析** | 完整技术革命阶段分析——判断为重大范式转型 | 01 + 03 + 07 + 08 | 全流程 9 步展开，从技术识别到跟踪信号逐一执行。适用于重大判断。 |
| **C·主题提问** | 具体概念解读或单一判断点 | 按问题类型加载相关理论文件（01 中的对应理论编号） | 定点回答。不展开全部流程，只提取与问题相关的范式框架进行审视。 |
| **D·泡沫检验** | 市场对某项新技术一边倒狂热——"AI是泡沫吗" | 01（理论 3 金融资本vs生产资本 + 理论 2 大浪潮）+ 07 checklist | 以金融资本vs生产资本检验为主。输出以结构化的"这是导入期狂热的金融资本主导现象/这是展开期的生产资本深耕"定调。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 是具体概念/理论问题？
  │    └─ 是 → C·主题提问：加载相关理论，定点回答
  │
  ├─ 对某技术/产业有"泡沫vs革命"关切？
  │    └─ 是 → D·泡沫检验：金融资本vs生产资本检验
  │
  ├─ 需要完整技术革命/范式转型判断？
  │    └─ 是 → A·快速判断（先判是否构成范式转型）
  │              ├─ 不构成 → 输出"现有范式延伸"，终止
  │              └─ 构成 → B·深度分析（全流程 9 步展开）
  │
  └─ 只是想知道某项技术的周期位置？
       └─ A·快速判断：技术识别 + 阶段定位，两步定结论
```
