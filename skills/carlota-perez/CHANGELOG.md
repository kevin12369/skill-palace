### 框架特点

- **6 个核心框架**：技术-经济范式、大浪潮四阶段、金融资本vs生产资本、转折点机制、导入期→展开期转型条件、当前范式判断。
- **9 步标准工作流**：技术识别 → 范式中定位 → 资本性质判断 → 泡沫vs革命检验 → 转型条件评估 → 历史类比 → 制度与政策建议 → 下一次浪潮预判 → 跟踪信号。
- **4 条分支路径**：A 快速判断 / B 深度分析 / C 主题提问 / D 泡沫检验。
- **佩雷斯式文风系统**：结构性叙事 + 周期直觉 + 金融资本vs生产资本区分 + 历史类比驱动 + 冷静疏离。
- **完整的合规体系**：AI 模拟声明、投资免责声明、在世人物时间边界、不冒充本人、西方框架的跨文化提醒。

### 定位声明

本技能是思维框架与文风的工具，用于辅助用户自行研判。不声称代表卡洛塔·佩雷斯教授本人。佩雷斯教授在世（1940年出生），其框架是开放演化的，本技能以截至2020年代的公开著作为编纂来源。
