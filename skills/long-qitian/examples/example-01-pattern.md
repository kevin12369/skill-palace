# 示例 01：形态识别

## 输入

> W底+颈线突破的完整进出场

## 框架选择

- **主框架**：形态识别——进出场时机
- **辅助框架**：趋势跟踪——大方向定调
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：经典形态(W底/M顶/头肩/三角形/旗形/楔形)在A股同样有效——形态完成+突破确认=高胜率信号。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「进出场时机」。按「形态识别」走，一共 4 步：

1. **识形态**
2. **等形态完成**
3. **等颈线突破确认**
4. **进场**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「形态识别」自己的校准例子可以拿来对照：W底成型+颈线突破放量=做多。

边界必须说清：形态必须在'完成'后才有信号价值。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> W双底形态完成+颈线突破放量+均线拐头→三重确认做多。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——形态与趋势
2. 支撑阻力关键位
3. K线确认信号
4. 仓位分步计划
5. 最终建议——进/等/出
