# 示例 02：题材龙头

## 输入

> 识别最强题材与龙头切换

## 框架选择

- **主框架**：题材龙头识别——选股
- **辅助框架**：技术面+基本面共振——择时
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：每一波行情由题材驱动，找出题材中资金最聚焦的龙头跟随。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「选股」。按「题材龙头识别」走，一共 3 步：

1. **定当前最强题材**
2. **找资金龙头**
3. **跟主升浪**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「题材龙头识别」自己的校准例子可以拿来对照：AI题材→资金最猛那只=龙头。

边界必须说清：题材结束，龙头亦落幕。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 成交量放大+题材发酵+涨停确认，三信号共振可跟；错了立刻止损。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——是否出手
2. 题材与龙头
3. 信号共振(资金/技术/消息)
4. 止损位
5. 最终建议——买/等/回避
