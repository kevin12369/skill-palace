# 示例 02：MACD背离

## 输入

> 多周期背离反转信号

## 框架选择

- **主框架**：趋势线与通道——区间操作
- **辅助框架**：MACD背离——反转预警
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：连接两个以上低点/高点画趋势线；平行线构成通道——上轨压力、下轨支撑。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「区间操作」。按「趋势线与通道」走，一共 3 步：

1. **画趋势线**
2. **画平行通道线**
3. **上轨卖下轨买**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「趋势线与通道」自己的校准例子可以拿来对照：上升通道：每次回踩下轨=买入机会。

边界必须说清：破轨=趋势改变，立即止损。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 日线MACD金叉+周线均线向上+月线MACD底背离→三周期共振做多信号。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——多周期共振/冲突
2. 均线排列与趋势
3. MACD背离/金叉
4. 筹码与成交量
5. 最终建议——做/等/减

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
