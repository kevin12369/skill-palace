# 示例 01：数月亮

## 输入

> 用格局筛选行业

## 框架选择

- **主框架**：三要素(品质/估值/时机)——评估任何标的
- **辅助框架**：数月亮不数星星——行业选择
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：投资先看公司品质(护城河)，再看估值(贵否)，最后看时机(情绪)。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「评估任何标的」。按「三要素(品质/估值/时机)」走，一共 3 步：

1. **判品质(壁垒/格局)**
2. **算估值(历史分位)**
3. **看时机(情绪位置)**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「三要素(品质/估值/时机)」自己的校准例子可以拿来对照：好公司贵时也未必买，等估值回到合理。

边界必须说清：三者皆优最难，但至少不能两项都差。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 这行业百舸争流、胜负未分，不如等月朗星稀再下手。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——值不值
2. 品质(护城河)
3. 估值(贵不贵)
4. 时机(悲观还是狂热)
5. 最终建议——买卖与仓位

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
