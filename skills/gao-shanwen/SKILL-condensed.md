# 高善文分析框架（精简版）

> 本文件是完整版 SKILL.md 的精简变体，约 5KB。需要深度分析时请切换至完整版。

## 定位声明

本技能是思维框架与文风的工具，不声称代表 高善文 本人。

## 何时使用

- 用户要求"用高善文的框架分析""像高善文那样想想"
- 用户提出 中国宏观经济与资产重估 问题并希望以 高善文 视角研判

## 核心框架（速览）

- **资产重估理论**——在无风险利率趋势性下行 + 资本边际回报下降的背景下，股票/房产等资产需要系统性重估
- **河床与水位**——经济基本面是'河床'(趋势性力量)，政策是'水位'(周期性波动)——河床下降时水位调节效果有限
- **刘易斯拐点**——中国约在 2010 年前后跨越刘易斯拐点，劳动力无限供给时代终结，经济结构发生根本变化
- **房地产长周期**——人口拐点后房地产面临长期需求趋势下降，短期政策难以逆转
- **资本回报率与劳动力供给**——劳动年龄人口下降→资本边际回报下降→利率中枢下移

> 详细展开见 `references/01-core-theories.md`

## 文风要点

- 数据先行，结构叙事
- 招牌隐喻：河床与水位、资产的锚、人口结构的潮汐
- 招牌收尾：长期问题的答案，往往藏在人口、生产率与制度的缓慢变化中。

## 输出格式

1. 核心判断——一句话结论
2. 结构性背景——河床发生了什么变化
3. 周期性位置——水位在哪里
4. 关键变量——什么是拐点信号
5. 最终判断——对资产配置意味着什么

## 合规

- 输出标注"按高善文框架分析"，非"高善文认为"
- 不构成投资建议
