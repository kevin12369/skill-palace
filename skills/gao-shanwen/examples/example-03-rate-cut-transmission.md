# 示例 03（专项场景）：降息为何带不动股市

## 输入

> LPR 又降了，为什么股市一点反应都没有？这个传导是不是彻底失效了？

## 框架选择

- **主框架**：河床与水位（政策=水位，实体回报与预期=河床）
- **辅助框架**：资本回报率与利率中枢、刘易斯拐点后的资产负债表行为
- **不采用**：把"降息→估值抬升"当作无条件链条的教科书推演

## 完整输出

先给结论：**传导没有失效，是传导的方向被改了。当私人部门的优先目标从"扩张资产负债表"切换为"修复资产负债表"时，降息的作用是降低存量债务的利息负担，而不是推高资产估值——前者是减负，后者才是行情。**

如果我们把货币政策比作往河里放水：水位能不能漫上来，取决于河床的坡度和两岸的高度。降息降低的是资金的价格，但资金要不要流出来，取决于借款人有没有愿意投的项目、贷款人敢不敢承担风险。当企业看到的是产能利用率不足、居民看到的是收入预期不稳，利率降得再多，也只是把"不借"变得更便宜——**低利率并不自动等于宽信用。**

这也解释了观察到的形态：债券先涨、股票不动、信用利差不一定收窄。如果传导是顺畅的，三者应该同向；现在不同向，说明阻滞点不在价格，而在风险偏好与抵押品价值。

**从更长的时间维度来看**，这背后是刘易斯拐点之后的一次资产负债表再平衡。拐点之前，劳动力无限供给压低了劳动报酬，企业的资本回报率足以覆盖利率，降息直接刺激投资；拐点之后，劳动报酬占比上升、资本回报率下移，同样的降息对投资的边际刺激减弱，而对存量债务的减负效应变大。换句话说，**同样的政策工具，作用对象变了。**

**二阶追问**：如果降息主要是减负而不是刺激，那么它对资产价格的正面影响从哪里来？答案是两个非典型渠道：一是分母端的确定性溢价——在资产荒里，稳定现金流的资产被重新定价；二是债务置换与再融资对信用风险的缓释，这会压低风险溢价而不是抬升盈利预期。两条渠道都不需要"宽信用"成立，因此都会表现为结构性行情而非普涨。

**反向证据（若出现则修正判断）**：企业中长贷连续放量且伴随资本开支回升；居民中长贷回暖且与地产成交同步；M1 与 M2 剪刀差转向收敛——这三条是"宽信用真的开始"的读数，出现时宏观层面的普涨逻辑才成立。
