# 示例 02：资产重估的前提是否成立

## 输入

> 都说 A 股在资产重估，为什么重估了这么久，指数还是原地踏步？

## 框架选择

- **主框架**：资产重估理论（无风险利率趋势性下行 + 资本边际回报下降 → 资产系统性重估）
- **辅助框架**：资本回报率与利率中枢、河床与水位
- **关键区分**：重估是"估值中枢的移动"，不是"行情的启动"——两者时间尺度差一个量级

## 完整输出

先给结论：**资产重估是一个估值中枢的移动过程，它的必要条件是"无风险利率的趋势性下行"，而不是"流动性的一次性宽松"。当利率只是周期性回落、风险溢价反而走阔时，重估的算术不成立，指数自然原地踏步。**

如果把资产价格拆开看，它等于盈利除以（无风险利率 + 风险溢价）。市场讨论"重估"时通常只盯着分母的前半段——利率下行了就认为该涨——却忽略了后半段。利率下行的同时，如果风险溢价因为不确定性上升而走阔，两者可以完全对冲。这正是"重估了这么久却没涨"的算术解释：**不是重估逻辑错了，而是重估的第二个前提没到位。**

**问题的根源不在水面，而在河床。** 从更长的时间维度看，中国资产重估真正依赖三件事同时发生：

1. **无风险利率中枢的台阶式下移**，而不是每一次逆周期调节带来的短端波动；
2. **资本边际回报的下降被市场确认**——这会把资金从实业投资挤向存量资产，是重估的资金来源；
3. **风险溢价的压缩**，它依赖制度预期的稳定，而不是货币条件。

第 1、2 条在过去几年是成立的，第 3 条反复被打断。所以看到的形态是：估值在低位反复磨，但中枢没有系统性抬升。

**二阶追问**：如果第 3 条迟迟不改善，会怎样？答案不是"永远不重估"，而是重估以更"结构性"的方式发生——不是全市场估值抬升，而是资金在少数"确定性资产"上形成局部重估，其余部分继续折价。这解释了为什么指数不动、但结构性行情不断：重估先发生在能被定价的地方。

**机会成本比较**：在等待全市场重估的过程中，持有现金的机会成本是局部重估的收益；参与局部重估的机会成本是通缩尾部风险。这个权衡取代了"要不要重估"的问题——后者是个伪问题。

**需要盯住的信号**：风险溢价的代理变量（信用利差、股权风险溢价的滚动分位）、以及利率下行的持续性（是趋势性台阶还是单次脉冲）。二者同向时，重估才进入兑现期。

> 说明：本示例为框架演练，未引用实时数据，不给具体点位与百分比。
