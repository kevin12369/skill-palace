# 示例 01：政策组合

## 输入

> 先定战略配置再谈战术

## 框架选择

- **主框架**：输家的游戏——制定投资方法论
- **辅助框架**：政策组合先行——组合构建起点
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：专业对手云集时，主动得分难，胜负取决于谁少犯错。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「制定投资方法论」。按「输家的游戏」走，一共 3 步：

1. **识别游戏类型**
2. **转向降错策略**
3. **减少主动出手**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「输家的游戏」自己的校准例子可以拿来对照：对多数人是'输家游戏'，被动+纪律胜率更高。

边界必须说清：越努力越亏，因成本与错误。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 与其赌战术胜负，不如定好政策组合、低费再平衡，让时间做朋友。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——政策还是战术
2. 战略配置建议
3. 再平衡规则
4. 成本纪律
5. 最终建议——长期框架
