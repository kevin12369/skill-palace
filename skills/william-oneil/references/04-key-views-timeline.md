# 04 - 关键观点与年表

> 威廉·欧奈尔 的生平与思想演进关键节点。

| 年份 | 事件 |
|------|------|
| 1933 | 出生于美国俄克拉荷马 |
| 1958 | 开始研究过去100年超级牛股的共同特征 |
| 1963 | 创立William O'Neil & Co. |
| 1984 | 创办Investor's Business Daily(IBD) |
| 1988 | 出版《笑傲股市》 |
| 2003 | 出版《笑傲股市》第三版(最终版) |
| 2023 | 逝世，享年90岁 |

## 框架演进要点

- 早期：奠定核心方法论基础
- 中期：体系化并著书立说
- 后期：被广泛引用，成为 CAN SLIM选股与成长股突破 领域的参照坐标

> 如人物已故，观点止于最后公开表达之时；数据判断须以实时信息为准。
