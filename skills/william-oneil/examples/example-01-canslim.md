# 示例 01：CAN SLIM完整筛选

## 输入

> 用七字母系统逐一打分量产一只候选股的全过程

## 框架选择

- **主框架**：CAN SLIM七字母系统——系统化筛选潜在牛股
- **辅助框架**：杯柄形态——寻找突破买入的精确时机
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：C=当季每股盈利(增长≥25%)、A=年度盈利(三年稳定增长≥25%)、N=新东西(产品/管理/股价新高)、S=供需(突破日放量+流通盘适中)、L=龙头(RS≥80，只买第一不买第二)、I=机构赞助(至少几家优质基金持有)、M=市场方向(大盘处于确认上升趋势)。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「系统化筛选潜在牛股」。按「CAN SLIM七字母系统」走，一共 4 步：

1. **逐项检查CAN SLIM七项是否达标**
2. **任一项不达标→Pass**
3. **七项全部达标→画出杯柄/突破图形**
4. **确定精确买入点和7-8%止损位**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「CAN SLIM七字母系统」自己的校准例子可以拿来对照：2023年某AI龙头：C=EPS+45%、A=三年+30%、N=新品发布+股价新高、S=突破日放量3倍均量、L=RS=92、I=多家优质基金持有、M=纳斯达克确认上升趋势→CAN SLIM全达标。

边界必须说清：CAN SLIM不是一个选股指标，是一个系统——七项必须同时满足，一项不及格就不买。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按欧奈尔CAN SLIM框架：该股当季EPS增长35%(C达标)，三年稳健(A达标)，刚突破一个22周杯柄形态放量50日均量的2倍(S/L达标)，RS为89，大盘处于确认上升趋势(M达标)——这是一个教科书级的CAN SLIM买入信号。止损设在突破点以下7%。

可执行的判断规则（本 SKILL 的输出格式）：

1. CAN SLIM七项逐项评分——C/A/N/S/L/I/M各多少分
2. 核心形态判断——是否出现杯柄/双底/平底等买入形态
3. 量价确认——突破是否伴随放量
4. RS评级——是否满足RS≥80
5. 止损计划——精确入场价和7-8%止损价
6. 最终判断——Buy / Wait / Pass
