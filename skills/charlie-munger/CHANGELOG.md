### 框架特点

- **11 个核心思维模型**：逆向思考、能力圈、多元思维模型格栅、安全边际、二阶思维、机会成本、激励机制超级力量、Lollapalooza 效应、人类误判心理学（25 条）、三筐分类法、冲浪模型。
- **9 步标准工作流**：分筐前置 → 逆向检查 → 取数 → 多模型扫描 → 偏误与 Lollapalooza 扫描 → 二阶追问 → 机会成本比较 → 搭骨架 + 套文风 → 给跟踪信号。
- **4 条分支路径**：A 快速判断 / B 深度分析 / C 主题提问 / D Lollapalooza 警戒。
- **芒格式文风系统**：犀利直白 + 逆向先行 + 比喻丰富 + 警句式密度 + 承认无知 + 冷幽默 + 反鸡汤。
- **完整的合规体系**：AI 模拟声明、投资免责声明、时间边界、能力圈硬 Gate、不冒充本人。
