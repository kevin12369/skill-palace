# 示例 01：逆向思考评估商业模式失败风险

## 输入

> 帮我用芒格的逆向思维看看，这门生意最可能怎么死？

## 框架选择

- **主框架**：逆向思考（总是反过来想）——不问"怎么成功"，先问"怎么必然失败"
- **辅助框架**：人类误判心理学（激励导致的偏差）、Lollapalooza 效应
- **注意**：逆向的目的在于排雷，正常推进到"唱反调"就变成了另一种偏见

## 完整输出

先给结论：**要判断这门生意会不会死，别列成功要素，去列死亡路径。把能想到的死法写满一页，然后逐条问：这条路上，公司现在站在第几步？**

常见的死亡路径就那几条，一条条过：

1. **客户集中致死**。前几大客户占比高，一旦丢一个，固定成本立刻吃掉利润。检验：丢掉最大客户后，现金流是负数吗？
2. **激励反向致死**。销售按签约额提成而不按回款提成，就会先增长后暴雷。检验：一线人员的奖金挂在哪个指标上？这个指标和公司想要的长期结果是不是同一件事？
3. **技术替代致死**。不是"对手更强"，而是"客户不再需要这个环节"。检验：客户的问题是被更好地解决了，还是被绕过去了？
4. **杠杆致死**。不是亏损致死，是到期还不上致死。检验：把最差一年的现金流套进去，还能不能覆盖本息？
5. **规模不经济致死**。扩张时单位成本上升而不是下降，说明生意的规模效应是假的。
6. **合规与声誉致死**。一次事故就能抹掉多年积累，且恢复成本非线性。

**Lollapalooza 检查**：以上几条很少单独发作。真正的崩塌通常是三四个因素同向叠加——激励反向 + 客户集中 + 杠杆，一起发作时没有任何缓冲。所以要看"最坏情况下有几条同时成立"。

**反过来想的第二层**：如果你列不出五条像样的死法，通常不是这门生意安全，而是你还没看懂它。列不出死法是最危险的信号。

**结论的用法**：不是"避开所有风险"，而是找到"致命风险"——那些一旦发生就没有翻身机会的。可以承受的风险与不可以承受的风险，必须分开对待。
