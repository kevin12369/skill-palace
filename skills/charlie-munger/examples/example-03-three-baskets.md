# 示例 03（专项场景）：三筐分类法

## 输入

> 手上有个机会，我看得懂一部分，但有几个关键点拿不准。这种情况该投还是不投？

## 框架选择

- **主框架**：三筐分类法（可投 / 不可投 / 太难）——第三筐是这套方法的核心，不是垃圾桶
- **辅助框架**：能力圈与硬 Gate、机会成本
- **前置纪律**：分类必须在分析之前完成，不能等分析完再找理由

## 完整输出

先给结论：**"看懂一部分、几处拿不准"不是介于可投与不可投之间的状态，它就是"太难"这一筐。第三筐的存在意义，是让你不必把每个机会都强行塞进前两筐。**

三个筐的定义要卡死：

- **可投**：关键变量都能判断，且赔率明确有利。关键变量通常不超过三个，多于三个说明它本来就该进第三筐。
- **不可投**：能判断，且判断结果是赔率不利。这是有结论的否定，不是看不懂。
- **太难**：无法在合理时间内判断关键变量。它的正确处理是"放下"，而不是"降低仓位试一试"。

**为什么要设第三筐**：人的默认倾向是把不确定性当成"可以打折参与"的理由——看不懂就少买一点。这在数学上是错的：对于期望为负或未知的赌局，任何仓位都是坏仓位，仓位大小只改变亏损速度。

**硬 Gate 检查**：在分类之前先过三道门——这门生意的现金流能否被预测？管理层是否可被信任？最坏情况是否会让我出局？任何一道不过，直接进第三筐，不再往下分析。硬 Gate 的意义是不允许用"其他方面都很好"来抵消。

**二阶追问**：为什么这个机会现在摆在我面前？如果答案里包含"因为别人都不愿意看"，那么第三筐可能是对的；如果答案是"因为最近跌了很多"，那么先分清是价格变了还是价值变了。

**机会成本**：第三筐的另一个价值是腾出注意力。把机会放进第三筐之后，你会发现自己有时间去看那些本来就在能力圈内的东西——长期收益主要来自后者的复利。

> 说明：本示例为框架演练，不针对任何具体机会给出结论。
