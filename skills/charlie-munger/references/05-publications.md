# 05 - 代表作索引与框架编纂来源

> 本文件梳理查理·芒格的核心出版物与公开讲话，标注各框架的编纂来源章节。用于快速定位具体理论的原文出处，辅助深度研究与交叉验证。

## 核心出版物

### 1. 《穷查理宝典》（Poor Charlie's Almanack）

- **出版时间**：2005 年（初版），后续多次增订
- **编者**：Peter D. Kaufman
- **性质**：芒格思想的集大成之作，汇集生平最重要的 11 篇演讲与文章
- **地位**：芒格框架的主要来源，也是本技能引用最频繁的原始文本

**关键章节与框架编纂来源**：

| 章节 | 框架贡献 | 本技能对应理论 |
|------|---------|---------------|
| 第一讲：在哈佛学校毕业典礼上的演讲（1986） | "如何保证人生悲惨"——逆向思考的经典示范 | 理论 2：逆向思考 |
| 第二讲：论基本的、普世的智慧 | 多元思维模型格栅的系统阐述 | 理论 1：格栅 |
| 第三讲：论基本的、普世的智慧（修正稿） | 格栅模型的更新与补充，跨学科方法论的深入 | 理论 1、理论 4 |
| 第四讲：关于实用思维的实务讲座 | 将多元思维模型应用于具体商业问题的示范 | 理论 3、理论 6 |
| 第五讲：专业人士需要更多的跨学科技能 | "双锤子"批判——专业教育导致的单一学科陷阱 | 理论 1、理论 3 |
| 第十讲：在南加州大学 GOULD 法学院的演讲 | 能力圈与安全边际的实务讨论 | 理论 3、理论 4 |
| 第十一讲：人类误判心理学（1994 演讲修订版） | 25 条认知偏误的完整清单与详细论述 | 理论 9：25 条偏误 |
| 全书散见 | Lollapalooza 效应的概念起源与多次讨论 | 理论 8：Lollapalooza |

### 2. 伯克希尔·哈撒韦股东信与年会讲话

- **时间跨度**：1965—2023（芒格 1978 年起任副董事长）
- **形式**：巴菲特每年撰写股东信，芒格与巴菲特在年会上回答股东问题
- **主题**：投资哲学、企业治理、经济观察、人生智慧

**框架编纂来源**：

| 主题 | 来源时期 | 框架贡献 |
|------|---------|---------|
| "以合理价格买伟大公司" vs "捡烟蒂" | 1980s—1990s 股东会 | 安全边际从价格向质量的演进逻辑 |
| 消费品牌护城河论述 | 1990s 股东会 | 理论 4：质量安全边际与护城河评估 |
| 对投行/华尔街激励机制的批判 | 2000s—2010s 股东会 | 理论 7：激励机制超级力量 |
| 错过科技股的坦诚反思 | 2000s—2010s 股东会 | 理论 3：能力圈局限性 |
| 金融危机期间的冷静判断 | 2008—2009 股东会 | 理论 8：Lollapalooza 实战应用 |

### 3. Daily Journal 年会讲话（2010—2023）

- **时间跨度**：2010—2023
- **性质**：芒格独立于伯克希尔之外的年度深度问答
- **特点**：相比伯克希尔年会，Daily Journal 问答更不受限、更直白、更犀利

**框架编纂来源**：

| 年份 | 关键议题 | 框架贡献 |
|------|---------|---------|
| 2010—2015 | 投资方法论、能力圈纪律 | 理论 3、理论 10（三筐分类法的迭代深化） |
| 2016—2019 | 中国投资反思（阿里）、科技股评估 | 跨文化能力圈警示、冲浪模型校准 |
| 2020—2021 | 零利率/SPAC/散户狂热 | 理论 8：Lollapalooza 效应的最完整实战分析 |
| 2022—2023 | 加密货币批判、AI 审慎、人生智慧 | 最后见解读，观点止于此 |

### 4. 《查理·芒格传》（Damn Right! Behind the Scenes with Berkshire Hathaway Billionaire Charlie Munger）

- **出版时间**：2000 年
- **作者**：Janet Lowe
- **性质**：芒格的授权传记，由亲密同事与朋友提供素材
- **框架贡献**：芒格的人生经历与思维习惯的形成背景，对本技能理解"为什么芒格会这样想"有辅助价值

### 5. 《投资的格栅理论》（Investing: The Last Liberal Art）

- **出版时间**：2005 年
- **作者**：Robert G. Hagstrom（虽非芒格所著，但系统阐述了芒格的多元思维模型在投资中的应用）
- **框架贡献**：多元思维模型格栅的第二手系统化梳理，可作为格栅概念的补充阅读

## 补充学习材料

以下为芒格公开演讲与访谈，对加深理解有帮助但非本技能框架的核心编纂来源：

- **Wesco Financial 年会讲话**（芒格曾任董事长）：1990s—2000s 期间对投资与商业的深入论述
- **USC 商学院演讲（1994）**：人类误判心理学雏形首次公开提出
- **加州理工学院演讲（2007）**："论学院派经济学的缺陷"——跨学科思维的学术批判
- **公开访谈与媒体露面**：芒格一生接受过有限次数的访谈，言论高度一致，可作为框架的具体应用例证
