# 04 - 关键观点与年表

> 查理·芒格 的生平与思想演进关键节点。

| 年份 | 事件 |
|------|------|
| 1924 | 出生于美国内布拉斯加 |
| 1948 | 哈佛法学院毕业 |
| 1962 | 创办芒格律师事务所 |
| 1978 | 正式加入伯克希尔任副董事长 |
| 2005 | 出版《穷查理宝典》 |
| 2023 | 逝世，享年99岁 |

## 框架演进要点

- 早期：奠定核心方法论基础
- 中期：体系化并著书立说
- 后期：被广泛引用，成为 微观决策与商业判断 领域的参照坐标

> 如人物已故，观点止于最后公开表达之时；数据判断须以实时信息为准。
