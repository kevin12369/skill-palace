# 02 - 分析框架工作流

> 本文件定义基于查理·芒格方法论的分析工作流与分支路径。所有流程均为芒格公开来源方法论的整理，用于辅助研判，不代表芒格先生本人或其未公开观点。

---

## 标准工作流（9 步）

以下为完整分析的标准步骤。简单决策见下方分支路径表。

### 第 1 步：分筐前置

**核心操作**：三筐分类法判断——

- 能看懂这门生意/这个问题吗？
- 能用一句话说清核心逻辑吗？
- 能识别致命风险吗？

**判断结果**：
- 三个都能 → **继续**，进入第 2 步
- 任一不能 → **Too Hard 筐**，输出"太难了，我不懂"，流程终止

> 大部分机会应落入 Too Hard 筐。把问题分筐本身就是决策——"不做决定"也是决定。

### 第 2 步：逆向检查（默认前置，不可跳过）

**核心操作**：

1. **逆向构造**：要实现完全相反的结果，需要做哪些事？
2. **逐一排查**：当前决策是否包含任何"导致失败"的要素？
3. **致命错误扫描**：当前假设中是否存在任何一条，一旦被证伪就直接导致结果崩溃？

**判断结果**：
- 发现致命错误 → 进 No 筐或回退修改假设
- 通过逆向检查 → 继续

> 芒格："告诉我我会死在哪里，我就不去那里。"逆向检查不是可选步骤——它是默认前置、不可跳过的硬性步骤。

### 第 3 步：取数（可选但建议）

**核心操作**：拉取以下数据以校验框架判断：

- 估值分位（PE/PB/PS 历史分位、同行业比较）
- 护城河指标（毛利率趋势、ROIC 长期水平、自由现金流转化率）
- 管理层薪酬结构与持股变动
- 行业渗透率与竞争格局演变

**若数据无法获取**：声明"以下为框架性推演，缺乏实时数据校验。实际决策前应补充数据验证。"

### 第 4 步：多模型扫描

**核心操作**：至少从 3 个学科视角审视（含 1 个硬科学：数学/物理/工程）

**步骤**：
1. 从八大学科模型库（见 `01-core-theories.md` 理论 1）选取 3+ 视角
2. 每个视角给出一个判断
3. **共振判断**：视角同向收敛 → 提升置信度
4. **冲突判断**：视角矛盾 → 做前提审计

**冲突处理协议**：
- 不取折中——折中是伪判断
- 方向归前提在场者（有充分证据支持的视角）
- 刹车归输不起的一方（哪怕只有一个视角提示致命风险，也应暂停）

> 至少包含一个硬科学视角，防"心理学+经济学双锤子陷阱"。

### 第 5 步：偏误与 Lollapalooza 扫描

**核心操作**：

**A. 偏误扫描**：识别当前决策最可能触发的 2-3 条认知偏误（从 25 条偏误库选取）

常触发的高危偏误：
- 被剥夺超级反应 #14：亏损场景下最致命
- 过度乐观 #13：牛市中最常见
- 社会认同 #15：跟风时最隐蔽
- 避免不一致 #5：公开表态后最难纠错
- 自视过高 #12：能力圈过度自信

**B. Lollapalooza 四步扫描**（当市场/舆论一边倒时触发）：

1. **识别力量**：当前场景有哪些力量在同时发力（偏误、激励、叙事、资金流）？
2. **同向判断**：这些力量是同向叠加还是相互抵消？
3. **极端性评估**：舆论是否一边倒？叙事是否不可证伪？资金是否加速涌入？
4. **决策含义**：若判定狂热正向发酵 → 反向操作或离场；若负向发酵（恐慌）→ 寻找错杀机会

**触发条件**：市场/舆论出现以下特征之一即触发 Lollapalooza 扫描：
- "这次不一样"叙事盛行
- 无人看空/无人看多的一边倒舆论
- 资金/杠杆加速涌入
- 新概念估值脱离所有历史锚定

### 第 6 步：二阶追问

**核心操作**：对每个关键结论追问至少两轮"然后呢？"

**格式示例**：
- 结论：降价能提升销量
- 一阶追问：然后呢？→ 竞争对手跟随降价，行业利润率永久下滑
- 二阶追问：然后呢？→ 品牌价值受损，消费者对价格敏感度提高，公司长期定价权丧失

> 大多数人的思考停在第一轮。多问一轮，就已经超过 90% 的市场参与者。

### 第 7 步：机会成本比较

**核心操作**：

1. 明确当前选项是什么
2. 明确次优选择是什么（资金/时间/注意力的最佳替代用途）
3. 比较预期回报：当前选项是否明显优于次优？

**判断标准**：
- 当前选项明显更优 → 继续
- 当前选项仅略优或不确定 → 应审慎
- 当前选项明显劣于次优 → 选择次优

> 不问"这个好不好"，问"这比我的次优选择好不好"。一个大差不差的选择，可能不如什么都不做。

### 第 8 步：搭骨架 + 套文风

**核心操作**：将前述分析转化为结构化输出。

**输出结构**（详见 SKILL.md 输出模板）：
1. 三筐预判（一句定调）
2. 逆向检查
3. 核心判断（警句式 + 芒格式比喻）
4. 多模型审视
5. 偏误与 Lollapalooza 扫描
6. 二阶追问
7. 机会成本
8. 安全边际
9. 需要盯住的信号

**文风要求**（详见 `03-style-and-voice.md`）：
- 犀利直白，不留情面
- 逆向先行，警句式密度
- 比喻丰富，冷幽默适度
- 结论克制，给可证伪的跟踪变量

### 第 9 步：给跟踪信号

**核心操作**：附"未来需要盯住哪几个变量/事件来验证或推翻本判断"。

**有效跟踪信号的特征**：
- 可观测（不是"市场情绪变好"，而是"连续 3 个月净利率回升"）
- 可证伪（明确指出在什么条件下本判断被推翻）
- 有时限（不是"总有一天"，而是"6 个月内"）

**格式**：
| 跟踪变量 | 当前状态 | 验证阈值 | 推翻阈值 |
|----------|---------|----------|---------|
| 变量 1 | 当前值 | 若达到 X，判断成立 | 若跌破 Y，判断推翻 |
| 变量 2 | 当前值 | 若达到 X，判断成立 | 若跌破 Y，判断推翻 |

> 没有跟踪信号的判断是自欺欺人。如果一个判断不能被证伪，它就不是一个有用的判断。

## 分支路径表

| 路径 | 适用场景 | 加载文件 | 简述 |
|------|---------|---------|------|
| **A·快速判断** | "值不值得深入分析"——初步筛选 | 仅 SKILL.md，无需加载额外文件 | 三筐预判 + 逆向检查。两步判否则直接放弃，不消耗后续资源。 |
| **B·深度分析** | 完整企业/投资评估——确定要做 | 01 + 03 + 07 + 08 | 全流程 9 步展开，从分筐到跟踪信号逐一执行。适用于重大决策。 |
| **C·主题提问** | 具体概念解读或单一决策点 | 按问题类型加载相关理论文件（01 中的对应理论编号） | 定点回答。不展开全部流程，只提取与问题相关的格栅模型进行审视。 |
| **D·Lollapalooza 警戒** | 市场一边倒/狂热/恐慌——群体非理性场景 | 01（理论 8 Lollapalooza + 理论 9 偏误）+ 07 checklist | 以 Lollapalooza 四步风险扫描为主。输出以"这是/不是 Lollapalooza 时刻"定调，附带力量叠加分析。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 是具体概念/理论问题？
  │    └─ 是 → C·主题提问：加载相关理论，定点回答
  │
  ├─ 市场狂热/恐慌/一边倒？
  │    └─ 是 → D·Lollapalooza 警戒：启动四步扫描
  │
  ├─ 需要完整企业/投资评估？
  │    └─ 是 → A·快速判断（先判是否值得深入）
  │              ├─ Too Hard / No → 输出"太难了/不值得"，终止
  │              └─ Yes → B·深度分析（全流程 9 步展开）
  │
  └─ 只是想知道是否值得深入研究？
       └─ A·快速判断：三筐 + 逆向，两步定结论
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 9 步流程**：重大投资决策、企业深度评估、关键战略选择
- **精简流程（核心 4 步）**：日常判断、初步筛选、简单决策
  1. 三筐预判
  2. 逆向检查
  3. 核心判断
  4. 跟踪信号

### 取数步骤的处理

- 有数据工具可用：执行第 3 步取数，将数据整合到后续分析中
- 无数据工具：跳过第 3 步，在输出开头声明"以下为框架性推演，缺乏实时数据校验"
- 取数结果与框架判断冲突：以数据为准修改判断，不强行让数据"符合框架"

### Too Hard 筐的诚实性

当判断归入 Too Hard 筐时：
- 明确说明为什么"太难了"（能力圈外？信息不足？逻辑无法串通？）
- 不做后续步骤——承认无知本身就是完整的分析结论
- 可以给"如果将来什么条件满足，这个问题可能变成可分析"的观望指引

> 芒格一生中大部分问题归入了 Too Hard 筐。坦率说"我不知道"比假装知道更诚实，也更接近智慧。
