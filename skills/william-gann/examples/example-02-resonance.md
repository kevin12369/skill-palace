# 示例 02：三维共振

## 输入

> 时间+价格+比例共振转折

## 框架选择

- **主框架**：江恩角度线——趋势与支撑阻力
- **辅助框架**：江恩方图——寻找关键价格位
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：以1x1线(45度)为价格与时间的平衡线，上方角度线为阻力、下方为支撑。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「趋势与支撑阻力」。按「江恩角度线」走，一共 3 步：

1. **定起点**
2. **画1x1平衡线**
3. **画1x2、2x1等辅助角度线**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「江恩角度线」自己的校准例子可以拿来对照：回调至1x1线获支撑→强买信号。

边界必须说清：角度线持续有效，跨年跨月。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 本轮下跌运行至第89个交易日，触及前低斐波那契38.2%，时间与价格共振→关注转折信号。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——时间周期位置
2. 角度线/方图关键位
3. 时间价格共振判断
4. 止损位
5. 最终建议——转折信号/观望
