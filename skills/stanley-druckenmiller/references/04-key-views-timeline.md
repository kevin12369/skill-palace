# 04 - 关键观点与年表

> 斯坦利·德鲁肯米勒 的生平与思想演进关键节点。

| 年份 | 事件 |
|------|------|
| 1953 | 出生于美国 |
| 1977 | 加入匹兹堡国民银行任股票分析师 |
| 1981 | 创立Duquesne Capital |
| 1988 | 受邀加入量子基金为索罗斯工作 |
| 1992 | 与索罗斯共同做空英镑——击败英格兰银行的人 |
| 2000 | 离开量子基金回归Duquesne |
| 2010 | 关闭Duquesne转为家族办公室 |
| 2013 | 在南加州大学访谈中系统阐述投资哲学 |

## 框架演进要点

- 早期：奠定核心方法论基础
- 中期：体系化并著书立说
- 后期：被广泛引用，成为 宏观投资与资本保全 领域的参照坐标

> 如人物已故，观点止于最后公开表达之时；数据判断须以实时信息为准。
