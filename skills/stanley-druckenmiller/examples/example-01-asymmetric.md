# 示例 01：非对称风险收益判断

## 输入

> 用德鲁肯米勒框架评估A股当前的宏观风险报酬比

## 框架选择

- **主框架**：非对称风险收益——任何交易决策前的仓位和风险管理
- **辅助框架**：自上而下框架——从空白开始构建一个投资组合
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：胜负取决于正确时赚多少 vs 错误时亏多少的不对称性——追求每次交易中上行远大于下行的机会。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「任何交易决策前的仓位和风险管理」。按「非对称风险收益」走，一共 4 步：

1. **判断向上空间(目标价-现价)**
2. **判断向下空间(止损价-现价)**
3. **只有上行/下行比大于等于3:1才值得下注**
4. **根据比值决定仓位大小**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「非对称风险收益」自己的校准例子可以拿来对照：德鲁肯米勒1992年做空英镑：下行封顶(英国不可能让英镑大幅贬值)，上行几近无限——教科书级的非对称交易。

边界必须说清：非对称不等于高风险——恰恰是通过严格下行保护来降低风险。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按德鲁肯米勒框架：当前联储转向宽松叠加盈利增速回升→风险报酬比向有利方向倾斜，应集中配置受益于流动性改善和增长动量的行业龙头。但任何一笔仓位的最大损失必须预设硬上限。

可执行的判断规则（本 SKILL 的输出格式）：

1. 宏观定调——全球流动性+经济增长的合力方向
2. 非对称判断——当前风险报酬比倾斜向哪边
3. 行业/资产筛选——自上而下选出最受益方向
4. 仓位逻辑——为什么这个头寸应该大/小
5. 资本保全——最大下行风险在哪，如何对冲
