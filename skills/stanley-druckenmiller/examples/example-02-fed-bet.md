# 示例 02：联储政策博弈

## 输入

> 判断联储的紧缩到宽松拐点对A股的传导效应

## 框架选择

- **主框架**：自上而下框架——从空白开始构建一个投资组合
- **辅助框架**：资本保全第一——每笔交易的下行保护
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：经济-行业-个股三层筛选：先宏观定方向，再中观选行业，最后微观挑个股。顺序不可颠倒。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「从空白开始构建一个投资组合」。按「自上而下框架」走，一共 3 步：

1. **判断全球宏观方向(增长+通胀+政策)**
2. **确定受益/受损行业**
3. **在受益行业中选出最优个股**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「自上而下框架」自己的校准例子可以拿来对照：2020年疫情后：宏观判断→大规模财政货币刺激利好风险资产；行业判断→科技和远程办公受益；个股→选出行业龙头。

边界必须说清：自上而下不是忽略个股——而是确保个股选择在正确的宏观背景中。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按德鲁肯米勒框架：当前联储转向宽松叠加盈利增速回升→风险报酬比向有利方向倾斜，应集中配置受益于流动性改善和增长动量的行业龙头。但任何一笔仓位的最大损失必须预设硬上限。

可执行的判断规则（本 SKILL 的输出格式）：

1. 宏观定调——全球流动性+经济增长的合力方向
2. 非对称判断——当前风险报酬比倾斜向哪边
3. 行业/资产筛选——自上而下选出最受益方向
4. 仓位逻辑——为什么这个头寸应该大/小
5. 资本保全——最大下行风险在哪，如何对冲

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
