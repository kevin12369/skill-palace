# 示例 01：15点清单应用

## 输入

> 用费雪框架给一家公司做15点打分的完整推演

## 框架选择

- **主框架**：Scuttlebutt 闲聊法——深入调研一家公司的竞争力
- **辅助框架**：15 点清单——系统化评估一家公司
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：真正的投资研究不是读年报，而是走到企业生态中去聊——跟供应商、客户、竞争对手、前员工、行业协会聊出真实的竞争力。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「深入调研一家公司的竞争力」。按「Scuttlebutt 闲聊法」走，一共 4 步：

1. **列出5类信息来源(供应商/客户/竞争对手/前员工/行业专家)**
2. **设计开放式问题(问优势/弱点/变化)**
3. **拼合碎片形成整体图像**
4. **对照管理层自己的表述**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「Scuttlebutt 闲聊法」自己的校准例子可以拿来对照：调研一家消费电子公司:客户说'产品用了就回不去'，供应商说'他们要求最高但也最懂技术'——这是正向信号。

边界必须说清：闲聊法耗时但极有价值——定量分析无法回答的问题，定性访谈可以。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按费雪框架：这只科技股业绩好但更关键的是——我和五个前员工聊过，管理层对研发的执着和长期主义几乎偏执；竞争对手说'他们做的事我们至少落后两年'。这是费雪15点清单打高分的公司。

可执行的判断规则（本 SKILL 的输出格式）：

1. 公司核心竞争判断——Scuttlebutt拼出的图像
2. 15点清单快速评分——逐一打分并给出依据
3. 管理层评估——人品/能力/战略
4. 成长可持续性——研发和市场机会的长期逻辑
5. 最终判断——该不该长期持有

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
