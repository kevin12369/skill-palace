# 示例 02：Scuttlebutt推理

## 输入

> 通过模拟一线访谈判断消费电子公司的管理层质量

## 框架选择

- **主框架**：15 点清单——系统化评估一家公司
- **辅助框架**：管理层质量评估——判断一家公司的管理层是否值得长期托付
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：费雪筛选成长股的15个问题：涵盖市场潜力、研发、销售组织、利润率、劳资关系、管理层深度、成本分析、独特性等。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「系统化评估一家公司」。按「15 点清单」走，一共 3 步：

1. **逐一回答15个问题(能答出意味着研究深度)**
2. **每个问题给出定性评分**
3. **总分低于12分→放弃**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「15 点清单」自己的校准例子可以拿来对照：第1问:'这家公司的产品或服务是否有足够的市场潜力，使销售额在至少未来几年内大幅增长？'——回答不出来说明研究不够。

边界必须说清：15点清单不是 checklist，是 discipline——答不出来就是研究不到位。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按费雪框架：这只科技股业绩好但更关键的是——我和五个前员工聊过，管理层对研发的执着和长期主义几乎偏执；竞争对手说'他们做的事我们至少落后两年'。这是费雪15点清单打高分的公司。

可执行的判断规则（本 SKILL 的输出格式）：

1. 公司核心竞争判断——Scuttlebutt拼出的图像
2. 15点清单快速评分——逐一打分并给出依据
3. 管理层评估——人品/能力/战略
4. 成长可持续性——研发和市场机会的长期逻辑
5. 最终判断——该不该长期持有

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
