# 02 - 分析框架工作流

> 本文件定义基于菲利普·费雪方法论的分析工作流与分支路径。所有流程均为费雪公开来源方法论的整理，用于辅助研判，不代表费雪先生本人或其未公开观点。

---

## 标准工作流（7 步）

### 第 1 步：闲聊法前置

**核心操作**：在设计任何定量分析之前，先明确定性信息的获取计划。

**步骤**：
1. 列出信息源清单：供应商、客户、竞争对手、前员工、行业分析师
2. 为每类信息源设计 3-5 个关键问题
3. 记录已有信息中的"信号碎片"
4. 标记信息空白——哪些关键维度完全缺乏外部验证？
5. 设计交叉验证计划——从 A 处和 B 处获得的同一件事的信息是否一致？

**若无法获取外部信息**：声明"基于公开资料的框架性分析，缺乏闲聊法外部验证。以下判断的置信度较低。"

---

### 第 2 步：15点清单打分

**核心操作**：逐条评估 15 点，给出判断和依据。

| # | 评估维度 | 判断（强/中/弱） | 依据 | 风险信号 |
|---|---------|-----------------|------|---------|
| 1 | 市场潜力 | | | |
| 2 | 研发决心 | | | |
| ... | ... | | | |
| 15 | 综合判断 | | | |

**重点关注**：
- 第 7、8、14 条——管理层评估三角
- 第 13 条——坦诚度（如果这条弱，所有财务数据打问号）
- 第 14 条——诚信（一条否决）

**判断结果**：
- 14条（诚信）不合格 → 直接放弃，无论其他维度多好
- 管理层三角中有 2 条以上弱 → 高风险
- 整体强项>10 条 → 值得深入研究

---

### 第 3 步：管理层深度评估

**核心操作**：针对管理层质量进行专项评估。

**评估框架**：
1. **CEO 画像**：建设者 vs 守成者？战略决策能力？对坏消息的态度？
2. **团队深度**：独立决策能力？关键岗位接班人？高管流失率？
3. **研发组织**：研发投入的持续性（3-5年趋势）？研发与市场的衔接？研发人才保留？
4. **销售组织**：好产品能卖出去吗？销售与研发的人员比例？客户获取成本？
5. **诚信检验**：薪酬与业绩的匹配度？与股东的承诺一致性？费雪终极问题。

**关键陷阱**：
- 不要被 CEO 的"个人魅力"蒙蔽——看他的决定，不是他的口才
- 区分"低调但有执行力"和"只会念 PPT"的管理层
- 在中国市场，区分"创始人型"和"职业经理人型"管理层的不同评估维度

---

### 第 4 步：研发真实性评估

**核心操作**：判断公司的研发投入是"真功夫"还是"花架子"。

**评估维度**：
1. **持续性**：看 3-5 年研发投入的趋势，不是看一年的绝对金额
2. **方向集中度**：是深耕一个方向还是在撒胡椒面？
3. **人才质量与保留**：研发团队的稳定性；核心研发人员的背景
4. **市场衔接度**：研发人员知道客户要什么吗？有客户反馈进入研发流程吗？
5. **成果转化率**：过去 3 年的新产品/新功能有多少来自研发投入？

**判断标准**：
| 信号 | 真功夫 | 花架子 |
|------|--------|--------|
| 研发投入占比 | 稳定在行业领先水平 | 某一年突然大幅增加（跟随风口） |
| 研发方向 | 深耕 1-2 个方向 | 热点全覆盖（AI/元宇宙/新能源皆投） |
| 人才 | 核心人员稳定，行业顶级 | 人员流动大，靠高薪挖人 |
| 市场反馈 | 客户说"他们的产品确实比别人好" | 客户说"没什么区别" |

---

### 第 5 步：成长期待判断

**核心操作**：费雪的"贵不贵"问题——成长速度能否证明当前价格合理？

**费雪式估值思考**：
1. 不是问"PE 是多少分位"——费雪不玩分位游戏
2. 而是问："如果这家公司未来 5 年的成长符合你的判断，今天这个价格是贵还是便宜？"
3. 三种可能的答案：
   - **"即便成长符合预期，估值也已经完全反映了"** → 没有安全边际（即使是费雪式的）
   - **"如果成长超预期，当前价格还算合理"** → 有费雪式安全边际
   - **"无论怎么算都太贵"** → 放弃

**费雪式安全边际 = 盈利增长 × 时间 > 当前估值所隐含的成长预期**

---

### 第 6 步：搭骨架 + 套文风

**输出结构**（详见 SKILL.md 输出模板）：
1. 闲聊法调研清单
2. 15点清单快速扫描
3. 管理层核心评估
4. 成长性判断
5. 核心判断
6. 持有指引

**文风要求**：
- 研究导向——像一篇深度研报的叙述者
- 定性优先——关注"人"和"组织"
- 娓娓道来——讲这家公司为什么值得（或不值得）持有十年

---

### 第 7 步：给持有指引

**核心操作**：附"什么条件触发卖出"和"什么信号验证长期判断"。

**持有指引格式**：

| 类型 | 条件 | 当前状态 | 触发后行动 |
|------|------|---------|-----------|
| 卖出条件 | 最初判断被证伪 | | 立即卖出 |
| 卖出条件 | 基本面永久恶化 | | 逐步减仓 |
| 卖出条件 | 管理层诚信出问题 | | 立即卖出清零 |
| 验证信号 | 成长性符合判断 | | 继续持有 |
| 验证信号 | 成长性低于预期但方向正确 | | 重新评估 |
| 验证信号 | 成长性超预期 | | 考虑增持 |

> 费雪的原则：如果只是因为"涨太多了"而想卖——坐着不动。

## 分支路径表

| 路径 | 适用场景 | 简述 |
|------|---------|------|
| **A·快速管理层判断** | 只需判断"是否值得深入研究" | 15点清单第13-15条 + 闲聊法碎片 |
| **B·全景15点评估** | 完整企业成长性评估 | 15点清单全量 + 管理层深度 + 研发评估 |
| **C·持有决策审视** | 已持有的股票是否应该卖出 | 卖出三原则逐条检验 |
| **D·新机会 vs 现有持仓** | 是否换仓 | 机会成本比较 + 研究强度判断 |

---

## Too Hard 筐的诚实性

当判断归入"无法获取足够定性信息"时：
- 费雪的核心原则：没有足够理解就不碰
- "如果我不能在 15 点中至少给出 10 条以上的清晰判断，这家公司不在我的能力圈内"
- 可以给：需要什么信息才能做出判断——用闲聊法清单的形式说明研究方向
