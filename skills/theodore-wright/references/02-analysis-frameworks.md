# 02 - 分析框架工作流

> 本文件定义基于莱特定律方法论的分析工作流与分支路径。所有流程均为莱特公开方法论与后人验证的整理，用于辅助研判。莱特先生于 1970 年逝世。

---

## 标准工作流（9 步）

以下为完整分析的标准步骤。简单问题见下方分支路径表。

### 第 1 步：数据基础确认

**核心操作**：确认待分析技术的以下数据是否可用——

- **累计产量历史数据**：至少 5 年以上，越长越好（如光伏有 40+ 年数据）
- **单位成本历史数据**：与累计产量相对应的成本数据，需调整通胀/汇率
- **数据质量评估**：来源可靠性、统计口径一致性、是否存在重大结构性断点（如政策剧变导致的产能突变）

**判断结果**：
- 数据充足（R² > 0.8）→ 继续，进入第 2 步
- 数据不足或质量不佳 → 标注"以下为基于有限数据的框架性估算，置信度较低"，可选择类比同类技术或中止

### 第 2 步：学习率估算

**核心操作**：对数回归估算学习率——

1. 对数据进行对数转换：ln(单位成本) → Y, ln(累计产量) → X
2. 线性回归 Y = a + (-b) × X
3. 学习弹性（learning elasticity）：-b
4. 学习率 L = 1 - 2^(-b)
5. 评估拟合优度 R²

**判断结果**：
- R² > 0.85 → 高置信度预测
- R² 0.7-0.85 → 中等置信度
- R² < 0.7 → 低置信度，标注"学习率估算存在较大不确定性"

**典型参考值**：

| 技术/行业 | 典型学习率 L | R² 参考 |
|----------|------------|--------|
| 光伏组件 | 20-24% | >0.95 |
| 锂电池组 | 18-22% | >0.90 |
| 半导体 | 25-30% | >0.85 |
| 风电 | 7-15% | 0.7-0.9 |
| LED | 20-28% | >0.90 |
| 氢能电解槽 | 15-20%（估） | 0.6-0.8（新兴技术） |

### 第 3 步：莱特定律拟合验证

**核心操作**：将预测的成本曲线与历史实际成本数据对比——

1. 使用学习率 L 绘制"累计产量 vs 预测成本"曲线
2. 将实际成本数据叠加在同一张图上
3. 评估残差分布——是否有系统性偏差？
4. 检查是否有结构性断点——如技术路线更替（多晶→单晶PERC→TOPCon/HJT）

**关键检查**：
- 残差是否随机分布？（好）还是呈现趋势性偏差？（需调查原因）
- 是否存在"学习速率"变化——不同时间段的学习率是否一致？

### 第 4 步：预测计算

**核心操作**：基于学习率，计算达到目标成本需要的翻倍次数和时间——

1. **当前状态**：单位成本 C_now，累计产量 Q_now
2. **目标状态**：目标成本 C_target
3. **翻倍次数**：N = log(C_target / C_now) / log(1 - L)
4. **预计时间**：基于产量年增速 g 计算达到时间

**产量增速 g 的估算方法**：
- 基于行业产能扩张计划
- 基于过去 3-5 年的产量复合增长率
- 基于政策目标（如各国可再生能源装机目标）
- 给出乐观/基准/悲观三种情景

**输出格式**：
- 乐观情景（g=高，L=低）：X 年达到目标
- 基准情景（g=中，L=中）：Y 年达到目标
- 悲观情景（g=低，L=高）：Z 年达到目标

### 第 5 步：经验曲线扩展

**核心操作**：从纯制造成本扩展到全成本视角——

1. 识别该技术的"全成本"结构（制造/销售/分销/售后各占多少）
2. 判断市场份额与累计产量的关系——是否形成"强者恒强"的正反馈？
3. 评估市场竞争格局变化对学习曲线的影响（如新进入者可能加速整体学习率提升）

**关键问题清单**：
- 当前市场份额最大的企业是否正在加速拉开与追赶者的产量差距？
- 追赶者是否有技术路线优势（可以跳过旧技术的部分学习曲线）？
- 是否出现了可能重置学习曲线的颠覆性技术？

### 第 6 步：交叉验证

**核心操作**：与其他技术预测框架做交叉检查——

1. **摩尔定律复合效应**：该技术是否同时受摩尔定律驱动？如果是，叠加计算性价比提升。
2. **替代技术比较**：是否有替代技术在以更快的学习率进步？被替代的风险有多大？
3. **需求侧检验**：目标成本是否真的能触发需求大幅增长？（有些技术即便成本够低，需求也未必爆发）

### 第 7 步：地板效应评估

**核心操作**：判断成本下降的底部约束——

1. **识别物料清单（BOM）中原材料的占比**：原材料成本是刚性地板
2. **识别物理极限**：是否有不可逾越的物理规律约束？
3. **参考成熟度最高区域的成本结构**：如果该技术在某个市场已高度成熟，其成本结构可作为"地板"的参考

**输出**：该技术在不同学习率情景下的"理论地板成本"。

### 第 8 步：搭骨架 + 套文风

**核心操作**：将前述分析转化为结构化输出——

1. 数据概览（关键数字一句话）
2. 学习率估算与拟合验证
3. 预测计算（翻倍次数与时间估算）
4. 扩展分析（经验曲线 + 交叉验证 + 地板效应）
5. 核心判断（一条量化的成本预测结论）
6. 跟踪信号

**文风要求**（详见 `03-style-and-voice.md`）：
- 数据驱动：每条判断有数字支撑
- 量化预测：不给模糊表述
- 实证主义：注明置信度
- 简单直接：拒绝过度复杂化

### 第 9 步：给跟踪信号

**核心操作**：附"需要盯住的关键参数来验证或推翻本预测"。

**有效跟踪信号的特征**：
- 可观测（不是"技术进步"，而是"季度产量增速""季度成本降幅"）
- 可证伪（给出推翻预测的阈值）
- 有因果关联（跟踪信号与预测结论之间存在明确的逻辑关系）

**格式**：

| 跟踪参数 | 当前值 | 验证阈值（预测成立） | 推翻阈值（预测错误） |
|---------|-------|-----------------|-----------------|
| 年产量增速 | X% | >Y% | <Z% |
| 学习率 | L% | 维持在 L%±2% | <L%-4% |
| 原材料价格 | $P/kg | 稳定或下降 | 持续上涨>W% |

## 分支路径表

| 路径 | 适用场景 | 简述 |
|------|---------|------|
| **A·快速估算** | "大概什么时候能平价"——初步判断 | 数据概览 + 学习率参考值 + 翻倍次数估算。3 步定结论。 |
| **B·深度预测** | 完整的成本预测与产业竞争力分析 | 全流程 9 步展开。适用于重大技术投资决策。 |
| **C·学习率比较** | "A 公司和 B 公司谁的成本降得更快" | 聚焦学习率估算 + 经验曲线竞争格局。 |
| **D·地板分析** | "这项技术的成本能降到多低" | 聚焦地板效应评估 + 原材料/物理约束分析。 |

### 路径选择决策树

```
用户提问
  │
  ├─ 只是想知道大概时间？
  │    └─ A·快速估算：学习率参考 + 翻倍次数
  │
  ├─ 需要完整投资/战略决策支撑？
  │    └─ B·深度预测：全流程 9 步
  │
  ├─ 比较多家企业的成本竞争力？
  │    └─ C·学习率比较：聚焦学习率 + 竞争格局
  │
  └─ 想知道成本的最终底部？
       └─ D·地板分析：聚焦物理约束 + 原材料成本
```

## 流程使用说明

### 何时用完整流程 vs 精简流程

- **完整 9 步流程**：重大技术投资决策、产业规划、国家能源政策评估
- **精简流程（核心 5 步）**：日常判断、快速估算
  1. 数据概览
  2. 学习率估算
  3. 预测计算
  4. 核心判断
  5. 跟踪信号

### 数据不足时的处理

- 新兴技术（历史数据 < 5 年）：使用同类技术的学习率作为参考，明确标注"基于类比估算"
- 数据质量差：降低置信度评级，建议用户关注未来几个季度的数据以验证
- 完全无数据：**放弃量化预测**，仅讨论该技术的一般性学习潜力与约束

> 莱特定律的核心价值在于它基于数据而非叙事。没有数据支撑的莱特定律分析，就像没有罗盘的航行。
