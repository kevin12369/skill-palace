# 01 - 核心理论详解

> 本文件详解西奥多·莱特的 5 个核心框架。SKILL.md 中的"核心框架"区块在此展开为完整定义。
> 所有框架均为莱特 1936 年原始论文与后人（BCG、学术界）验证与扩展的公开方法论整理，用于辅助研判。莱特先生于 1970 年逝世，其对光伏、锂电池等后世技术的应用分析属于后人工作。

---

## 框架 1：莱特定律（Wright's Law）

### 定义

莱特定律的核心表述：**每累计产量翻倍，单位成本以固定百分比下降。** 这一规律由西奥多·莱特于 1936 年在研究飞机制造成本时发现。与摩尔定律（每 18 个月性能翻倍）不同，莱特定律适用于所有制造业：产量越大、经验越多、成本越低。

### 核心公式

单位成本 = 初始单位成本 × (累计产量 / 初始累计产量) ^ (-b)

其中：
- b 是学习弹性（learning elasticity），b = -log(1 - L) / log(2)
- L 是学习率（learning rate），如 L = 0.20 表示累计产量翻倍时成本降至原来的 80%

简化计算：**累计产量翻 N 倍 → 单位成本 = 初始成本 × (1 - L)^N**

### 经典实证案例

**光伏（Solar PV）**：
- 1976-2020 年期间，光伏组件价格从约 $106/W 降至约 $0.20/W
- 累计装机每翻一倍，组件价格平均下降约 20-24%（学习率 L ≈ 20-24%）
- Farmer & Lafond（2016）的研究表明，光伏成本下降历史几乎完美拟合莱特定律
- 即使考虑硅料价格波动和政策变化，长期趋势严格遵循莱特定律

**锂电池**：
- 1991-2020 年，锂电池组价格从约 $7,500/kWh 降至约 $137/kWh（2020 年）
- 累计产量每翻一倍，价格下降约 18-22%（学习率 L ≈ 18-22%）
- Nykvist & Nilsson（2015）的研究系统验证了锂电池的莱特定律
- 2023 年进一步降至约 $100/kWh 以下，持续验证学习曲线

**半导体**：
- 1960-2020 年，单个晶体管的制造成本以惊人的学习率持续下降
- 半导体的学习率 L ≈ 25-30%，是所有行业中学习率最高的之一
- 同时受摩尔定律（性能翻倍）和莱特定律（成本下降）的双重驱动

### 适用场景

- 制造业技术成本预测（光伏、电池、风电、氢能电解槽、LED 等）
- 判断某项技术何时达到经济可行（平价）时点
- 比较不同厂商/国家的学习率差异，判断竞争优势可持续性

### 注意事项

- 莱特定律的预测准确性取决于历史数据质量和学习率的稳定性
- 学习率可能随技术成熟度变化（早期通常更快，后期渐趋平缓）
- 有"地板效应"——成本不可能无限下降，原材料和物理极限形成底部
- 不适用于非制造业（纯软件、服务等），这些领域的学习机制不同

## 框架 2：学习曲线（Learning Curve）

### 定义

学习曲线是莱特定律的经济学基础，描述"干中学"（learning-by-doing）——重复生产同一产品时，工人和管理者通过实践不断提高效率、降低单位成本的现象。

### 核心参数：学习率

学习率（Learning Rate, L）是学习曲线的关键参数：

| 学习率 L | 累计产量翻倍时成本降至 | 典型行业 |
|---------|---------------------|---------|
| 10% | 90% | 传统制造业（边际改进） |
| 15-20% | 85%-80% | 航空制造（莱特的原始观察）、风电 |
| 18-22% | 82%-78% | 锂电池、光伏组件 |
| 20-28% | 80%-72% | LED、太阳能逆变器 |
| 25-30% | 75%-70% | 半导体、消费电子 |
| 30-40%+ | 70%-60%以下 | 新兴技术早期（可能高估） |

### 干中学的机制

1. **劳动效率提升**：工人通过重复操作提高熟练度，减少失误和时间浪费
2. **工艺改进**：管理人员发现并消除瓶颈，优化生产流程
3. **设备与工具优化**：专用设备和夹具的开发使用，提升单位产出
4. **良率提升**：经验累积→更少缺陷和废品→更低单位成本
5. **设计优化**：产品设计随经验累积变得更易于制造（制造性设计/DFM）

### 操作步骤

1. 收集技术的历史累计产量与单位成本数据（至少 5 年的数据，越多越好）
2. 对数据进行对数转换：ln(单位成本) vs ln(累计产量)
3. 线性回归得到斜率 = -b，学习弹性（learning elasticity）
4. 学习率 L = 1 - 2^(-b)
5. 评估拟合优度 R²——R² > 0.8 时预测较为可靠

### 注意事项

- 学习曲线假设学习率恒定——现实中学习率随时间递减（边际改进递减）
- 短时间窗口的数据可能导致学习率估计偏高（混淆了技术进步与规模效应）
- 不同厂商的学习率可能有显著差异——这是竞争优势的重要来源

## 框架 3：经验曲线（Experience Curve）

### 定义

波士顿咨询集团（BCG）在 1960-70 年代将莱特定律从纯生产成本扩展到全部成本（含营销、分销、管理、研发等）。BCG 的核心创新在于将"成本下降"与"市场份额战略"建立了因果关系。

### BCG 经验曲线的核心逻辑链

**市场份额最高 → 累计产量最大 → 单位成本最低 → 利润率最高 → 可再投资扩大份额 → 强者恒强**

这是一个自我强化的正反馈循环。BCG 建议企业不惜以短期利润换取市场份额，因为在经验曲线上走得最快的企业将获得不可逾越的成本优势。

### 三层成本下降机制

1. **制造成本**：莱特原始观察——重复生产带来的直接制造成本下降（学习曲线）
2. **规模经济**：更大产量允许更高程度的自动化和专用设备，降低固定成本分摊
3. **全价值链效率**：采购（更大批量→更低价）、分销（更大规模→单位物流成本降低）、管理（经验累积→管理效率提升）

### 经典案例

**福特的 T 型车（1908-1927）**：
- 累计产量每翻一倍，单车价格下降约 15%
- 福特将节省的成本部分传递给消费者→更大销量→更大市场份额→更低成本
- 直至通用汽车引入多款车型战略打破这一循环

**三星 vs 京东方（LCD/OLED 面板）**：
- 韩国先发优势→累计产量领先→成本领先→利润再投资
- 京东方通过大规模投资快速追赶累计产量，缩小学习曲线差距
- 当前局面：双方在不同世代产线上各有优势

### 巴菲特的护城河中的"成本优势"

经验曲线是巴菲特"成本优势"护城河的量化表达：
- 一个低成本制造商可以通过经验曲线持续保持成本领先
- 前提是：领先者的产量增速不低于追赶者（否则累计产量差距会被缩小）
- Geico（保险）、Borsheims（珠宝）等伯克希尔旗下公司的竞争优势部分来自规模带来的成本结构优势

### 注意事项

- 经验曲线的逻辑链有脆弱点：如果市场份额是用低价买来的而非产品质量赢来的，其可持续性存疑
- 技术突变可能重置经验曲线——新进入者可以跳过旧技术的学习曲线
- 在某些行业，差异化比成本领先更重要——不必盲目追求市场份额

## 框架 4：技术成本预测（Technology Forecasting）

### 定义

莱特定律是现代技术成本预测最有效的工具之一。回答的核心问题："当太阳能/锂电池/氢能/碳捕获的累计装机翻 X 倍后，成本会降到多少？到什么时候能和化石燃料平价？"

### 预测计算步骤

**步骤 1：确定当前状态**
- 当前单位成本 C_now
- 当前累计产量 Q_now

**步骤 2：确定目标**
- 目标单位成本 C_target（如与化石燃料平价时的成本）
- 学习率 L（基于历史数据估算）

**步骤 3：计算需要的翻倍次数**
- 翻倍次数 N = log(C_target / C_now) / log(1 - L)

**步骤 4：计算达到时间**
- 预计年产量增速 g（基于产能扩张计划与市场预测）
- 达到目标时间 = N × log(2) / log(1 + g)

### 具体计算示例

**问题**：光伏组件当前成本 $0.25/W，学习率 20%。要达到 $0.10/W 与煤电平价还需要多少累计产量？

- N = log(0.10 / 0.25) / log(1 - 0.20) = log(0.4) / log(0.8) = -0.916 / -0.223 = 4.1 次翻倍

如果全球光伏装机年增速为 25%：
- 翻倍时间 = log(2) / log(1.25) ≈ 3.1 年
- 达到目标时间 ≈ 4.1 × 3.1 ≈ 12.7 年

### 注意事项

- 产量增速 g 是最大不确定性来源——受政策、市场、供应链多重因素影响
- 学习率 L 可能随时间变化（通常早期更快，后期渐缓）
- 原材料价格波动可能短期背离莱特定律趋势
- 预测置信度随预测时间跨度增加而显著降低

## 框架 5：莱特定律与摩尔定律的关系

### 定义

莱特定律与摩尔定律并不矛盾，而是互补——两者从不同维度描述了技术进步的规律：

| 维度 | 摩尔定律 | 莱特定律 |
|------|---------|---------|
| 描述对象 | **性能**的提升 | **成本**的下降 |
| 驱动因素 | 物理极限的突破（晶体管缩小） | 制造业经验的积累 |
| 时间尺度 | 性能每 18-24 月翻倍 | 累计产量翻倍时成本降固定% |
| 适用范围 | 半导体、集成电路 | 所有制造业 |
| 是否有理论极限 | 有（原子尺度） | 有（原材料成本/物理约束） |

### 双重驱动的复合效应

当一项技术同时受摩尔定律和莱特定律驱动时（如芯片），性价比的复合提升是惊人的：

- 摩尔定律：每 2 年性能翻倍（性能 ↑ 100%）
- 莱特定律（半导体 L≈30%）：累计产量翻倍时成本降至 70%
- 双重叠加：**每单位性能的成本以约 50% / 年的速度在下降**

这意味着 10 年内：**每美元能买到的算力翻了约 1024 倍。**

### 地板效应（Floor Effect）

莱特定律的核心局限之一是"地板效应"——成本不可能无限下降，存在两个硬约束：

1. **原材料成本**：即使制造工艺完美到零浪费，原材料的采购成本仍是刚性成本。例如光伏组件中硅料的成本约占 10-20%，不可能通过制造经验完全消除。
2. **物理极限**：某些制程步骤受物理定律约束。例如半导体光刻的分辨率受光的波长限制，EUV 光刻机本身已接近物理极限。

**识别地板的方法**：
- 观察物料清单（BOM）中原材料占比——成本无法降至原材料成本以下
- 观察学习率是否在长期中持续下降（学习率趋于零→接近地板）
- 参考同类型成熟技术的成本结构

### 注意事项

- 不要把摩尔定律和莱特定律混为一谈——一个是性能曲线，一个是成本曲线
- 不要忽视地板效应——无限降本的叙事在物理上不可能
- 当学习率开始明显下降时，可能是接近地板的重要信号
