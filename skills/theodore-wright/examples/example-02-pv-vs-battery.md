# 示例 02：光伏vs电池成本竞赛

## 输入

> 比较光伏和电池的成本下降曲率

## 框架选择

- **主框架**：莱特vs摩尔——判断一种技术的成本下降是由产量还是技术进步驱动
- **辅助框架**：学习曲线与经验曲线——预测一个制造业产品的成本下降路径
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：莱特：成本∝(累计产量)^(−log2(1−L))，靠产量驱动；摩尔：晶体管密度每18-24月翻倍，靠时间驱动。前者是统计规律，后者是行业路线图。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断一种技术的成本下降是由产量还是技术进步驱动」。按「莱特vs摩尔」走，一共 4 步：

1. **看成本下降是否与累计产量成对数线性关系**
2. **与技术突破的时间点对照**
3. **若对齐产量更好→莱特主导**
4. **若对齐时间→摩尔主导**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「莱特vs摩尔」自己的校准例子可以拿来对照：半导体制程同时有莱特(产量越大良率越高)和摩尔(技术节点推进)驱动——但莱特效应在成熟节点更显著。

边界必须说清：两者不互斥，多数技术同时有这两种效应。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按莱特定律：光伏组件每累计产量翻倍成本下降约24%。全球光伏装机从2020年的700GW到2024年的约1800GW(5年翻倍)意味着组件成本已再降约24%——这解释了光伏的持续降价趋势。

可执行的判断规则（本 SKILL 的输出格式）：

1. 莱特定律应用——该行业的学习率是多少
2. 累计产量与成本推演——当前产量/成本下，翻倍后的成本预测
3. 规模化可行性——需要多大产量才能让成本有竞争力
4. 与竞争对手的成本差距预测
5. 最终判断——赢家是谁？成本下降最快的玩家
