# 示例 01：学习曲线预测

## 输入

> 用莱特定律预测锂电池2028年成本

## 框架选择

- **主框架**：莱特定律——预测新能源/新兴制造业的成本下降趋势
- **辅助框架**：莱特vs摩尔——判断一种技术的成本下降是由产量还是技术进步驱动
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：累计产量每翻一倍，单位成本下降一个固定的百分比——这个百分比称为'学习率'。历史数据证实：光伏~24%、锂电池~18%、风电~10-15%、半导体~30%。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「预测新能源/新兴制造业的成本下降趋势」。按「莱特定律」走，一共 4 步：

1. **确定该行业的学习率(历史数据)**
2. **计算当前累计产量**
3. **预测下一次产量翻倍的时点**
4. **按学习率算出届时成本**

4 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「莱特定律」自己的校准例子可以拿来对照：全球锂电累计产量约3TWh，学习率18%→当累计产量达6TWh时(约2027-28)，电池成本将在现有基础上再降18%。

边界必须说清：莱特定律预测的是趋势性成本下降，技术突破可加速但这个基础曲率不变。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 按莱特定律：光伏组件每累计产量翻倍成本下降约24%。全球光伏装机从2020年的700GW到2024年的约1800GW(5年翻倍)意味着组件成本已再降约24%——这解释了光伏的持续降价趋势。

可执行的判断规则（本 SKILL 的输出格式）：

1. 莱特定律应用——该行业的学习率是多少
2. 累计产量与成本推演——当前产量/成本下，翻倍后的成本预测
3. 规模化可行性——需要多大产量才能让成本有竞争力
4. 与竞争对手的成本差距预测
5. 最终判断——赢家是谁？成本下降最快的玩家

> 说明：本示例为框架演练，未使用实时数据，不含具体数值与点位判断；实际分析须以当期公开数据为准。
