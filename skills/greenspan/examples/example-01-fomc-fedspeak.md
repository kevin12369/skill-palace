# 示例 01：FOMC 声明解读

## 输入

> 这次联储声明里说"将密切关注"，是不是意味着下一次就要降息了？

## 框架选择

- **主框架**：Fedspeak 的三层结构（事实陈述 / 条件假设 / 政策倾向）
- **辅助框架**：数据依赖的渐进主义、风险管理范式
- **不采用**：把模糊措辞直接映射为动作的"关键词表"

## 完整输出

先给结论：**"密切关注"不是信号，是留白。它说明委员会尚未就方向形成多数意见，而不是在暗示下一次的动作。**

读声明可以按三层拆：

1. **事实陈述**：对当前经济状态的判断，例如"就业增长放缓""通胀仍高于目标"。这一层信息量最大，因为它是共识，且会被后续数据检验。
2. **条件假设**：什么情况下会调整。"若劳动力市场出现进一步走弱"这类句子给出的是触发条件，而不是时间表。真正要读的是条件本身的宽窄：条件写得越具体，政策反应越接近规则；越笼统，越接近相机抉择。
3. **政策倾向**：措辞的方向性变化，例如"进一步收紧"变为"保持限制性"。这一层最容易过度解读，因为它的措辞变化往往滞后于实际立场。

**读法上的三条纪律**：

- 先比较"本次与上次"的措辞差异，而不是与市场预期的差异。前者的信噪比更高。
- 把"密切关注""依赖数据"这类句子当成默认填充物，不作为信号。
- 看有没有人投反对票、以及反对的方向——分歧的位置比一致的表态更有信息。

**必须补上的一维**：只看声明会漏掉资产负债表。政策立场还体现在准备金与资产购买的安排上；当措辞与操作冲突时，以实际操作量为准。

**二阶追问**：如果下一次真的降息，是"预防式"还是"应对式"？前者意味着对下行风险的提前管理，后者意味着已经看到了坏数据。两者的资产含义完全不同——前者利好风险资产，后者可能相反。

> 说明：本示例为框架演练，不引用任何具体会议日期与措辞原文。
