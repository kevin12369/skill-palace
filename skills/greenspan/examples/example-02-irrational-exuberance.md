# 示例 02：非理性繁荣的识别

## 输入

> 现在全球风险资产涨了这么久，怎么判断是不是已经进入非理性繁荣？

## 框架选择

- **主框架**：非理性繁荣（价格脱离可持续的盈利基础，靠预期自我强化）
- **辅助框架**：风险管理范式、格林斯潘期权（政策对下行风险的隐性担保）
- **方法论立场**：泡沫难在事前确认，因此重点是"识别脆弱性"而非"预测崩盘时点"

## 完整输出

先给结论：**非理性繁荣不是一个点位判断，而是一组结构性特征。要判断"是不是"，不必预测"什么时候破"，只需回答三个问题：上涨靠什么支撑、杠杆在哪里、政策是否在兜底。**

三个问题具体化：

1. **上涨的支撑是盈利还是估值？** 如果涨幅主要来自估值扩张，那么它依赖的是"未来会更乐观"这个假设，而不是已经实现的现金流。估值扩张本身不是罪证，但它意味着对预期变化的敏感度上升。
2. **杠杆长在谁身上？** 这是最关键的一问。同样的涨幅，如果由现金买家推动，回撤是价格问题；如果由融资盘推动，回撤会变成流动性问题。看融资余额、看抵押品价值的顺周期性、看有没有"以资产价格换融资能力"的结构。
3. **政策是否在提供隐性担保？** 当市场相信"跌了就会有人救"，风险定价会被系统性压低。这种信念本身会推高风险偏好，直到某次不救为止。

**为什么我不主张事前戳破**：识别脆弱性相对可靠，预测时点几乎不可能——因为泡沫的持续时间取决于参与者的耐心与资金期限，而不是估值模型。承认这一点，方法论上就应该从"择时"转向"提高组合在最坏情形下的存活率"。

**检验清单**（任一为真，脆弱性上升）：新增买家以杠杆为主；抵押品价值与资产价格高度顺周期；风险溢价处于历史低位而盈利预期在上调；市场对坏消息的反应明显弱于对好消息的反应。

**二阶追问**：如果所有人都知道这是泡沫，为什么还在涨？因为参与者比的是"在破裂前离场"，这是一个关于他人行为的博弈，而不是关于价值的判断。承认这一点，才能理解为什么"看对了方向"依然可能亏钱。

> 说明：本示例为框架演练，不给出任何市场位置的结论与点位判断。
