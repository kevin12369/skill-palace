# 分析流程：完整工作流与分支路径

> 本文档将格林斯潘分析框架的 6 步工作流进行完整展开，提供 4 条分支路径的场景匹配表，以及常用数据锚点的取数清单。使用时先识别议题层级，再根据分支路径选择对应的核心理论组合。

---

## 完整工作流（6 步展开）

### 第一步：识别议题层级

在执行任何分析之前，首先判断用户问题属于哪个层级——这将决定后续选用的框架、数据源和分析深度。

**三个核心层级：**

- **长期结构层级**（3-10 年视野）：问题涉及全球储蓄流动模式、生产率趋势、人口结构与劳动力供给、全球化格局变化。例如"美元利率中枢是永久性下降还是周期性偏低？""AI 对全要素生产率的潜在影响有多大？"
- **中期周期层级**（6 个月-3 年视野）：问题涉及当前经济周期位置、通胀/增长/就业的边际变化、货币政策路径判断。例如"联储这轮加息还有多远？""当前通胀压力是暂时性还是持续性？"
- **短期政策层级**（数天-数月视野）：问题涉及下一次 FOMC 会议决策预判、某项数据发布后的市场反应解读、央行沟通的弦外之音。例如"下个月的 CPI 数据会改变联储的措辞吗？"

**复合判断**：如果用户问题跨越多个层级（例如"AI 如何影响利率长期中枢，以及联储当前路径应考虑这一点？"），识别为"综合宏观判断"——需要先做结构层级分析，再将其结论嵌入到中期判断中。

**判断指引**：如果不确定议题层级，默认从"中期周期层级"切入——这是最常用、最稳妥的起点。在分析过程中发现了结构性的因素需要引入时，再升级为综合判断。

---

### 第二步：取数

根据第一步确定的议题层级，从以下数据锚点中拉取对应序列。

**建议拉取的常用数据序列：**

| 数据项 | 频率 | 来源方向 | 适用层级 |
|--------|------|----------|---------|
| 2 年期/10 年期/30 年期美债收益率 | 日频 | Treasury / FRED | 全部 |
| 10Y-2Y 期限利差（或 10Y-3M） | 日频 | 计算 | 全部 |
| 核心 PCE 物价指数同比 | 月频 | BEA | 全部 |
| 非农生产率（季度年化） | 季频 | BLS | 结构/综合 |
| 单位劳动成本同比 | 季频 | BLS | 结构/综合 |
| 全球主要经常账户余额（中国/东亚/OPEC/德国等） | 季频/年频 | IMF WEO | 结构 |
| 美元指数（DXY 或广义美元指数） | 日频 | FRED | 中期/短期 |
| 股权风险溢价（ERP）与估值分位（S&P 500 PE/CAPE） | 日频 | 计算/数据商 | 泡沫评估 |
| 美联储/欧央行/日央行资产负债表规模 | 周频 | 各央行 | 中期/短期 |
| 初请失业金人数（4 周移动平均） | 周频 | DOL | 全部 |
| ISM 制造业/服务业 PMI | 月频 | ISM | 中期/短期 |
| VIX 及其他波动率指标 | 日频 | CBOE | 泡沫评估/短期 |
| 5 年/10 年 TIPS 盈亏平衡通胀率 | 日频 | FRED | 中期 |
| 联邦基金期货隐含利率路径 | 日频 | CME | 短期 |

**取数原则**：
- 不追求数据全量，而是追求"最少代表性序列"——能够回答问题的前提下，数据越少越好
- 优先拉取有长期时间序列的数据，以便做历史分位比较
- 对于微观先导指标（纸箱/金属订单/铁路货运等），仅在需要验证宏观方向时额外拉取

---

### 第三步：搭骨架

将取到的数据与核心理论匹配，确定分析结构。

**搭骨架的决策逻辑：**

1. 将数据初步浏览，标记最显著的特征（如"10Y-2Y 利差深度倒挂 50bp""生产率增速降至低位""工资增速远超生产率""全球储备美元占比趋势性下降"）
2. 根据最显著特征，从 6 个核心理论（`01-core-theories.md`）中选择 1-3 个适合的框架作为分析骨架
3. 确定框架之间的层级关系——是"一个主导框架 + 辅助验证框架"，还是"多框架并联联动"
4. 如果数据特征指向多个框架且方向一致（如生产率停滞 + 单位劳动成本上行 + 通胀高于目标），则分析的结构就是"多重证据指向同一方向"
5. 如果数据特征指向不同框架但方向矛盾（如生产率加速但通胀居高不下——可能是供给冲击），则需要特别标注矛盾所在，并作为"不确定性来源"记录

---

### 第四步：套文风

将搭好的分析骨架，用 Fedspeak 风格进行表述。完整的文风规范见 `03-style-and-voice.md`。此处给出快速参考要点：

- 先呈现数据观察，再给出条件性判断，最后给出"如果…那么…"的政策含义
- 高频使用 hedging 用词：在某种程度上 / 大体而言 / 在现有信息范围内 / 部分反映
- 避免精确预测值和单一定性结论
- 善用招牌概念：irrational exuberance / Conundrum / mop-up / fog of uncertainty
- 不确定性段落必须出现——即使你对自己的判断很有信心

**文风转换示例：**

原始分析结论："美国通胀已经见顶，联储应该在三季度停止加息。"

Fedspeak 表述："最近几轮核心 PCE 数据的下行走势，在某种程度上暗示物价压力可能正在接近本轮周期的高点区域。如果这一趋势在未来几个月内得到更多数据确认——特别是劳动密集型服务价格也开始出现放缓迹象——那么政策利率达到充分限制性水平的时点在时间维度上可能与当前市场定价所暗示的路径大致吻合，至少不至于显著偏离。当然，在我们有足够信息将近期走势定义为趋势而非波动之前，保持政策灵活性的价值不可低估。"

---

### 第五步：给跟踪信号

列出后续验证判断需关注的具体指标与条件阈值，使分析不是一次性的静态判断，而是可跟踪、可纠偏的动态过程。

**跟踪信号制定原则：**
- 信号必须具体——"关注通胀"不合格，"关注核心 PCE 在未来 3 个月的环比均值是否持续 < 0.2%"才合格
- 包含确认信号（验证判断正确）和否定信号（触发重新评估）两类阈值
- 明确每个信号的跟踪频率——日频/周频/月频
- 标明信号的优先级——哪些信号一旦触发必须立即重新评估，哪些仅作为参考

---

### 第六步：清晰度权衡

评估输出是否因过度使用 Fedspeak 而丧失了可操作性。Fedspeak 的"刻意含糊"有其价值——反映真实的不确定性、保留政策空间——但当含糊过度时，用户可能得到"什么都说到了但什么都不确定"的输出，失去使用价值。

**清晰度权衡检查项：**

1. 用户能否从输出中提取出一个"条件性方向判断"？如果不能——收敛文风，明确方向
2. 不确定性部分是否至少指出了可能的走向范围？如果只说了"不确定"而没有说"不确定的范围大致在 A 与 B 之间"——补充范围描述
3. 跟踪信号是否可操作？如果只是"关注后续数据"——需要更具体地指明关注什么数据、什么阈值、什么频率
4. 是否需要提供"非 Fedspeak 简化版"作为补充？对于决策导向的用户，可以附加一段去掉了大部分 hedging 的简化版核心结论

## 分支路径表

根据议题层级和核心问题类型，匹配以下 4 条分支路径：

### A·长期结构分析

**适用场景**：判断结构性变化趋势（如利率中枢、生产率增长、全球化格局、人口结构），视野 3-10 年。

| 步骤 | 操作 |
|------|------|
| 主导框架 | 生产率驱动增长（理论 1）+ 全球储蓄过剩（理论 2） |
| 辅助验证框架 | NAIRU 变奏（理论 5）——判断结构性劳动力供给变化 |
| 核心数据 | 非农生产率、单位劳动成本、全球经常账户余额、美债长端收益率、劳动参与率、美元指数 |
| 分析重点 | 区分结构性趋势与周期性波动；对"趋势持续或反转"的条件给出具体触发阈值 |
| 典型输出 | "如果生产率维持在过去 5 年约 1.0% 的年增速，那么中性利率 r* 可能仍处于较低水平，全球储蓄过剩的结构性因素（新兴市场预防性储蓄 + 人口老龄化）在可预见的未来并不支持长端利率大幅上行。但如果 AI 投资开始转化为可测量的全要素生产率提升——目前证据尚不足以确认——则这一判断可能需要重新评估。" |

### B·中短期政策分析

**适用场景**：判断联储政策路径（加息/降息方向、幅度、终点）、传导效率、下一次会议预期，视野 6 个月-3 年。

| 步骤 | 操作 |
|------|------|
| 主导框架 | 数据依赖（理论 6）——实时数据流的条件性判断 |
| 辅助验证框架 | 利率之谜/储蓄过剩（理论 2）——评估传导效率；NAIRU 变奏（理论 5）——评估劳动力市场松紧 |
| 核心数据 | 核心 PCE 月频趋势、初请失业金人数、ISM PMI、联邦基金期货隐含路径、期限利差 |
| 分析重点 | 构建"如果数据 X 显示 Y → 联储倾向于 Z"的条件链；不预测具体利率走向 |
| 典型输出 | "从数据依赖的角度看，目前的决策环境有以下特征：核心通胀月环比在过去 3 个月均值约为 0.25%，略高于与 2% 年化目标一致的 0.17% 水平；劳动力市场尽管有边际放缓迹象（初请失业金人数 4 周均值从低点上升约 15%），但绝对水平仍在历史低位。如果通胀月环比在未来 2-3 个月内持续高于 0.2%——意味着年化仍在 2.5% 以上——那么保持限制性政策的理由依然充分。如果劳动力市场出现更明确的松动信号，则需要权衡通胀与就业的双重使命。" |

### C·资产泡沫评估

**适用场景**：评估资产估值是否进入"非理性繁荣"区间、Greenspan Put 的强度与边界、市场定价中隐含的风险溢价，视野 3 个月-2 年。

| 步骤 | 操作 |
|------|------|
| 主导框架 | 非理性繁荣（理论 3）+ Greenspan Put（理论 4） |
| 辅助验证框架 | 全球储蓄过剩（理论 2）——超低期限溢价的来源；数据依赖（理论 6）——监控泡沫形成的实证信号 |
| 核心数据 | ERP（股票风险溢价）当前值及历史分位、VIX 及波动率曲线、融资余额/杠杆率、资金流入速度、信用利差、美债期限溢价估算 |
| 分析重点 | 识别"估值偏高"与"非理性繁荣"之间的差异——前者不一定需要行动，后者需要"观察-待命"；评估 mop-up 能力的边界 |
| 典型输出 | "S&P 500 当前的股权风险溢价约在 X%，处于历史上最低的 Y% 分位数。这本身不一定意味着非理性繁荣——如果盈利增长预期足够强劲且利率环境温和，低 ERP 可能是理性的。但与此同时，融资余额在过去 6 个月以约 Z% 的速度增长，散户参与度指标也处于历史高位——这提醒我们，当估值偏贵叠加杠杆加速时，即使判断'没有泡沫'，也不需要对其形成时点做过于精确的判断。如果市场的下行修正建立在自身内部去杠杆的基础上，央行的事后清理能力通常有效；如果下行由偿付能力风险触发——目前没有明显信号——则 mop-up 的空间将显著受限。" |

### D·综合宏观判断

**适用场景**：用户的判断需要多个框架联动、涉及跨层级推论，是前三类的整合升级版。例如"AI 如何影响全球利率、通胀和资产定价？"

| 步骤 | 操作 |
|------|------|
| 主导框架 | 全部 6 个框架联动——从生产率（理论 1）切入，延伸到储蓄过剩/利率之谜（理论 2）、NAIRU（理论 5）、非理性繁荣（理论 3） |
| 分析逻辑 | 首先做长期结构分析（AI 对全要素生产率的影响评估 → 推导对 r*/利率中枢/通胀中枢的影响 → 判断需要多长时间在经济数据中显现），然后将长期结论嵌入到中短期判断中（联储在多大程度上需要考虑长期结构变化？→ 当前数据依赖框架下，什么数据出现变化时意味着 AI 效应开始显现？），最后评估资产定价含义（如果 r* 确实上移，当前估值是否需要重估？→ Greenspan Put 在此过程中扮演什么角色？） |
| 核心数据 | 使用全部常用数据序列（见取数清单），重点对比 "含 AI 假设计"与 "不含 AI 假设计" 两组场景下的差异 |
| 典型输出 | 综合全部框架的联动表述，结论层层嵌套但每层可独立验证；跟踪信号分为"结构信号"（AI 对生产率的可测量影响出现）和"周期信号"（常规数据变化改变联储路径）两套 |

## 常用数据锚点取数清单

以下清单按用途分类，标注了每个数据锚点的推荐来源方向和关键解读维度：

### 利率与利差

| 数据锚点 | 关键关注维度 | 使用框架 |
|----------|------------|---------|
| 10 年期美债收益率 | 绝对水平的历史分位、与实际 GDP 增速的对比、TIPS 分解（实际利率 vs 通胀补偿） | 利率之谜 / 全球储蓄过剩 / 生产率驱动增长 |
| 2 年期美债收益率 | 联邦基金利率预期的市场定价 | 数据依赖 |
| 10Y-2Y 期限利差 | 倒挂深度与持续时间、历史倒挂后的衰退概率映射 | 利率之谜 / 非理性繁荣 |
| 10Y-3M 期限利差 | 联储偏好的衰退预警指标（更少受期限溢价波动干扰） | 数据依赖 |
| 5Y5Y 远期通胀互换 | 中长期通胀预期的市场定价 | NAIRU 变奏 / 数据依赖 |
| TIPS 盈亏平衡通胀率（5Y/10Y） | 市场定价通胀预期与实际通胀的偏差 | 数据依赖 |

### 增长与就业

| 数据锚点 | 关键关注维度 | 使用框架 |
|----------|------------|---------|
| 非农生产率（季度年化） | 长期趋势、加速/减速拐点、与工资增速的缺口 | 生产率驱动增长 |
| 单位劳动成本同比 | 工资-生产率缺口 → 成本推动型通胀压力 | 生产率驱动增长 / NAIRU 变奏 |
| 失业率（U3） | 绝对水平 vs NAIRU 区间估计 | NAIRU 变奏 |
| U6 失业率 | 包含 discouraged workers 和兼职就业不足——更全面的松弛度 | NAIRU 变奏 |
| 劳动参与率 | 结构下降（人口老龄化）vs 周期波动 | NAIRU 变奏 |
| 初请失业金人数（4 周 MA） | 趋势方向——最前沿的劳动力市场边际变化信号 | 数据依赖 |
| 职位空缺率 / 辞职率 | 贝弗里奇曲线——劳动力市场匹配效率 | NAIRU 变奏 |
| 平均时薪 / 雇佣成本指数（ECI） | 全面工资压力的最佳衡量 | NAIRU 变奏 / 数据依赖 |
| ISM 制造业/服务业 PMI | 新订单 vs 就业分项——方向一致性 | 数据依赖 |

### 全球与跨境

| 数据锚点 | 关键关注维度 | 使用框架 |
|----------|------------|---------|
| 中国经常账户余额 / GDP | 全球储蓄过剩的核心来源——趋势变化 | 全球储蓄过剩 |
| 全球主要经济体经常账户余额汇总 | 盈余国（中国/德国/日韩/OPEC）与赤字国（美国/英国等）的映射 | 全球储蓄过剩 |
| 全球外汇储备货币构成（美元占比） | 美元资产需求的趋势性变化 | 全球储蓄过剩 |
| 美元指数（DXY / 广义美元指数） | 强弱对新兴市场美元债务和全球金融条件的反馈 | 利率之谜 / 数据依赖 |
| 美债海外持有占比 | 下降趋势——去美元化？还是正常再平衡？ | 全球储蓄过剩 |

### 资产定价与风险

| 数据锚点 | 关键关注维度 | 使用框架 |
|----------|------------|---------|
| S&P 500 CAPE（席勒 PE） | 当前分位 vs 历史均值——估值热度 | 非理性繁荣 |
| 股权风险溢价（ERP） | 隐含的风险补偿幅度——历史最低分位意味着什么？ | 非理性繁荣 / Greenspan Put |
| VIX / VIX 期货曲线 | 绝对低位——市场是否为尾部风险定价不足？期货曲线形状——近期 vs 远期恐惧 | Greenspan Put / 非理性繁荣 |
| 信用利差（投资级 / 高收益） | 过低利差 = 风险定价不足 | Greenspan Put |
| 融资余额同比增速 | 杠杆参与度上升——泡沫加速信号 | 非理性繁荣 |
| 美债期限溢价（ACM / KW 模型估算） | 负值表明全球储蓄过剩等结构性力量仍在压低长端 | 全球储蓄过剩 / 利率之谜 |

### 央行与政策

| 数据锚点 | 关键关注维度 | 使用框架 |

## 取数操作指引

1. **按需取数**：不需要每次都拉取全部清单——根据第一步识别的议题层级和第四步确定的分支路径，只拉取相关数据序列
2. **优先长序列**：有长期历史可比较的数据（利率、通胀、生产率）比短序列数据（某些新编的指数）更有分析价值
3. **注意可比性**：取数时确保单位与频率一致——如核心 PCE 同比与核心 CPI 同比不能直接替换使用
4. **记录数据时间点**：在输出中标注数据日期，便于用户核实和后续跟踪
5. **微观验证宏观**：当宏观数据出现方向性信号时，用微观先导指标（初请/PMI/信用利差）进行交叉验证——这是格林斯潘数据依赖方法论的核心实践
