# 关键观点年表

本文件按时间顺序梳理格林斯潘重要公开观点，标注每个观点对核心框架的贡献。

| 时间 | 场合 | 核心观点 | 框架贡献 |
|------|------|---------|---------|
| 1996-12-05 | 美国企业研究所（AEI）演讲 | "我们如何知道非理性繁荣何时过度抬高了资产价值…我们不应低估…与之相关的复杂问题" | "非理性繁荣"框架首次公开化；奠定资产价格预警思路 |
| 1997-02 | Humphrey-Hawkins 国会证词 | 亚洲金融危机前夜，提示"过度杠杆与亚洲金融部门脆弱性" | 数据依赖早期范例：基于跨境资本流数据提前预警 |
| 1998-09 | 伦斯勒理工学院演讲 | "我不认为我们能通过提高生产率增长来引发通胀" | 生产率驱动增长框架：生产率加速不必然引发通胀，支持不加息决策 |
| 1999-08 | 杰克逊霍尔年会"货币不确定性与评估" | "我们必须更谦卑地认识到…我们对经济结构的认知是不完全的" | 数据依赖方法论的哲学表述；拒绝机械规则 |
| 2000-02 | Humphrey-Hawkins 证词 | 生产率加速使潜在增长率上移，NAIRU 下移 | NAIRU 变奏框架：自然失业率随生产率动态重估 |
| 2001-01 | 联邦公开市场委员会声明 | 启动宽松周期应对互联网泡沫破裂与衰退 | "事后清理 mop-up"框架范例：先泡沫破裂后宽松 |
| 2002-08 | 杰克逊霍尔"经济波动与货币政策" | "Greenspan Put"市场预期被讨论；强调不主动刺破泡沫 | Greenspan Put 框架公开化 |
| 2003-07 | Humphrey-Hawkins 证词 | "通胀率若过低…将带来负面后果"，预防性宽松 | 数据依赖 + 风险管理：对尾部风险不对称反应 |
| 2005-02 | Humphrey-Hawkins 证词 | 长端利率未随加息上行，"Conundrum（利率之谜）" | Conundrum 框架命名；全球化资本流动对美国利率的反向压制 |
| 2005-08 | 杰克逊霍尔"全球化与货币政策" | 全球储蓄过剩压低全球长期实际利率 | 全球储蓄过剩框架正式化 |
| 2007-09 | 《The Age of Turbulence》自传出版 | 系统梳理全球宏观模型、储蓄过剩、印度硅港、老龄化 | 框架来源集成化 |
| 2008-10 | 国会作证 | 承认"模型存在缺陷…我等了 40 年的一个发现" | 反思风险模型对尾部事件的低估；本 skill 仅作背景参考 |
| 2013 | 《The Map and the Territory》出版 | 风险模型需引入"动物精神"与行为因素 | 后期方法论扩展，作为背景补充 |

## 使用说明

- 分析历史性问题时优先引用本表中的场合与措辞
- 2008 年之后的反思性表述仅作背景参考，不作为核心框架
- 引用时应注明具体日期与场合，避免泛化"格林斯潘说过"
- 跨年表引用时保持框架名称与 `references/06-glossary.md` 一致
