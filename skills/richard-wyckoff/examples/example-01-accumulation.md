# 示例 01：吸筹结构

## 输入

> 识SC→ST→Spring→SOS完整吸筹循环

## 框架选择

- **主框架**：吸筹/派发循环——判大势
- **辅助框架**：供求法则——供需判断

## 完整输出

先说这套框架的判断逻辑：市场在PS(初步支撑)→SC(卖出高潮)→AR(自动反弹)→ST(二次测试)→Spring(弹簧)→SOS(强势信号)六个阶段循环。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判大势」。按「吸筹/派发循环」走，一共 3 步：

1. **识当前阶段**
2. **看量价结构**
3. **在Spring/SOS入场**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「吸筹/派发循环」自己的校准例子可以拿来对照：缩量横盘+多次ST不创新低=吸筹末端。

边界必须说清：识别阶段是威科夫的第一步。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 低位窄幅横盘+量缩=吸筹结构正在形成；Spring假跌破+量放大=进场信号。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——处在吸筹还是派发
2. 供求关系
3. 量价结构(测试/弹簧)
4. 关键位
5. 最终建议——等/进/出
