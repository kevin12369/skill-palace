# 示例 02：均值回归

## 输入

> 估值分位与回归压力

## 框架选择

- **主框架**：流动性驱动——判断市场水位
- **辅助框架**：估值均值回归——贵贱判断
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：市场的本质是钱多钱少；流动性宽松水位高，收紧水位降。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「判断市场水位」。按「流动性驱动」走，一共 3 步：

1. **看央行与利率**
2. **看增量资金**
3. **判水位方向**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「流动性驱动」自己的校准例子可以拿来对照：宽松周期推高估值，收紧周期杀估值。

边界必须说清：流动性拐点常领先基本面。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 信用周期仍处扩张后段、估值已修复大半，均值回归下行的风险大于上行。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——周期位置
2. 信用与流动性
3. 估值与资金流
4. 中美传导
5. 最终建议——配置方向
