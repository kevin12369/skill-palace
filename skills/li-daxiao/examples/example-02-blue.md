# 示例 02：蓝筹导向

## 输入

> 低估值优质蓝筹评估

## 框架选择

- **主框架**：底部命名法——标记底部
- **辅助框架**：顶部警示——提示风险
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：用"婴儿底""钻石底"等形象命名标记底部区域，便于传播与记忆。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「标记底部」。按「底部命名法」走，一共 3 步：

1. **识别估值/政策底部**
2. **命名强化**
3. **跟踪确认**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「底部命名法」自己的校准例子可以拿来对照：2015 股灾后提出"婴儿底"。

边界必须说清：命名是沟通工具，非精确点位。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 估值处历史低位+政策暖风+情绪冰点，钻石般的底部区域，好股票值得坚守。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——牛熊位置
2. 政策面
3. 估值面
4. 情绪面
5. 最终建议——守底还是防顶
