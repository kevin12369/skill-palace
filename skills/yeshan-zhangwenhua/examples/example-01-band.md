# 示例 01：波段操作

## 输入

> 四阶段波段操作的完整循环

## 框架选择

- **主框架**：波段操作——操作周期选择
- **辅助框架**：量价形态——真假判断
- **不采用**：先做横向排名与增速外推。它们是结果指标，不能替代框架判断

## 完整输出

先说这套框架的判断逻辑：A股不适合长期持有也不适合天天超短——波段(2-8周)是最适配散户的节奏。

因此这类问题不先问答案，先问判断依赖哪些前提——定位是「操作周期选择」。按「波段操作」走，一共 3 步：

1. **寻低位起涨信号**
2. **等2-3周拉升**
3. **在高潮区获利了结**

3 步走完只得到一个「有条件」的判断，不是一句断言：条件成立时倾向哪一边，条件被破坏时判断要往哪边改。框架的价值就在这里——它不提供答案，它提供的是「这个答案依赖什么」。

「波段操作」自己的校准例子可以拿来对照：均线金叉+放量阳线→波段起涨；均线走平+缩量→止盈。

边界必须说清：波段的核心在节奏，不在选股。

同一个判断，用本 SKILL 的语气写出来是这样的（用于校准文风，不是本示例的结论）：

> 低位放量阳线+均线金叉+位置不高→波段买点；缩量回踩均线可加。

可执行的判断规则（本 SKILL 的输出格式）：

1. 核心判断——有波段机会否
2. 量价形态与均线位置
3. 主力资金迹象
4. 支撑与目标位
5. 最终建议——等买/持有/止盈
