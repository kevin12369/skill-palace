# 04 - 关键观点与年表

> 詹姆斯·西蒙斯 的生平与思想演进关键节点。

| 年份 | 事件 |
|------|------|
| 1938 | 生于美国马萨诸塞 |
| 1961 | 与陈省身共创陈省身-西蒙斯定理（微分几何） |
| 1978 | 创立文艺复兴科技(Renaissance Technologies) |
| 1988 | 大奖章基金(Medallion)成立，转向纯量化 |
| 2024 | 逝世，享年86岁 |

## 框架演进要点

- 早期：奠定核心方法论基础
- 中期：体系化并著书立说
- 后期：被广泛引用，成为 量化投资与统计套利 领域的参照坐标

> 如人物已故，观点止于最后公开表达之时；数据判断须以实时信息为准。
